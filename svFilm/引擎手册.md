# 二、引擎的关键语义

```
★ `{"mul":k}` 乘的是**预设自己的基值**（不是上层解析后的值）
★ 层序：`_scene_engine["*"]` → `_stock_engine[<预设>]` → 轴层（**后者盖前者**）
★ `overrides` 的键名 = **运行时属性路径**（`simulation.print_exposure` ⇒ `enlarger.print_exposure`）
★ **改 exposure 的那一层 = `exposure.py` 的 `ev' = (1-w)·ev + b`**
  ⇒ 「逐图算印相曝光」**只能在这层做**；`print_exposure` 是**整卷常数**，加一层 = 重复计数
★ `film_format_mm` = 画幅**长边**（mm）⇒ 70 vs 36 ⇒ 三条空间族 σ_px **×0.514**
★ `film_format_mm` 语义 = `max(图长边)` ⇒ **裁图后只是近似**
★ ★★ **`presets.render()` 裸调不读 `targets.json`**
  ⇒ 生产路径 = `targets.scene_engine(sc, stock, cfg)` 之后作为 overrides 传入
★ ★ **`overrides` 必须整份传**：只传"要改的那根"会让 `density_curves_morph.active` 丢
  （它只在 `_scene_engine["*"]` 里是 True）⇒ 整根 morph **静默死掉**
```

# 三、能改"分色形状"的机制（**只有三类**）

## ① `film_render.dir_couplers.*`（9 个矩阵元 + `amount`；密度依赖）

```
★★ 作者原话（`spektrafilm/README.md（作者仓库）:107-111`）：
   「data-sheet curves are really not enough ... The key is to understand that film emulsions
     contain couplers ... these are very important for achieving the desired saturation」
   ⇒ ★ 他说"最关键的一步 = 耦合剂"，目的 = "想要的饱和度"
   ⚠ 但他**没写 "most important"** —— 引用时不许升级措辞
★★ 而 9 个矩阵元是 TODO（`params_builder.py:175`）：
   「gamma_interlayer_b_to_rg = (0.168, 0.226)  # just eyeballed, optimize!」
   ⇒ ★ "目标已写、还没做" ⇒ 我们那条把 9 个矩阵元**原样用引擎默认**（零实测）
★★ `inhibition_interlayer` 与 `amount` 在 Lab 响应空间**夹角余弦 0.9905**
   ⇒ 机制① 的"强度"只有**一个**自由度；三条的 raw gamma 字段逐位相同（形状也没分家）
★ 已做对的：负片端耦合剂在跑、**相纸端不跑**（`_apply_print_specifics()` 空函数）
   —— 与作者设计一致（`README.md:95-98`：相纸端"no couplers in this case"）
```

**★ 主旋钮 = `couplers.amount`，而它不是"只动彩度"的旋钮：**
```
★★ **颊色相响应 増田 +40.7° / 单位 amount**（鹿井 −32、滨田 ~0）⇒ **连符号都不同**
★ 増田 +0.10 的 Δ`b*−a*` +2.07 里 **只有 +0.43 是幅度、+1.85 全部来自色相**
★ 它对**亮度 / 白端 / 中性轴**基本不动（这一部分成立）
★★ **对 `A4_b`（中/亮）杠杆 ≈ 0**（走一整档只值分辨力的 0.2~4.1%）
   —— 机制：纯标量倍率**同乘分子分母**，比值不动
```

**★ "改色相配比"两条路：**
| 路 | 斜率 | 代价 |
|---|---|---|
| **`film_gamma_factor` 3 元组** | **+145 / 单位 \|dg\|max** | **ΔC\* ≈ +0.27（≈免费）** ⇒ ★ **首选** |
| `couplers.amount` | +19.9 / 单位 | **颊 C\* +2.3** ⇒ **贵 8 倍** |

## ② 逐通道密度曲线（`gamma_factor_{rgb}` / `density_curve_gamma` 3 元组）

```
★★ **两入口不是同一根旋钮**：
   · 印相端 = **绕枢轴旋转**（da\* 变号于 L\*≈54）
   · 胶片端 = **单瓣**（da\* 全程同号、L\*10~80、两端趋零）
★ 但**两入口都不是"暗端选择性"**：暗瓣/其它档 = 印相 ≤0.78 / 胶片 ≤0.51
  ⇒ A2（"只推暗端"）**两入口都做不到**（三通道近共线，硬解要 |dγ| ≈ 7.7，物理不可行）
★ `presets.py:383` 的 `float()` 已放开 ⇒ **3 元组可落地**（标量或 3 元组都收）
```

## ③ 光谱级 —— **只剩"换卷 / 换纸"**

```
★★ `camera.filter_uv` / `filter_ir` **属线性类**，不是光谱级：
   · 传递性质证明：Hanatos 路径上只有"逐通道缩放"能精确传递（跨色度展宽 0.00%）
     ⇒ UV/IR 在 film raw 上就是 **3×3 对角阵**；21 臂实测 R/G 幅度带仅 **0.46%**
   · A2 暗端选择性 0.117（要 ≫1）· 颊色相 +0.99°（跨大师差 12°）⇒ 差一个量级
   · 且它把 R1 推向更大（0.951→1.293）⇒ 与"修黑端"反向
★ 预设里**从没人设过**它（全是 schema 默认）⇒ **保持 amp=0 不设**
★★ "按卷分家"已由**卷 profile 自带的适配窗**承担（红通道 +1.4%~+5.9%、跨色度展宽 16~47%）
   ⇒ 比 camera filter 大一个量级 ⇒ **别再在 `filter_*` 上分一次**
```

**★ 其余（滤片 / 光源 / 眩光 / 色域压缩 / 任何 3×3）属线性类：**
```
ΔC*/C* = c + p·cos2h + q·sin2h ⇒ 只有 DC + 二次谐波 ⇒ **做不到分色相**
```

## ★ 总账
```
① 只有 1 个自由度（已被 `amount` 占）· ② 做不到 A2 · ③ UV/IR 属线性类
⇒ ★★ **"能改分色形状"的路，只剩「换卷 / 换纸」**
```

# 四、空间族（颗粒 / 柔光 / halation）

## ★★★ 验收 = 「**物理方向 + 目检**」，**不是"像大师"**

```
★★★ **大师是【真实胶片机】拍的，我们是【数码相机】拍的** —— 两条不同的链**
   · 大师的颗粒 = 乳剂里真实银盐的随机簇（拍摄时**记录**进去的）
   · 我们的颗粒 = 引擎在数码图上叠的噪声（后期**造**出来的）
   · halation：大师是"光穿乳剂→片基背反射→记录"；我们是**模拟**
   ⇒ ★ **来源不同 ⇒「对上去」本身没有定义**
★ **物理/器材事实只提供【方向】**（他用了柔光镜 / 卷抗晕弱 / 画幅 6×7 / 逆光 ⇒ 晕明显）
   ❌ **不提供【值】** —— 他的 "Pro-Mist 1/8" 是在他的镜头+他的胶片上；
   我们设同档 = 在数码图上叠加 ⇒ **效果不等价** ⇒ 值必须在**我们自己的数码链**上定（试 + 目检）
★ ★ 空间族是**唯一"可以不靠大师数字就正当定值"的一族**（依据在**器材**里，不在成片里）
★ ⚠ **必须【全长边】判**（2048 上高频已被缩图抹掉）
★ ⚠ **它会串到颜色**（halation 是带色的）⇒ 改它要同时看肤色 / 脸−臂 / 中性轴
```

## ★★ 已测出的物理事实

```
★★ **颗粒幅度 vs 亮度：中调最响、两端归零**（实测峰 L*45–60，解析峰 L*30–45）
   ⇒ **我们原生像物理** ✓（机制：σ(D)=√(D(Dmax−D)/n) × 影调斜率 ⇒ 两头都塌）
   ⚠ 差异：真实"最粗"在**负片最薄处（阴影）**，我们在**输出中调**（落点由冲扫斜率决定）
★★ **颗粒功率谱：原生是白噪声（−0.162 = 平）** ⇒ **满足"大于乳剂相关长度上谱应平"** ✓
   · 交付物上的陡降（−1.355）是 `grain.blur` 做的，**形状随口径变** ⇒ 不是颗粒的内禀结构
   · ⚠ **"真实银盐是团簇"这个假设，二手材料不支持**（Selwyn / 专利 CA2309002A1：
     "grain noise seems to be white noise blurred by the film scanner PSF"）
★ **halation**：`σ_h` per-channel ⇒ G 收窄到 0.45σ_R
   · 交付尺度 R/G：65 µm 处 **7.2** → 130 µm 处 **3.6**；**贴边 R/G = 1.35**（由幅度比 8:2 定死）
   ⇒ 0.45 **只改"多快变红"，改不了贴边那一瞬**
★ **画幅**：36 → 70 ⇒ 三条空间族 σ_px **×0.514**（已验）
```

## ★★ 两条不可复现的事实（**取差前必读**）

```
★★★ **`print_render.glare` 永不可复现**
   · 根因：走 **numba RNG**（`fast_binomial` / `fast_poisson` / `fast_lognormal_from_mean_std`），
     **`np.random.seed()` 管不到**（numba 0.67 无 `_init` 钩子）
   · 实测：**同参两渲 max|Δ| = 22 码**
   ⇒ ★★ **任何"同参两渲取差"必须先关 glare**
★★★ **"同参两渲差 = 纯颗粒"是错的**
   · 整链同参两渲的**负片密度场本身就不一样**（颗粒模型入参 hash 变了）
   · 量级：**6264** 上密度差只有 1e-4（颗粒 0.132）⇒ 可忽略
   · ⚠ **2048 上与颗粒同量级** ⇒ **不许用 2048 的颗粒绝对值**（只能当方向）
```

## ★ 空间族的现状（**幅度已定，形状/半径/器件没碰**）

```
★ **已定死**：颗粒倍率 `particle_area_um2=1.2`（风格，目检定的常量）
   · halation `(0.08,0.02,0.0)`（= 引擎给 `('still','weak')` 的物理基线）
★ **技术性缺口已修完**：
   · `GRAIN_BLUR_REF_LONG_SIDE = 6264` · `LENS_BLUR_REF_LONG_SIDE = 6264`（预览 = 交付）
   · `HALATION_G_SIGMA_RATIO = 0.45`（钩子，实现"近橙远红"）
★ **没碰过的**：46 个柔光/光晕键里 **35 个**（只做了幅度，没做形状/半径/器件）
   · `camera.diffusion_filter` **整族 11 键全死**（`active=false`）· `camera.lens_blur_um = 0`
   · halation 的**散射段 6 键** · `print_render.glare.*` 3 键
★ `grain.density_min` 是**活键**，但它是 **LUT 归一化下界 = 负片的 0 参考点**（全局量）
   ⇒ **不是暗端旋钮**；现值 `[0.07,0.08,0.12]`（B 通道高 = **负片橙 mask 的物理值**）
```

## ★★★ 量法铁律

```
★★★ **不要用 `film_render.grain.active=False` 当"颗粒基线"**
   · `grain.blur` 那道**全图高斯糊只加在 `active=True` 分支里**
     （`grain.py:104-106`；`active=False` 在 `:176` 直接 return）
   ⇒ "有颗粒 − 无颗粒"的差 = **【一道全图糊 + 颗粒】两样东西**，不是颗粒
```

# 五、已证否的路（**别再试**）

| 想做什么 | 为什么不行 |
|---|---|
| **逐色相改分色形状** | 线性类只有 DC + 二次谐波；机制① 只有 1 个自由度（已被 `amount` 占）|
| **A2「只推暗端」** | 两入口都做不到（三通道近共线，硬解要 \|dγ\| ≈ 7.7）|
| **`camera.filter_uv/ir` 做光谱级** | 属线性类（3×3 对角阵，R/G 带仅 0.46%）|
| **换卷换纸修 D-1** | 六种纸的"亮端窗斜率 ÷ 中段窗斜率"全在 0.906~1.062 ⇒ 无选择性去彩 |
| **`knee` 修"亮端彩度"** | 它**按饱和度**压（与亮度基本无关）⇒ 中段掉得比亮端多 ⇒ **方向反** |
| **用 `amount` 追 `A4_b`** | 杠杆 ≈ 0（同乘分子分母）|
| **`amount` 做"动态适配"** | "效果差一倍"是**图的属性**（图 75% / 链 14%）· 逐机**不可识别**（只有 1 台机身）· 逐图**会振荡** |
| **`camera.diffusion_filter`** | 整族 11 键 `active=false`（死键）|
| **`film_render.glare`** | 死字段（管线只读 `print_render.glare`）|
| **JSON 里写负片 `gamma_*`** | `_apply_film_specifics` 会**无条件重写**（死键）|
