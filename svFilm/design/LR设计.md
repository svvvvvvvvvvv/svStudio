# LR 设计

> 服从 `纪律.md` / `设计真源.md`。
>
> **最高规则：对齐人选的那张大师卡。**
> 卡给的是：WB/色温、明暗分布、肤色关系、冷暖/调色方向、背景关系。
> LR 侧只做两件事：**把卡级参数定下来**，**把每张图送到卡的关系上**。
>
> 本版 2026-11-01 整理。历史版本在 `_archive_20261101/`。

---

## 1 边界：哪些卡级，哪些图级

| 级别 | 谁管 | 内容 |
|---|---|---|
| **卡级** | 标卡时定，整组共用 | **WB / 色温 / Tint** · 明暗分布目标 · 肤色 C/L 关系（H 只记账，归 WB） · 冷暖/分色方向 · **一个局部蒙版** |
| **图级** | 每张算 | 曝光/明暗落点 · 曲线 · 肤色剂量 · 局部剂量 · 细节 |
| **不做** | — | 逐图 WB · 逐图换多组蒙版 · 数值靶/区间靶 · 任意 cap/one-step · **HSL 调肤色** · Blacks 一刀切 |

**WB 是卡级/组级，不是图级。** 一批里有两套光 ⇒ 拆批；不逐图调色温。

## 2 目录级标定：一个目录一个 WB

标一张大师卡时，除了现有 `points`，补：

```json
"wb": {
  "cast": {"a": -1.0, "b": 2.5, "n": 10},  // 目录级全局 cast 目标（中低段中性；诊断用）
  "temperature": 5400,                      // 目录级引擎输入（解出来的，不是白点 CCT）
  "tint": 0.98,
  "policy": "directory-fixed"
}
```

- **cast 目标**：每张大师取 `C*≤10、L*20–80` 的中性像素中位 a\*/b\*，再对目录内大师取中位；**不是白点、不是脸、不是整体暖色**。
- **temperature/tint 是目录级引擎输入**：在一个同光批次上用 3 个探针（base / temp+Δ / tint+Δ）量同一个 cast，2D 解出来；不是把成片白点 CCT 反解成解码温度。
- **白点/L\*80–100 只做诊断**：相纸 base_density 把白顶钉在 b\*+0.8~0.96，WB 推不动，也不该拿它当目标；解超过 7000K 说明介质/印相不匹配，停止，不接受。
- 一个目录一个值，整批共用；一批混两套光 ⇒ 拆批，不逐图调。
- 卡 108 当前：`cast a−1.0 / b+2.5`，引擎 `5400 K / tint 0.98`（已解）。
- **WB 在引擎 RAW 解码层落**（`io.load_raw(wb=…)`）：TIFF/JPEG 在 LR 里的 Temp/Tint 是**相对量程**（Adobe 明文），写开尔文会错，所以 LR XMP 保持 `As Shot`。

跑批时：

```
一个目录一个 WB（同光批次共用）
→ 混光拆批
→ 每张只算：曝光/明暗、曲线、肤色剂量、局部
```

## 3 图级顺序：先全局，后局部

### 3.1 曝光 / 明暗

先让**整幅/背景**成立，再补脸。

- 用卡的**明暗分布/曲线形状**（p5/p50/p95/对比/肩趾）作为关系，不用单点 p50；
- **Basic 为主**：Exposure、Highlights、Shadows、Whites、Blacks、Contrast；
- **Tone Curve 补形**：Basic 定大关系，曲线修肩/趾/局部形状；
- 目标不是“背景 L=某个数”，是背景的结构/层次和卡的关系；
- 背景已成立、脸偏 ⇒ 局部补脸，不拿全局曝光压背景；
- 整幅都偏 ⇒ 动全局曝光。

### 3.2 颜色

- WB 已由卡级固定；**色相归 WB，不在 LR 里用 HSL 拧**；
- 肤色：**只用蒙版里的 Point Color**（沿用 2026-10-31/11-01 跑通的 `POINTSWATCH` + `SatScale` 路径，不另起一套，也不做 HSL）；
- 机制：在 subject 蒙版组里加一张 **local point-color 肤色色票**（取样 = 这张脸的真实像素，不用 Lab 反算）；`SatScale` 是相对饱和刻度，按肤色 C/L 关系给量：

  ```
  r0 = C0 / L0（这张 ①）      r* = C* / L*（卡/peer）
  e  = r*/r0 − 1             ⇒ SatScale = clamp(e, −1, 1)
  ```

- **肤色处理不能改整体背景**：色票按肤色色相取样，只动肤色窗内的像素；
  白衫低饱和、树墙的橙红不在同一窗 ⇒ 不拿背景换肤色；
- 冷暖/分色：只对卡里**近中性**（C\* ≤ 1.5）且方向在暖（20–70°）/冷（200–260°）的
  高光/暗部；**场景色**（树叶绿 h≈99、天空蓝等）跳过，不做全局分色。
  剂量由目检验证，不固定 +10。

### 3.3 局部

- **一张卡用一个局部蒙版**（脸/肤色）；整组共用同一套蒙版设置，不逐图换多组；
- 补脸/肤色只作用在蒙版内；**不能改整体背景**；
- 局部曝光/局部明暗只在“背景已成立、脸/关系偏”时动；
- 一组蒙版只做一件事；需要背景分开就另开背景蒙版，不能拿 subject 整身蒙版补脸。

### 3.4 细节

- 锐化/降噪/导出只做物理层；颗粒/光晕归引擎，不在 LR 里补。

## 4 不做的规则（本版清掉）

以下是我之前拍的/历史脚手架，不再作为生产规则：

- ❌ 六格决策当唯一路径（先判脸÷背景再决定动谁）——改成“先背景、后脸”的顺序；
- ❌ 全局曝光必须为 0 / 必须为 p50 / 必须按 face_L——曝光是第一键，由整幅/背景定；
- ❌ `cap ±0.2`、`一档 10 UI`、`Whites 必须 −10` 当目标——只保留“无公开传递函数时先小步+③验”的方法，不保留固定剂量；
- ❌ “禁用 Blacks”——卡需要就用，剂量验证；
- ❌ “背景 L=30”这类数值靶；
- ❌ subject 整身蒙版补脸；
- ❌ 逐图 WB。

保留的只有：

- 物理底线：死白 / p1 死黑 / 量程 / 非单调 / 肤色崩；
- 卡的关系/形状/配比；
- ③ 预测 vs 实测 + 目检；
- 接口事实（下一节）。

## 5 接口事实（不是规则）

| 事实 | 值/做法 |
|---|---|
| `LocalExposure2012` 文件值 | EV/4（4 档 = 满刻度 1.0） |
| 局部其余滑杆文件值 | UI/100 |
| 写局部 | `MASK ...` 建组 + `MASKPARAM` 写值；直接 `MASK ... LocalExposure2012=` 不落地 |
| 回读 | 回读 nil ≠ 没写；以成片 XMP/测量为准 |
| 蒙版组 | `MASKPARAM` 只写第 1 组；一图一组 |
| 肤色蒙版 | `MASK <tif> subject` 建组 → `POINTSWATCH`（isForMasking=true）加肤色色票 → `MASKPARAM` 写局部；SDK **没有 facialSkin** 子类型（`people` 实测建不出组） |
| WB | 卡存 **look-white 目标**（a*/b*、Δuv）；解码 WB 用相机/介质；TIFF 的 Temp/Tint 是相对量程，不写开尔文 |
| A/B 合写 | 合并成一份 XMP 再写，写后回读校验 |
| 曝光 | LR Exposure +1 = 线性光 ×2 |

## 6 交付与目检

```
LR 出片 ③ → 出目检页（③ + ① + 测量）→ 人目检
机器不宣布“过/不过”；物理/卡偏差只做诊断
人说过，才算过；人说过不了，写“哪一段没做到”
```

- 测量只定位：死白/p1/肤色崩/背景结构/卡偏差；
- 不设“背景 L 必须多少”的数值门；
- 目检先看整体（背景/环境），再看脸；脸好背景塌不算过。

## 8 代码地图

```
lr_plan.py      LRPlan 数据模型（WB/Basic/PointColor/局部/曲线）
lr_solve.py     图级：WB/曝光明暗、曲线、肤色（蒙版里的点颜色）、冷暖、局部
lr_response.py  Basic 滑杆实测一阶响应
lr_exec.py      plan → XMP/桥
lrsink.py       XMP 作业单 + 桥执行（subject 组 + 肤色色票）
lr_bridge.py    桥客户端（ADD/SELECT/EXPORTTIF/POINTSWATCH/MASKPARAM）
review.py       ③ 目检页（测量只做诊断）
peer.py         同构图/同场景 peer
card_*          卡级 WB/点值/内容
```
