# LR 设计

> 服从 `设计真源.md`。LR 只做修补：**A 收风格残差（批级）· B 收关系残差（图级）· C 验收**。

## 1 边界

| | A（批级） | B（图级） |
|---|---|---|
| 动 | 颜色（WB/肤色）· 明暗层次（曲线）· 冷暖参数 | 曝光 · 脸÷背景 · 白端 · 冷暖落地 |
| 不动 | 亮度（曲线保持 p50） | 颜色修正（WB/HSL/肤色） |
| 蒙版 | 不用 | 用唯一那一组 |
| 判据 | 卡的不变量带 | 条件表 + 物理 |

阈值 = 偏出卡带 **> 半个带宽** 才动，动到带边。

## 2 A 段：批级

```
1 全批 ① 的测量 → 逐量取中位
2 每个量 vs 卡带：在带内/偏出≤w/2 ⇒ 跳过；出带 ⇒ 按下面算
3 输出 batch_grade：全批一条曲线 + 一套颜色
```

| 项 | 做法 |
|---|---|
| 曲线 | 位置 = 全批分位中位；间距 = 卡的带；每锚点累计位移 ≤3 L\*；肩由卡 p95 上沿夹；补 0/100 端点；PCHIP；**保持 p50** |
| 肤色 C | 出带 ⇒ 局部饱和 **±10 UI**，③ 验 |
| 肤色 h | 只记目标 HSL 色相；局部染色是强染色，不写幅度 |
| 冷暖 | 出带 ⇒ SplitToning 两轮各 **10 点**，色相 45°/210° 成对 |
| 白平衡 | 方向：a 偏 → Tint，b 偏 → Temp；K/Δuv 由 `color_math` 算 |

曲线“保持 p50”是 A 不动亮度的唯一方式：两端可动，中间不平移，否则和 B 的曝光打架。
肤色只动 S/H，不动 L；饱和不越卡带；曲线不反折。

## 3 B 段：图级

```
1 光位（从 ① 判）：gap = bg.L_p90 − skin.L；dark = face_dark_share40
2 查条件形状：back / mid / front → 套在这张卡的 face_over_bg 带上
3 决策：脸/背景谁低，动谁；只动一个
4 写 plan：{light, band, action, predicted}
```

| 情形 | 动谁 | 公式 |
|---|---|---|
| 比值低 + 脸也低 | 主体局部 | `EV = ev_for_l(L0, Lt)`；Lt = 带下沿×bg_p90 |
| 比值低 + 脸在带内 | 背景压暗 | `ΔL_bg` 用 `ev_for_l` 换算 |
| 比值高 + 脸也高 | 主体局部压暗 | 同上，Lt = 带上沿×bg_p90 |
| 比值在带 + 脸偏 | 全局曝光 | `EV = ev_for_l(L0, Lt)` |
| 其余 | 不动 | — |

预测一律用精确式：`L' = 2^(EV/3)(L+16) − 16`；分位数与单调映射可交换。
局部曝光低段≈精确式，高段会压缩 ⇒ 大位移只当上限，不承诺落到目标。
预测出脸内死白或 p99 越白端 ⇒ 截断到带边，记账“物理截断”。

**白端**：p95 超卡肩 ⇒ Whites **−10 UI**，③ 验。
**局部 Shadows**：只记账；要动 ⇒ 一档 10 UI + ③ 验。
**黑端**：由曲线趾部/引擎黑点负责，不用 Blacks。

## 4 冷暖

```
A：warm_cool_b 出带 ⇒ 方向 + 一档 10 点（两轮成对，色相 45/210）
B：需要蒙版的那张，把同一组值挂到蒙版；不需要就记账，不改全局
```

## 5 执行与回读

```
一份 XMP：A 的键 + B 的键合并后一次写
蒙版：MASK subject|background → MASKPARAM
      LocalExposure2012 = EV/4；其余 = UI/100
回读：逐键回读；回读 nil ≠ 没写（以成片 XMP 为准）
失败：任一步回读不一致 ⇒ 中止并记账，不许静默跳过
```

## 6 机理成熟度

| 机理 | 传递 | 口径 |
|---|---|---|
| 全局曝光 | CIELAB Y 比 | 精确 |
| 局部曝光 | `l_after_ev` | 低段精确，高段压缩 |
| 曲线 | PCHIP | 可算 |
| Blacks / 冷暖 / 局部饱和 | 无公开传递函数 | 方向 + 一档 10 UI |
| 局部 Shadows | 无公开传递函数 | 只记账；要动一档 10 UI |
| 肤色色相 | Lab→HSL 有定义式，局部 UI 语义未验 | 只给方向 |
| 点颜色 | 无公开函数 | 不用 |

## 7 验收

```
③ 成片 → 量 → 硬门（脸 + 没把脸改坏）+ 软门（背景）
硬门破 ⇒ 先找漏：流程 / 引擎底片 / LR 剂量
质量差 ≠ 流程不通；不达标不许用“① 本身出区”放行
```

## 8 代码

```

batch_grade.py    A 段：全批中位 → 一条曲线 + 一套颜色
lr_solve.py       B 段：曝光/局部/白端；没传递函数的一档
lr_exec.py        plan → LRPlan；Whites 接线
lrsink.py         XMP/桥执行
review.py         ③ 验收
```
