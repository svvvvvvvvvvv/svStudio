# LR 设计（服从 `设计真源.md`）

> **宪法 = `设计真源.md`**。本文件只写 LR 三段（A/B/C）"怎么做"；冲突时改本文件。
> LR 只做修补：**A 收风格残差（批级）· B 收关系残差（图级）· C 验收**。

---

## 1 边界

| | A（批级） | B（图级） |
|---|---|---|
| 动 | 颜色（WB/肤色）· 明暗层次（曲线）· 冷暖**参数** | 曝光 · 脸÷背景 · 白黑端 · 冷暖**落地** |
| 不动 | **亮度**（曲线保持 p50） | **颜色修正**（WB/HSL/肤色） |
| 用蒙版 | 不用 | 用唯一那一组 |
| 判据 | 卡的不变量带 | 条件表 + 物理 |

**阈值一律 = 偏出量 > 半个带宽**（带宽是卡/条件带的宽，不另编数）。

---

## 2 A 段：批级

**hero 样片只做目检参考**——**由人选卡时一起指定**（`samples` 里点一张，和成片并排看）；
**数值目标 = 卡的不变量带**——出带且偏出 > w/2 才动，动到带边。**不拿 hero 做拟合**（拟合一张图 = 点靶，违反 P1）。

```
1 读全批 ① 的测量 → 逐量取中位（抗单张异常）
2 每个量：med vs 卡带
     · 在带内，或偏出 ≤ w/2 ⇒ 跳过，记账
     · 出带且偏出 > w/2 ⇒ 按下面的机理表算
3 输出 batch_grade.json（全批同参）
```

| 机理 | 目标量 | 公式 | 状态 |
|---|---|---|---|
| 曲线形状 | `toe/contrast_win/shoulder` | 锚点：p5→6、p25→6+toe、p75→p25+contrast_win、p95→min(p75+shoulder, W)；PCHIP 插值；**保持 p50** | ✅ 可算 |
| 曲线暗部 | 卡 `contrast` 带的残差 | 段内斜率 ×1/r，r=(p50−p5)后/前 | ✅ 有标定 0.30 L\*/px |
| 白平衡 | 中性轴 a/b | 只做方向：a 偏 → Tint，b 偏 → Temp；**Lab→Temp/Tint 无映射** | ⚠ 只有方向 |
| 肤色 C | 卡 `face_C` 带 | `Saturation = ΔC / 0.221` | ✅ 有标定 |
| 肤色 h | 卡 `face_h` 带 | HSL 橙 Hue；**Lab→HSL 无映射** | ⚠ 只有方向 |
| 冷暖强度 | 卡 `warm_cool_b` 带 | `S = Δb / 0.18`（背景 b50） | ✅ 有标定 |

★ 曲线"保持 p50"是 A 不动亮度的**唯一实现方式**：两端可以动，中间不能平移，否则 B 的曝光会跟 A 打架。

**三个保护（缺一不可）**：

```
肤色：只动 HSL 的 S / H，**L 不动**（改了 L 就不是"调色"，是"提亮"——那是 B 的活）
饱和：不许越卡 `face_C` 带（推过了会"假"）
对比：曲线**不反折**、**不动 p50**（反折 = banding；动 p50 = 抢 B 的曝光）
```

## 3 B 段：图级

```
1 光位标签（从 ① 判）：gap = bg.L_p90 − skin.L；dark = face_dark_share40
2 查条件形状（模型级）：back / mid / front → 套在**这张卡的** face_over_bg 带上（+ face_L 弱约束）
3 六格决策
4 写 plan_<stem>.json：{light, band, cell, action, predicted, skipped_reason}
```

| 情形 | 动谁 | 公式 |
|---|---|---|
| 比值低 + 脸也低 | 主体局部 | `EV = 3·log2((Lt+16)/(L0+16))`，Lt = 带下沿×bg_p90 |
| 比值低 + 脸在带内 | 背景压暗 | 压 bg：`ΔL_bg = bg_p90 − 带上沿×face`，用 18.7 近似换算 |
| 比值高 + 脸也高 | 主体局部压暗 | 同上，Lt = 带上沿×bg_p90 |
| 比值高 + 脸在带内 | 只记账 | — |
| 比值在带 + 脸显著偏 | 全局曝光 | `EV = 3·log2((Lt+16)/(L0+16))` |
| 其余 | 不动 | — |

**写之前先预测**：`ΔL_face = 18.7 × EV`；`Δp99 = 11.2 × EV`（未饱和）。
预测出**脸内死白**或 p99 越白端 ⇒ 截断到带边，记账"物理截断"。

---

## 4 冷暖：A 算、B 落地

```
A：由卡 warm_cool_b 带算方向与强度 S = Δb / 0.18，写进 batch_grade.json
B：哪张图要用蒙版（背景组），就把 S 一起挂上去
   图上不需要蒙版 ⇒ 冷暖不做（记账）；不许偷偷改全局
```

---

## 5 执行与回读

```
一份 XMP：A 的键（曲线/颜色）+ B 的键（曝光/蒙版）合并后一次写
蒙版：MASK subject|background → MASKPARAM（LocalExposure2012 = EV/4，其余 = UI/100）
回读：逐键回读；回读 nil ≠ 没写（成片 XMP 复核）⇒ 以成片为准
失败：任一步回读不一致 ⇒ **中止并记账**，不许静默跳过
```

## 6 机理成熟度（决定"能不能一次算"）

| 机理 | 传递 | 状态 | 缺什么 |
|---|---|---|---|
| 全局曝光 | CIELAB Y 比（精确） | ✅ | — |
| 主体局部 | 18.7 L\*/档（n=2） | ✅ | 样本少，误差 ±10% |
| 背景压暗 | 18.7 近似 | ⚠ | 背景单独标定（n=0） |
| 曲线形状 | PCHIP 闭式 | ✅ | — |
| 曲线暗部 | 0.30 L\*/px | ✅ | — |
| Blacks | 0.15 L\*/点（−10 附近） | ✅ | 大位移递减 |
| 冷暖强度 | 0.18 b\*/点 | ✅ | — |
| Saturation | 0.221 C\*/点 | ✅ | — |
| 白平衡 | 无映射 | ⚠ | Lab→Temp/Tint 标定 |
| 肤色色相 | 无映射 | ⚠ | Lab→HSL 标定 |
| LocalHighlights | 无标定 | ❌ | **不许用**（−30 已废） |

**⚠/❌ 的机理只许"方向 + 一档步进"，不许算精确值**——这是 P2 的兜底，不是终态。

## 7 验收与账本（C 段）

```
测 ③（同一把尺子）→ 逐项报：在带内 / 出多少（相对带宽）
预测 vs 实测：逐图报（今天 ±50%）
账本：stem · light · band · cell · action · predicted · measured · delta_band · skipped_reason
验收页：①/③/大师样片并排，标出出带项
```

判"过/不过"只有人；"不过"按宪法 §3.3 归因，**本批不再导出**。

---

## 8 失效

| 情况 | 处置 |
|---|---|
| 批内异质（IQR > 卡带宽） | 报人拆批 |
| 条件格 n<30 | 只报，不动图级 |
| 无中性面 | WB 不做 |
| 脸内死白 | 回退，不硬提 |
| 冷暖与提脸同时要蒙版 | 二选一，记账 |
| 前向模型 ±50% | 动到带边即止 |
