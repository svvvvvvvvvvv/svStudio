# LR 设计

> 服从 `设计真源.md`。LR 做两件事：**A 定这一批的骨架（曲线形状 + 冷暖方向）· B 补每张的参差（曝光 / 颜色 / 关系）· C 验收**。

## 1 边界

| | A（批级） | B（图级） |
|---|---|---|
| 动 | 明暗层次（曲线形状）· 冷暖的**方向** | 曝光 · 脸÷背景 · 白端 · **颜色补差（肤色 Point Color / 冷暖落地）** |
| 不动 | 亮度（曲线保持 p50）· 逐图曝光 | 介质与颗粒（卷纸质感归引擎） |
| 蒙版 | 不用 | 用唯一那一组 |
| 判据 | 卡的不变量（关系/形状） | 条件形状 + 物理 + **每张自己的颜色残差** |

判据 = 用公式/规律算目标值；物理不可逆的用物理上限；**不设区间靶**。

## 2 A 段：批级

```
1 全批 ① 的测量 → 逐量取中位
2 每个量 vs 卡的关系/形状：能被公式算的算目标；算不出的只给方向 + 一档
3 输出 batch_grade：全批一条曲线 + 方向（颜色只给方向，幅度在 B 逐图落地）
```

| 项 | 做法 |
|---|---|
| 曲线 | 位置 = 全批分位中位；间距 = 卡的关系/形状；每锚点累计位移 ≤3 L\*；肩由卡 p95 上沿夹；补 0/100 端点；PCHIP；**保持 p50** |
| 肤色 C | 全批中位偏离卡的目标只记账（说明这批整体偏）；**落地在 B：每张按 C/L 关系残差动，主体蒙版内 Point Color，SatScale 动态算（cap ±0.2），③ 验** |
| 肤色 h | 只记目标；**不用 HSL**（Point Color 只按肤色范围选，不转色相） |
| 冷暖 | 方向（色相 45°/210° 成对）由 A 定；**幅度按每张偏离卡的目标在 B 落地，10 点一轮** |
| 白平衡 | 方向：a 偏 → Tint，b 偏 → Temp；K/Δuv 由 `color_math` 算（图级） |

曲线“保持 p50”是 A 不动亮度的唯一方式：两端可动，中间不平移，否则和 B 的曝光打架。
颜色对齐卡的目标；曲线不反折。**判据：每张图自己的残差**，不是全批中位 —— 中位会把个体抹平。

## 3 B 段：图级

```
1 光位（从 ① 判）：gap = bg.L_p90 − skin.L；dark = face_dark_share40
2 查条件形状：back / mid / front → 按这张卡的 face_over_bg 关系值缩放
3 决策：脸/背景谁低，动谁；只动一个
4 写 plan：{light, target, action, predicted}
```

| 情形 | 动谁 | 公式 |
|---|---|---|
| 脸÷背景 < 卡的目标 | 主体局部 | `EV = ev_for_l(L0, Lt)`；Lt = 卡的目标比值 × bg_p90 |
| 脸÷背景 < 卡的目标、脸已在目标内 | 背景压暗 | `ΔL_bg` 用 `ev_for_l` 换算 |
| 脸÷背景 > 卡的目标 | 主体局部压暗 | 同上，Lt = 卡的目标比值 × bg_p90 |
| 脸亮度偏 | 全局曝光 | `EV = ev_for_l(L0, Lt)`；Lt = 卡的目标 face_L |
| 脸 C/L 关系偏离卡 | 主体蒙版内 Point Color | `SatScale = clamp(C_card/L_card ÷ C0/L0 − 1, ±0.2)`，③ 验 |
| 冷暖偏离卡的目标 | SplitToning | 10 点一轮，色相成对 |
| 其余 | 不动 | — |

预测一律用精确式：`L' = 2^(EV/3)(L+16) − 16`；分位数与单调映射可交换。
局部曝光低段≈精确式，高段会压缩 ⇒ 大位移只当上限，不承诺落到目标。
预测出脸内死白或 p99 越白端 ⇒ 截断到白端/物理上限，记账“物理截断”。

**肤色 Point Color（B 图级）**：

```text
r0 = C0 / L0                       # ①/引擎片的测量
r* = card.face_C / card.face_L     # 卡的关系，不是绝对 C 靶
e  = r* / r0 - 1
SatScale = clamp(e, -0.2, +0.2)    # 0.1 = 一档；cap = 两档
```

- `MASK subject` + 该图 `skin_rgb` 的 `H/S/L`（`RangeAmount 0.5`）作为 Point Color swatch；
- 不用 `LocalSaturation`、不用 HSL；
- `|e| > 0.2` 时只给边界值，记账“余量归引擎/卡”，不硬补；
- 跑的是 **引擎输出的 `*_engine.tif`**，不是 final TIFF。

**白端**：p95 超过卡的肩部物理上限 ⇒ Whites **−10 UI**，③ 验。
**局部 Shadows**：只记账；要动 ⇒ 一档 10 UI + ③ 验。
**黑端**：由曲线趾部/引擎黑点负责，不用 Blacks。

## 4 冷暖

```
A：warm_cool_b 偏离卡的目标 ⇒ 方向 + 一档 10 点（两轮成对，色相 45/210）
B：需要蒙版的那张，把同一组值挂到蒙版；不需要就记账，不改全局
```

## 5 执行与回读

```
一份 XMP：A 的键 + B 的键合并后一次写
蒙版：MASK subject|background → MASKPARAM
      LocalExposure2012 = EV/4；其余 = UI/100
回读：逐键回读；回读 nil ≠ 没写（以成片 XMP 为准）
失败：任一步回读不一致 ⇒ 中止并记账，不许静默跳过
```

## 6 机理成熟度

| 机理 | 传递 | 口径 |
|---|---|---|
| 全局曝光 | CIELAB Y 比 | 精确 |
| 局部曝光 | `l_after_ev` | 低段精确，高段压缩 |
| 曲线 | PCHIP | 可算 |
| Blacks / 冷暖 / Point Color SatScale | 无公开传递函数；SatScale 只按相对饱和关系式 | 方向 + 一档；Point Color 用 C/L 关系式 |
| 局部 Shadows | 无公开传递函数 | 只记账；要动一档 10 UI |
| 肤色色相 | 不用 HSL；只记账 | 不做 |
| 点颜色 | `SatScale` 是相对饱和刻度，不是绝对 C | 动态 C/L 残差，cap ±0.2 |

## 7 验收

```
③ 成片 → 量 → 物理底线（防事故）+ 目检（脸优先）
物理底线破 ⇒ 先找漏：流程 / 引擎底片 / LR 剂量
质量差 ≠ 流程不通；不达标不许用“① 本身出区”放行
```

## 8 代码

```
photometry.py     L*↔Y↔EV↔sRGB 码
batch_grade.py    A 段：全批中位 → 一条曲线 + 颜色方向
lr_solve.py       B 段：曝光/局部/白端；没传递函数的一档
lr_exec.py        plan → LRPlan；Whites 接线
lrsink.py         XMP/桥执行
review.py         ③ 验收
```
