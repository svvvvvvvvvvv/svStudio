# 纪律

> **每次思考或动手前必读**。本文 = 纪律（唯一）；设计 = `设计真源.md`（唯一）。
> 冲突时：**纪律 > 设计 > 代码**。
> 优先级：**脸（主体）> 背景高光 > 其它**。任何一步把脸压暗就是做错。
> 换卷/换纸 = **人的决定**；让引擎改曝光或多留余量 = **越界**；
> 收白收不住 ⇒ **接受背景过曝**，不回引擎。

## 六条铁律

1. **不许打数值靶**。数值只用于：定位问题 / 卡物理边界 / 判过不过的门槛。
   阈值只能来自：**量化下限 · 物理不可逆 · 生理常识 · 大师实测区间**。
2. **不许为单张/单批打补丁**。参数只挂三层：**卷纸 · 场景类 · 意图**；
   代码里不许按 stem / 文件名 / "这批都欠曝" 分支。
3. **先查资料再定系数**。查四类：GitHub 实现 · 论坛/厂商文档 · 专利 · 论文。
   查不到就明说"没有公开闭式"，**不许编斜率**；只给方向 + 一档步进。
4. **不许乱跑**。LR 只在**出 ③ 成片**时驱动；引擎先试点 2 张；测量默认 10~30 张 + 看图。
   跑之前写**代价 + 预期**，跑完只做"预测 vs 实测"，不许当场改参数再跑。
5. **先出成片，再量，再目检**。①≠成片；五段走满：引擎出片 → LR ②③ → 导出 ③ → 量 ③ → 目检。
   目检一页 HTML、竖排占满宽、不拼网格；链接独占一行。
6. **分工不许越界**：
   | 层 | 只许管 | 不许碰 |
   |---|---|---|
   | 引擎 | 卷/纸/颗粒/光晕/柔光/自己的测光/报余量/白点 | 逐图曝光落点、明暗分布、颜色 |
   | LR | 看哪里、曝光落点、收白、曲线、饱和、肤色 | 卷纸质感、颗粒 |
   | 人 | 意图（亮/暖/浓/软）、审片 | 具体参数 |

两条硬边界：**引擎不管脸、不管落点**；**算值不依赖 LR**（公式可查、可离线复算）。

## 不达标怎么归因

只有一种结论：**流程或实现哪一段没做到**。
"场景没余量 / 素材不行 / 换纸 / 这张本来就过曝"只能是现象描述，不能是结论。
每条"不达标"后面必须写"漏在哪一段"。

## 每轮标准动作

```
1 设计对齐（不动代码/不跑/不谈参数）→ 2 写代码+单测（先钉判据）→
3 五段出片 → 4 量 ③（只定位，不宣布对错）→ 5 目检（先看图）→
6 不达标→找漏（回 1/2）→ 7 记账（只写真源）
```

## 谁有权改什么

| 类别 | 谁定 |
|---|---|
| 技术性（bug/工具/物理换算） | agent 直接改 |
| **参数值**（阈值/系数/步长） | agent 定，依据 = 调研 + 实测 |
| **方向/意图**（亮/暖/浓/软） | 人 |
| **审片**（好不好看） | 人 |
| 换卷/换纸 | 人 |

## LR 数值（先查资料，查不到才自标定）

```
① 单位换算（EV/4、UI/100、+1档=×2）      ⇒ 写死，注明定义
② 标准量换算（L*↔Y↔EV↔sRGB 码、分位数）  ⇒ 用定义式，禁止斜率乘档数
③ 有公开传递函数？                        ⇒ 用公式（目前没有一根 Basic 滑杆有）
④ 有成熟开源实现？                        ⇒ 先过本方小矩阵；不过只作参考
⑤ 只有 n<5 实测？                         ⇒ 进 LEDGER，只预测不剂量
⑥ 都没有？                                ⇒ 方向 + 一档（10 UI）+ ③ 验，记账
```

**判据**：代码里出现 `X L*/点` / `X L*/档` 的绝对系数，先问它是①~⑥哪一类；
答不上来就是⑥，不许写。分析模型只许放 `analysis/`，**生产不 import**。
