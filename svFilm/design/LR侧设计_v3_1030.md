## 1 对齐匹配卡：卡提供三组**约束**，不是三组目标

一套目录 = 一张卡。卡里 12 个带，按用途分三组：

### 1.1 三组约束

```
关系约束（比值，跨场景可移植）
  face_over_bg   [0.78, 0.92]     脸 ÷ 背景亮部      → ② 关系的上界
  person_over_bg [1.24, 2.21]     人 ÷ 背景中位      → ② 的交叉校验
  light_ratio    [0.92, 1.29]     光比              → 光位（只作旁证）

形状约束（曲线形状 —— "像不像那套片子"的主体）
  toe / shoulder / contrast_win / skew                → ③a 曲线的四个锚点
  p95 带                                              → ③a 肩部落点（唯一的绝对量，且只作肩部）

色彩约束
  neutral_axis                     中性轴 a/b         → ①颜色锚的校验
  hue_bands（六段）                各段色相偏移        → ④肤色的先验 + 分色修正
  face_C / face_h 带               肤色区间            → ④的可行域
  warm_cool_b [0.9, 18.3]          冷暖倾向            → ⑤分离强度
```

### 1.2 用法（三条规矩）

1. **出带才修，带内不动** —— 这不是打靶：带内的差异不排名、不优化。
2. **绝对落点不学**：`p50`/`clip` 的分布随"拍什么"变，不进约束；只有 `p95` 进肩部（因为肩部是介质特性）。
3. **卡必须显式记录**：作业单里写 `card` 名 + 选卡方式（人工/自动）+ 选它的理由。否则这张片子"对齐的是谁"无从追溯。

## 2 七步（③ 拆成 ③a / ③b）

每步都给：**输入 → 工具 → 公式 → 参数类型 → 失败判据**。

### ① 两种锚（亮度锚 + 颜色锚）

| | 亮度锚 | 颜色锚 |
|---|---|---|
| 工具 | `Whites` / `Blacks` | `WhiteBalance(Temp/Tint)` |
| 输入 | 死白比例、p1、主体 p99 | 中性面的 a\*/b\*、`neutral_axis` 带 |
| 公式 | `Blacks = −Δp1 / 0.15`（实测，上限 −20） | 有中性面 ⇒ 把 b\* 归到卡的中性轴；**无中性面 ⇒ 不做强修正，记账** |
| 类型 | 模型（锚定理论）+ 经验（0.15） | 定义（色彩恒常性）+ 经验 |
| 失败 | 死白>0 或 p1 回不去 | 无中性面却硬归零 |

★ 为什么锚排最前：感知先定"什么算白/什么算中性"，其余才有参照。**先提亮后收白，等于在错的锚上判断。**

### ② 关系（脸该多亮）

```
贴脸圈 < 脸  ⇒ 整幅一起亮（全局 Exposure）   ← 暗背景，关系不变
贴脸圈 > 脸  ⇒ 只提人（主体蒙版 LocalExposure）← 亮背景，别推背景
目标脸 L = R × 背景亮部     （R 来自 face_over_bg 带中点，是**风格**）
EV = log2(Y(目标) / Y(当前)) × 工具系数（局部 15.7/18.7）
```

- **类型**：模型（比率原则）+ 经验（工具系数）
- **失败判据**：脸与贴脸圈的差，比原片大 >10 格 ⇒ 割裂
- **上界**：`EV ≤ EV_max = (100 − 主体p99)/slope(主体p99)`（物理，白端之上无信息）

### ③a 形状（学卡的曲线形状）

```
锚点（L* 域）：p5→6 · p25→6+toe · p75→p25'+contrast_win · p95→min(..., p95带中点)
插值：PCHIP（单调，不反折）
```
- **类型**：模型（形状带）+ 定义（PCHIP 单调性）
- **失败**：曲线出现反折 / 肩部越过卡的 p95 上沿

### ③b 层次（补回被压扁的暗部）

```
r = (p50−p5)_后 / (p50−p5)_前       跨度压缩比
曲线暗部段斜率 × (1/r)               只动暗部段，中间段留给脸
```
- **类型**：模型（Weber 律）+ 经验（0.30 L*/像素）
- **失败**：跨度没回到 0.9，或脸 L 被改 >1 格

### ④ 肤色（区间约束，不是对齐卡数值）

```
HSL 橙色：Hue 拉回卡带（黄橙区间）；Saturation 补回提亮稀释的彩度
Luminance **不动**（亮度归 ②）
```
- **类型**：经验（记忆色，区间来自卡）
- **失败**：脸 L 变化 >1 格（动了不属于它的维度）

### ⑤ 分离（把环境推远）

```
背景蒙版 LocalExposure −   （压环境整体，不压死）
背景蒙版 LocalToning       （阴影推冷，强度来自 warm_cool_b 带）
背景蒙版 LocalSaturation − （背景降饱和）
```
- **类型**：模型（色彩对比）+ **风格**（强度无公式，必须显式）
- **失败**：脸 b\* 变 >2（说明污染了中间调 —— 只在用全局轮时会发生）

### ⑥ 收白（一次算，不迭代）

```
死白比例 > 0        ⇒ 物理救不回 ⇒ 回退 ②的提亮，记账
死白 = 0 且 有濒白  ⇒ LocalHighlights = −(濒白超出量)/0.18
```
- **类型**：定义/物理（白端无信息）+ 经验（0.18 b*/点→实为 p95 响应）
- **失败**：压完死白还在（说明该回退提亮）

### ⑦ 轮廓光校验（只校验，不动手）

```
rim_after / rim_before < 0.7  ⇒ 提亮吃掉了发丝亮边 ⇒ 回退提亮或减量
```
- **类型**：经验（实操口径"亮边还在就停"）
- **现状**：字段已有（`rim.bright_share`），**未接入**

## 3 求解结构：CSP，不是最优化

**结论：这里没有"最优解"，只有"可行解"。** 设计真源原话：域内不排名。

```
变量：EV · local_ev · 曲线4参数 · HSL橙2根 · 分级3根 · 收白1根
约束：三组带 + 物理边界（死白=0 / p1≥下限 / 滑杆量程）
目标：无
```

### 3.1 为什么可以顺序解（解耦表）

| 耦合对 | 耦合？ | 证据 | 解法 |
|---|---|---|---|
| 曝光 ↔ 白端 | 有 | 1307 提 1.09 即爆 | 先算 `EV_max` 当**上界**，不迭代 |
| 曲线暗部 ↔ 脸 | 无 | 曲线只压暗部段 | 顺序 |
| 分离 ↔ 肤色（全局轮） | **有** | 脸 b\* 漏 0.13/点 | 换**背景蒙版**（实测脸 ±0） |
| 收白 ↔ 脸（全局） | **有** | 脸 0.02/点 | 换**背景蒙版**（实测脸 ±0） |
| 提亮 ↔ 轮廓光 | 有 | 1608 rim 0.00 | ⑦ 校验 + 回退 |

**一句话**：只要每个旋钮的**作用域**（蒙版 / 亮度段）被正确限定，七步就是一串单变量闭式解。
需要联合优化，只发生在"两个旋钮作用域重叠且都无法限定"时——而我们的工具已经能限定，所以不需要。

### 3.2 反过来：什么时候真的需要联合

- 只能用全局 `Highlights`（没有背景蒙版可用）时：压背景必压脸 ⇒ 要联合
- 曲线同时承担"形状"和"层次"且互相拉扯时 ⇒ 所以 ③ 拆成 a/b

## 4 分工：主笔 vs 修补（不划地盘）

| | 主笔（引擎） | 修补（LR） |
|---|---|---|
| 做什么 | 介质、性格、质感、自己的测光 | **残差**、小优化 |
| 输入 | 卡（卷/纸） | **残差**（"差多少"），不是目标 |
| 颜色 | 定倾向 | **可以动颜色**（LR 的色彩能力强）——但只补残差 |
| 越界判据 | —— | LR 改的是"差"还是"目标"？改目标 ⇒ 越界 |

★ 这条判据可操作：**LR 任何时候都不该知道"卡的中点"，只该知道"现在差多少"**。
所以 §1 的"出带才修"在实现上就是：把带的**边界**给 LR，不给中点。

## 5 流程与五层职责

```
[引擎] ① 介质/性格/质感      → 不做逐图落点
   ↓
[测量] 关系量 + 物理量 + 形状量 + 卡记录
   ↓
[卡]   三组带（只给边界）
   ↓
[LR]   七步 CSP：读残差 → 闭式 → 写参 → 记账（不迭代、不回看）
   ↓
[验收] 在不在带内 + 有没有破物理边界（不排名）
   ↓
[人]   意图 + 目检
```

**数据契约（每层只读它该读的）**

| 层 | 只读 | 只写 |
|---|---|---|
| 测量 | ① 图 | 关系量、物理量、形状量 |
| 卡 | 目录统计 | 三组带（边界） |
| LR | 残差 + 带边界 | LR 参数 + 记账 |
| 验收 | ③ 图 + 带 | 判词（在/不在带内） |

## 6 缺口（按优先级）

| # | 缺口 | 影响 | 补法 |
|---|---|---|---|
| 1 | ③a 形状带未接（现在只"补跨度"） | 学不到卡的曲线性格 | 用 toe/shoulder/contrast_win 生成锚点（公式已有） |
| 2 | 色彩三带只接了 face_C/face_h | 冷暖、六段色相、中性轴全空 | ⑤ 用 warm_cool_b；① 用 neutral_axis |
| 3 | ⑦ 轮廓光校验未接 | 提亮吃亮边（1608 rim=0.00） | rim 前后比 <0.7 触发回退 |
| 4 | 卡选择未记录 | 追溯不了"对齐的是谁" | manifest 加 card + 选法 + 理由 |
| 5 | 中性面检测缺失 | 颜色锚不可信（C1 前提） | 测"低饱和中亮区"占比 |
| 6 | "看直方图不看中间点"未落 | 判据仍偏分位数 | 加直方图形态：削顶量、空隙、双峰 |
| 7 | 光照边缘检测缺失 | 理论预示"这类图易显假" | 需新测量（脸旁边缘的对比突变） |
| 8 | 主体 clip 与背景 clip 未分开统计 | 收白会压错对象 | 按掩膜分开统计死白/濒白 |
