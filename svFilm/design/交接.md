## 二、设计定死了什么（这些不要再动）

### 2.1 分工

```
引擎：卷/纸（风格）· 颗粒/光晕/柔光（质感）· 自己的测光出片 · 报告"还能抬几档"
LR  ：看哪里（脸→人→整幅）· 曝光落点 · 收白 · 曲线形状 · 颜色 · 局部肤色
```

**两条硬边界（都违反过，各挨过一次）**
1. **引擎不管脸、不管落点。** 为了"留余量"在引擎里按脸推曝光 = 把刚拆掉的搬回去。
2. **算值不依赖 LR。** 公式要能查、能离线复算；只有"出 ③ 成片"才驱动 LR。

### 2.2 判据只有「不变量 + 意图」，没有「该到多少」

```
T0 出片   p95 ≤ 93 ｜ clip < 0.5% ｜ p1 ≥ 1.0
T1/T2 终片 clip < 2.5% ｜ p1 ≥ 2.0
T3 白点   |a|,|b| ≤ 2（8-bit 量化下限 ~1）
T4 脸 L ∈ 55~85 ｜ T5 脸 C ≥ 10
S1 改色不改明暗 ｜ S2 改局部不动全局 ｜ S3 曲线每锚点 ≤3 L*
S5 一段顶到上限 = 上游错，不许用别的旋钮补
```

阈值只从**量化下限 / 物理不可逆 / 生理常识 / 大师实测区间**来，不从任何一批成片当靶。

### 2.3 三类卡（别混）

| 类 | 数量 | 有什么 | 用途 |
|---|---|---|---|
| **参照卡** | **64**（大师 62 套鹿井 + xhs + 滨田） | 只有画像（中位 + IQR） | "这批该像哪一套" |
| **生产卡** | 3（卡38 / xhs预设 / 滨田预设 —— 名字带"预设"，但它们是**卡**） | 有配方（卷/纸/质感档） | 能渲 |
| 意图 | — | 人给的 −1..+1 | 只改方向 |

匹配两步：① 64 张参照卡里找最像的一套 → ② 现有生产卡能不能做到那个像（`feasibility`）。

## 六点五、LR 侧的「以人为本」已补齐（2026-10-29 上午）

设计出处 §25~§29。四条规则 + 三条约束，原来只有 1 条真的做了：

| 规则 | 原来 | 现在 |
|---|---|---|
| H1 有脸用脸 | ✓ 做了 | ✓（读 `skin.L`，判据 `face_w_native ≥ 40`） |
| H2 降级链 | `person` 分支 `cur=None` ⇒ **直接返回 0 档**，静默弃权；判"有人"用 `env_share<0.95` | 人的亮度**测量层还没接** ⇒ 明确降级到整幅并写理由（不假装有 person 档）；整幅落点没有不变量 ⇒ 弃权也写明 |
| H3 白端保护 | 只截引擎余量 | **两道预算取小**：引擎余量 ∩ p95 到白平台；差多少记 `exposure_debt`，不硬顶 |
| H4 逆光识别 | **没写**（`light_ratio` 只在匹配里用） | `light_state()`：<1.0 逆光 / >1.3 顺光；逆光 ⇒"提脸 + 预备收白"，顺光脸仍低 ⇒"先查测光" |
| L1 脸是约束不是目标 | `target_L=72` 硬编码 ⇒ 事实上是个点靶 | 只在出 55~85 时动，目标是"刚进区 +1.5 L*" |
| L2 收白顺序 | `solve_highlights` 吃 **① 的 clip** ⇒ 先收白、后算曝光 | 新增 `expose.after_ev()` 算 ①'，**在 ①' 上判** |
| L3 逆光/顺光分别处理 | 无 | 同上 |

**新文件 `design/expose.py`**（纯算，不渲、不驱动 LR）：
- 分位/脸 L 平移：CIELAB 恒等 `dL*/dEV = 0.2310·(L+16)`
- 色相不变：线性增益让 a/b 等比 ⇒ 角度不动
- 爆白**下界**（不等式，不是模型）：`p95'≥100` ⇒ 至少 5% 到顶；`p99'≥100` ⇒ 至少 1%
- 超预算几档 = `ev − headroom`（引擎自己算好的"还能抬几档"）

**十张只算不渲跑一遍（`cli plan`）**：

```
脸出区 5/10（<55）    要 +0.37 ~ +1.48 档，全部被预算截断 ⇒ 记欠账
① 本身就爆 3/10       下界 3.4~6.4% ⇒ 引擎欠账，给政策收白 −35（标"待验收"）
脸在区内 5/10         曝光 0 档（L1：脸是约束不是目标）
```

⇒ 结论：**LR 侧"能做对的都做对了"，剩下的缺口只有一处 —— 引擎余量 0.00（9/10 张）。**
按设计 §32 步③，这不是 LR 能顶的（不达标 ⇒ 回引擎），所以它现在只能如实记账。

**单测 12 → 26 项**，新增的 14 项全部钉上面这些判据（`design/tests/test_design.py`）。

**还没做（诚实写）**：
