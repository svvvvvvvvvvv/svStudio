## 二、今天定死的判据（都有出处，别再改回拍脑袋）

### 2.1 光位：双区统计（不是亮度比）

```
gap  = 背景亮部 L_p90 − 脸 L
dark = 脸掩膜内 L ≤ 40 的像素占比（绝对暗，不是"低于中位"）
逆光 = dark ≥ 0.35 且 gap ≥ 12   或   gap ≥ 35
顺光 = dark ≤ 0.12 且 gap ≤ 12
其余 = unknown（宁可弃权，不许猜）
```

出处：专利 CN109815905B（亮区 vs 暗区）、CN102013006B（前景暗像素占比）、
论文 Tsai & Yeh IEEE TCE 2010（YIQ + 照明分析三分类）。

**明确写下来**：两版旧判据都出过反例——
- 旧「脸 ÷ 背景**中位**」：逆光时背景中位落在暗部 ⇒ 把 1608 判成顺光
- 「脸 vs 背景 p90」单独用：有天空时 p90≈天空 ⇒ 把 1307（脸被太阳直照）判成逆光

`cli run --light` 可以人工覆盖；默认 `auto`。

### 2.2 脸亮区：分光位两套

| 光位 | 区间 | 依据 |
|---|---|---|
| 逆光 | **45~70** | 目录卡逆光片脸 L 中位 50.4（P10~P90 = 42~58） |
| 顺光 / unknown | **55~85** | 原 T4（生理常识） |

逆光**不再额外 +4 L\***（那是基于"逆光脸偏暗要提亮"的错误假设，已归零）。

### 2.3 提亮分寸：由关系推算，不写死档位

```
目标脸 L = 背景亮部 L × R        R = 0.88（起点，从 SV 目检 0.7 档反推）
需要的档位 = 反算(目标 − 当前)   ⇒ 每张图自己算，背景越亮提得越多
```

依据：目录卡的**脸/背景亮部比值**分布 —— 逆光 0.55、unknown 0.79、顺光 0.96；
实操资料口径「脸提到比天空暗半档就停」。R=0.88 即"脸快追上背景"。

### 2.4 处理顺序（三份实操资料口径一致）

```
先救脸（只碰人，不碰天）→ 再压环境高光（收白，不许压脸）→ 最后补饱和
```
我们 ②→③→⑥ 的顺序与此一致。**提亮会把彩度稀释**（1608 C 21.6→16.5 @+1.5 档），
所以"提完补饱和"不是可选项。

三条硬事实：

2. **轮廓光是逆光的标志**（0.11 vs 顺光 0.02，差 5 倍）。

## 四、三段机制（现在的实现）

```
② 全局曝光   目标 = 下界 + 3.5（落点容差）  ← 只在出区时动
③ 收白       Highlights 阶梯：clip > 2.5% 就加；脸掉 > 1 L* 就退（脸优先）
⑥ 补脸       先 主体蒙版（LocalExposure）；退路是点颜色亮度（只动肤色）
仲裁：脸不够且 ⑥ 没推满 ⇒ **这一轮不动收白**，先让 ⑥ 补
```

- **④ 曲线**：不变量没破就不动（今天 0 张）。
- **⑤ 全局饱和 / ⑦ 色相微调**：仍未实现（缺判据，"什么算偏灰/偏色"没定）。

## 八、今天新增的坑（血泪）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| **`MASK people` 不落地** | `groups=0->0`，MASKPARAM 报 no mask | 用 **`subject`**（background 也可；sky 不新增组） |
| **LocalExposure2012 刻度** | 写 0.5 顶到脸 85（≈2 档），写 1.0 过曝到检不到脸 | **值 = EV ÷ 4**，量程 −1~+1 |
| **`--light` 没传进出片循环** | v5 里逆光被当顺光推到 +0.5（**整批作废**） | cli → run_lr / run_final / build_review 三处都要传 |
| **验收传 `auto` 直接比字符串** | 逆光 48.7 被自己的 T4 判红 | verify 内部要逐图 `light_state(rec_1, given='auto')` |
| **`M.load` 只留有皮肤的** | 没脸的图（1726）在验收页消失 | 验收用 `M.load_all` |
| **`glob('*.jpg')+glob('*.JPG')`** | Windows 不分大小写 ⇒ 每张算两遍、传两遍 | 只用一个模式 |
| **`sky_share` 是百分数、`env_share` 是比例** | 混用会算错（今天真乘错过） | 新代码用 `sky_share_frac` |
