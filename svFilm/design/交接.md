## 二、设计定死了什么（这些不要再动）

### 2.1 分工

```
引擎：卷/纸（风格）· 颗粒/光晕/柔光（质感）· 自己的测光出片 · 报告"还能抬几档"
LR  ：看哪里（脸→人→整幅）· 曝光落点 · 收白 · 曲线形状 · 颜色 · 局部肤色
```

**两条硬边界（都违反过，各挨过一次）**
1. **引擎不管脸、不管落点。** 为了"留余量"在引擎里按脸推曝光 = 把刚拆掉的搬回去。
2. **算值不依赖 LR。** 公式要能查、能离线复算；只有"出 ③ 成片"才驱动 LR。

### 2.2 判据只有「不变量 + 意图」，没有「该到多少」

```
T0 出片   p95 ≤ 93 ｜ clip < 0.5% ｜ p1 ≥ 1.0
T1/T2 终片 clip < 2.5% ｜ p1 ≥ 2.0
T3 白点   |a|,|b| ≤ 2（8-bit 量化下限 ~1）
T4 脸 L ∈ 55~85 ｜ T5 脸 C ≥ 10
S1 改色不改明暗 ｜ S2 改局部不动全局 ｜ S3 曲线每锚点 ≤3 L*
S5 一段顶到上限 = 上游错，不许用别的旋钮补
```

阈值只从**量化下限 / 物理不可逆 / 生理常识 / 大师实测区间**来，不从任何一批成片当靶。

### 2.3 三类卡（别混）

| 类 | 数量 | 有什么 | 用途 |
|---|---|---|---|
| **参照卡** | **64**（大师 62 套鹿井 + xhs + 滨田） | 只有画像（中位 + IQR） | "这批该像哪一套" |
| **生产卡** | 3（卡38 / xhs预设 / 滨田预设） | 有配方（卷/纸/质感档） | 能渲 |
| 意图 | — | 人给的 −1..+1 | 只改方向 |

匹配两步：① 64 张参照卡里找最像的一套 → ② 现有生产卡能不能做到那个像（`feasibility`）。

## 九、踩过的坑（写代码前先看这张表）

| 坑 | 现象 |
|---|---|
| `render_safe` 的 `p95_max` 是死参数 | 给 80 与 88 出同一张图（白端循环只有 3 次×1.15，不看目标值） |
| 曲线 16 点用均匀网格 | 高光锚点在 code 250/254，修正在 LUT 里被完全抹掉 |
| 锚点位移实测比规划大 | 规划 3.0 量到 3.14 ⇒ 规划预算改 2.7 |
| 意图被算两次 | 曝光和曲线各加了一次 |
| 拿自己出片的偏差当需求 | 拿缺陷当需求（循环论证） |
| 缺规格的卷被当成"最细" | verita 不在 `grain.toml` 里，rms=0 会被当成最细 |
| 曝光计划超过余量 | 会安静输出 +2.4 档的毁图计划 |
| 用 `_` 当元组解包变量又当过滤条件 | 过滤恒为真（Dmax/γ_blue 的 bug） |
| γ 的量程是绝对值 0.25~4.0 | 拿增量去比会误判越界 |
