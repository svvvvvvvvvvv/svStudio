## 2 根因（7 条，按危害排序）

### R1 拿统计量当感知量（同名不同义）

同一个词，测量里有好几个版本，我每次随手拿一个：

| 词 | 测量里的版本 | 我踩的坑 |
|---|---|---|
| **背景** | 中位 / 全局亮部 p90 / 贴脸圈 / 近场环带 | 用中位判光位 ⇒ 1608 判成顺光；用全局 p90 定脸 ⇒ 边缘割裂 |
| **爆白** | 整幅 clip / 主体 clip / 背景 clip / 死白 / 濒白 | 用整幅 clip ⇒ 收白压错对象（1307 是主体爆） |
| **脸** | 皮肤盘中位 / 脸掩膜中位 / 脸内分位 | 一直用"皮肤点"，当成"脸" |

**根因**：进判据之前没做**消歧**。

### R2 没先定义"作用域"，就讨论"给多少"

- 用 `Highlights`（全幅·高光段）去压背景 ⇒ 也压脸
- 用 `LocalExposure`（主体·全段）去提脸 ⇒ 连带白裙爆
- 用全局阴影轮做冷暖分离 ⇒ 脸被染冷 0.13/点

**根因**：LR 每根旋钮天生带**两个维度**（作用域 × 亮度段），我只想了一个。

### R3 判据不能区分"两种坏"

`clip < 2.5%` 无法区分"背景太亮"和"人已经削顶"——而这两者的解法完全相反（一个压、一个回退）。
**根因**：判据只量了"多少"，没量"在哪、可不可逆"。

### R4 遇到反例先加常数

`−30`（压高光）、`+25`（贴脸圈上限）、`2.5%`（clip 门槛）——都是被反例逼出来的常数。
**根因**：常数能立刻让数字变好看，而**找出机理更慢**。这是最短视的一条。

### R5 没有前向模型，只能跑 LR 试

今天 40+ 次导出，本质是"算不出来就只能试"。而铁律 4 明令不许拿 LR 当标定台。
**根因**：把"试"当成了正常工作方式，而不是失败信号。

### R6 设计只写结论，不写反例和失效条件

所以每次新情况都要重新想；同一个坑换个场景又成立。
**根因**：设计文档缺"失效清单"，导致它只能防已知情况。

### R7 没先分类片子就动手

1608 是"暗树荫前的人"，1627 是"亮背景前的人"，我用同一套参数处理。
**根因**：缺少"先分类、再选策略"的前置步骤。

## 3 变成当前设计的护栏（v3 → v3.1）

每条护栏都对应一个根因，且必须是**可检查的**，不能是口号。

### G1 量释义表（对 R1）

测量层每个字段必须写三件事：**代表什么感知 / 有几个同名版本 / 判据里用哪个**。
没写清楚的字段，**不许进判据**。

### G2 旋钮作用域强制表（对 R2）

每个旋钮在使用前必须填满两格：

| | 全段 | 高光 | 中间调 | 阴影 |
|---|---|---|---|---|
| 全幅 / 主体 / 背景 | ← 用哪一格 |

填不出 ⇒ 说明还没想清，不许写进计划。

### G3 判据二分性检查（对 R3）

任何判据必须能区分**两种不同的坏**，否则不许用：

```
clip  → 死白 / 濒白         （可逆性）
clip  → 主体 / 背景          （归属）
暗部  → 跨度压缩 / 黑点抬起  （层次 vs 锚）
```

### G4 常数登记簿（对 R4）

每个常数必须标注来源类别，四选一：
**量化下限 / 物理不可逆 / 生理常识 / 大师实测区间** —— 加一类"**工具刻度（需标定）**"。
**四类之外不许出现常数**；说不出类别的，就不许写。

### G5 前向模型优先（对 R5）

任何"跑一下看看"的动作视为违规。要跑之前必须先写**预测值**，跑完只做"预测 vs 实测"的对照。
（今天标定 40+ 次里，有一半是没写预测就开的。）

### G6 每条判据附反例（对 R6）

格式：
```
判据：脸与贴脸圈差 ≤ X
反例：1608 用局部提到差 46.7（X=25 时会被判违规，但那张本来就该少提）
失效条件：贴脸圈极暗且脸上有光斑时
```

### G7 先分类再处理（对 R7）

片子先过一道分类树，再进七步：

```
有脸？ ──否──→ 整幅策略（不做人像流程）
  │是
贴脸圈 < 脸？ ──是──→ 暗背景分支（全局提 + 关系保持）
  │否
  └──→ 亮背景分支（局部提 + 别推背景）
       │
       └─ 有中性面？ ──否──→ 颜色锚不可信，颜色只做保守修正
```

## 4 对当前设计（v3）的具体启发

1. **§1 的"三组约束"要加一列"这个量代表什么感知"** —— 否则又是 R1。
2. **§2 的七步要加"作用域"两格**（现在是自然语言描述，不够强制）。
3. **§6 的缺口清单要加"失效清单"** —— 不是"还没做"，而是"做了也会在这些情况下失效"。
4. **§7 的纪律对照要加两条**：常数登记（G4）、前向模型优先（G5）。
5. **流程最前面加分类树（G7）** —— 这是今天所有错误的共同前置缺失。

---

## 5 一句话总结

**今天的迭代不是"想漏了"，是"没有机制强制我想全"。**
七个根因里，五个的共同点是：**我用的判据能算出数，但算不出"这个数在讲哪件事"**。
所以护栏的核心不是"更聪明"，而是**在写判据之前先被迫回答三个问题**：
这个量代表什么？作用在谁身上？它能不能区分两种坏？
