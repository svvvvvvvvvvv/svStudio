# 测量设计（服从 `设计真源.md`）

> **宪法 = `设计真源.md`**。本文件只写"怎么量"，不写"该多少"；冲突时改本文件。
> 尺子只回答"是多少"，不回答"对不对"。

---

## 1 域与口径

| 项 | 规定 | 为什么 |
|---|---|---|
| 三态 | `①′` 基线渲染 · `①` 正式渲染 · `③` LR 后 | 每个旋钮只对着它作用之前那一态量 |
| 检测分辨率 | **1080** | 快；检测/掩膜只在这里做 |
| 统计分辨率 | **原生** | 缩小会压平两端，p1/p99/clip 系统性偏低 |
| 色彩 | CIELAB D65，16bit 输入 | 跨卡可比 |
| 肤色口径 | **FACE ∩ 皮肤似像素**（不画圆），取样点中位 | 圆盘会把背景算进肤色 |
| 量化下限 | u8 一个编码：L\* ≈ 0.4 · a/b ≈ 0.5 · C ≈ 0.2 | 小于一格不做决策 |

**同一个量只有一个定义、一处实现、一个 `measure_sha`。** 换了尺子 ⇒ 三态一起重测，不许只测一态。

## 2 字段（每个都要能回答：代表什么 / 有哪些同名版本 / 判据用哪个）

| 字段 | 代表什么 | 同名版本（易混） | 判据用哪个 |
|---|---|---|---|
| `skin.L/C/h/a/b` | 观众"看脸"的那个点 | 脸掩膜中位 / 脸内 p90 | 取样点中位 |
| `face_L_med` / `face_L_p90` | 整张脸的亮度分布 | 取样点 | **只报**，不进判据 |
| `face_dark_share40` | 脸内 L≤40 的占比 | 脸内暗部、`dark` | 光位判据的一半 |
| `rim.L_p50/p90` `rim.over_share` | **贴脸那一圈**的亮度与亮边 | 近场 ring、背景 | 轮廓只报；方向判据待用 |
| `rim.bright_share` | 环带里比脸亮一截的占比 | —— | **不判**（门槛跟着脸走，不独立） |
| `near_bg.L_p50/p90` | 整个人周围一圈 | 贴脸圈 / 全局背景 | 只报（"整幅该多亮"的参考） |
| `bg.L_p50/p90` `bg.b_p50` | 背景（含天空） | 贴脸圈 / 近场 | 关系的分母；冷暖 |
| `img.p5/p50/p95` `img.clip_pct` | 整幅分布 | 人 clip / 天空 clip | 形状与白端（整幅） |
| `person.clip_pct` | 人身上爆白 | 整幅 clip | 物理（死白归属） |
| `neutral.share/a/b` | 中性面 | `neutral_axis`（五段） | 有占比才算数 |
| `warm_cool_b` | 亮部 b − 暗部 b | 脸色温 / 背景 b | 冷暖层次 |
| `shape.toe/shoulder/contrast_win/skew` | 形状四项（p25−p5 等） | 曲线形状 | 明暗层次 |

★ 名字带域/单位：`_frac`（0–1）· `_pct`（百分数）· `_native`（原生像素）。历史上 `sky_share` 与 `env_share` 单位不同，被乘错过一次。

## 3 光位**不是**测量

测量只负责给原料，标签在求解层算（唯一一套，双区判据）：

```
gap  = bg.L_p90 − skin.L
dark = face_dark_share40
back  : gap ≥ 35，或（dark ≥ 0.35 且 gap ≥ 12）
front : dark ≤ 0.12 且 gap ≤ 12
其余   : mid
```

为什么不在测量层给标签：两套判据会给同一张图两个答案（1608：旧标签判 `front`，双区判 `back`），后面所有条件带都跟着错。

## 6 不测什么

| 不测 | 为什么 | 替代 |
|---|---|---|
| 颗粒 / 锐度的**绝对值** | 1080 复原不了 48µm 颗粒与 MTF50 | 高频只记档；**低频（bloom/halo/veil）另测**（§6.1） |
| 构图 / 被摄体 / 透视 | 不模仿内容 | 人看样片 |
| 光位标签 | 是判据不是测量 | 求解层算 |

### 6.1 质感分两类：**高频测不到，低频能测**

| 类 | 量 | 1080 上 | 用途 |
|---|---|---|---|
| **高频** | `grain`（平滑区高频残差）· `ratio` · `edge` | **测不到**（卡内 IQR ≈ 卡间 IQR，743 张实测） | 只记档，不能按卡对齐 |
| **低频** | `bloom` · `halo` · `veil` | **能测**（低频不被缩图抹掉） | 定柔光档 / 光晕 / 眩光 |

低频三量的量法：

```
bloom：取 p99+ 高光区，量 0.5% / 1% / 2% / 4% 画面宽的环带亮度，拟合衰减曲线
halo ：同一条曲线"降到一半"的距离 + 各通道差异（光晕带色）
veil ：高光附近暗部（同环带内的低分位）被抬了多少
```

- 只保证**相对排序**（同一把尺子、**同一长边**），不保证绝对值。空间族**没有跨链等价**（真实是记录、引擎是叠加），
  所以这些量只能给"方向"，参数值要在**引擎链**上标定后反解（见 `引擎设计.md` §7.5）。
- 高频三项：这一版**不用它按卡对齐**（实测无效；744 张：grain 卡内 0.55 vs 卡间 0.51）。
- 低频三项：可以给**方向与相对强度**（`引擎设计.md` §7.5）。

## 8 全量测大师：测什么 / 怎么测 / 给谁用

### 8.1 下游要什么（先列消费者，再定字段）

| 消费者 | 要的量 | 粒度 | 现状 |
|---|---|---|---|
| 匹配（候选） | 不变量层中位 / 分布 | 卡 | ✅ 有 |
| LR-A look | hero 样片 + 不变量带 | 卡 | 样片有，**hero 没指定** |
| LR-A 三保护 | `face_C/face_h` 带、饱和带、曲线 p50 | 卡 | ✅ 有 |
| LR-B 条件 | 光位 + `face_over_bg` / `face_L` | 图（模型级） | ✅ 部分 |
| 引擎-介质 | 色调 / 色偏量（批级预演用） | 卡 | ✅ 有 |
| **引擎-空间族** | **bloom / halo / veil** | 卡 | ❌ **缺** |
| 引擎-颗粒 | rms 公开规格 | 卷 | 查表，不测 |

⇒ **只缺"低频三量"和"hero 指定"**；其他字段已经够用，别重测。

### 8.2 口径与算法（一次说死）

```
核心：L* ≥ p99.5 的连通区（面积 ≥ 0.1% 画面），记 E_core、峰值 L_peak

bloom：外扩 0.5% / 1% / 2% / 4% 画面宽的环带 → Σ环带能量 ÷ E_core（L* 加权）
halo ：沿核心边缘的径向剖面，找降到 (L_peak + 背景)/2 的距离（占画面宽）；
       R/G/B 分开 → 顺带出"光晕带色"
veil ：核心外 2–5% 环带的 p10 亮度 − 远场暗部 p10（ΔL*）
```

### 8.3 怎么测（方法）

```
域   ：原生分辨率（低频不缩图）；①②③ 同一把尺子 sha
抽样 ：每卡 ≥3 张（光位不同）；全卡测一遍，取中位 + IQR
复现 ：同图连测 5 次，离散 ≤ 量化下限，否则先修尺子
失败 ：bloom 三点非单调 / 找不到半程 / veil < 0 ⇒ 该图弃用并记账
盲   ：测的时候不看卡名（防挑选偏差）
```

### 8.4 数据契约（新增字段）

```
每图：texture_lowfreq = {bloom, halo_r, halo_g, halo_b, veil}
卡级：中位 + IQR + n；与现有字段同一个 json，版本号 +1
```

### 8.5 不测什么

```
颗粒（无跨链等价，原扫描件也救不了）· 绝对亮度落点（场景相关）· 构图 / 内容
```

### 8.6 按最新设计，引擎侧 / LR 侧各要什么

```
引擎：film/print（批级预演）· format（卡来源事实）· amount（待标定）
      bloom/halo/veil（卡的低频纹理）· grain（卷规格）· glare.percent（来自 veil）
LR  ：不变量带（contrast / shape / face_C / face_h / warm_cool）· hero 样片
      条件表（光位 → face_over_bg）· 人/背景分计 clip（仍缺）
```
