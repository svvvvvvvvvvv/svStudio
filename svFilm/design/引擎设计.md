# 引擎设计（服从 `设计真源.md`）

> **宪法 = `设计真源.md`**。本文件只写介质级"怎么做"；冲突时改本文件。
> 引擎只管**材质签名**：卷/纸、颗粒、光晕、锐度、化学曲线、自己的测光。

---

## 1 职责边界

| 管 | 不管 |
|---|---|
| 介质（卷/纸/画幅）· 质感（颗粒/光晕/柔光/锐度）· 化学曲线 · 自己的测光 · 白点 | 逐图亮度落点 · 白端求解 · 颜色分级 · 冷暖 · 构图 |

**"回引擎"只有两层意思**：换卷/换纸（人的决定）；让引擎多留余量（**越界，禁止**——余量是产物，不是目标）。

---

## 2 输入与两种渲染

```
输入：相机原片目录（RAF/JPG，未经外部调色）+ 卡（→ 语料 → 介质）+ 人确认的批边界
①′ 基线渲染：用基线介质渲全批，**只为匹配**（把原片送进成片域）
①  正式渲染：人拍板卡之后，用**卡的介质**重渲；与基线同介质可复用 ①′
```

## 4 参数组（谁定、什么单位、什么约束）

| 键 | 管什么 | 单位 / 约束 | 谁定 |
|---|---|---|---|
| `simulation.film_stock` / `print_paper` | 卷 / 纸 | 枚举 | **人**（换风格） |
| `simulation.film_format_mm` | 画幅**长边** | mm（70 vs 36 ⇒ σ_px ×0.514） | 人 |
| `simulation.scan_unsharp_mask` | 中频对比 | `(σ_px, amount)`，σ 是**像素**、不缩放 | agent（跟出图长边绑定） |
| `grain.rms_granularity` | 颗粒（48µm 孔径） | 建议值 24（鹿井） | agent |
| `grain.blur_dye_clouds_um` | 染料云 | µm，2.0（鹿井） | agent |
| `halation.strength/sigma` | 高光渗色 | 2.5 / 0.8 / σ75 | agent |
| `camera.lens_blur_um` · `*.diffusion_filter` | 光学柔 | µm / BPM | agent |
| `scanner.black_level/white_level` · `lc` | 黑白端 | `lc` 默认 off | agent |
| `couplers.amount` | 彩度分配 | 鹿井 1.00 / 滨田 0.65 / xhs 1.20 | 人（换风格级） |
| `film_chemistry.gamma_factor_{rgb}` | 色相配比 | 3 元组 | agent（实测方向） |
| `export` | 交付规格 | 长边 / jpeg / px_ref | agent |
| `wb` | 色温 | 每条预设一个值 | 人（换风格级） |

**换卷 / 换纸 = 大动作**：动 4 组 couplers γ + halation σ/strength，还强制 `scan_film` ⇒ 下面两层全部重解。

## 5 测光

```
三主叠加：camera.auto_exposure(主体) · enlarger.normalize_print_exposure(18.4% 中灰) · 我们的 pe
锚 0.184 写死 ⇒ 不读图 ⇒ 不振荡
外部**不许**再乘 EV / PE（那就是手册里的振荡路径）
```

引擎的测光只保证：**余量一致、不剪死**。逐图落点不归它。

---

## 6 物理底线（引擎自己的，不是卡的带）

```
p1 ≥ 1（不堵黑）
不出现结构性剪死（clip 恒为 0 时要注意：天花 <100 会把 clip 结构性地压成 0，必须显式标"余量不可信"）
```

## 7 质感对齐（目的 2 的核心，当前缺输入）

### 7.1 现状

卡里**没有质感量** ⇒ 只能按语料取预设值，记账"未对齐"。这是目的 2 唯一的硬缺口。

### 7.2 目标：在**成片域**（大师扫描件）量三个量

| 量 | 怎么量 | 反推到哪个参数 |
|---|---|---|
| 颗粒中频能量 | 高通后取中频段功率（原生分辨率） | `grain.rms_granularity` · `blur_dye_clouds_um` |
| 锐度 | MTF50（刀边或斜边法） | `scan_unsharp_mask` 的 `(σ, amount)` |
| 光晕 | 高光边缘的亮度衰减半径 | `halation.strength/sigma` |

★ **不比引擎内部数值**：颗粒/锐度的空间族没有跨链等价，只在"扫描件 → 扫描件"这一域里比。

### 7.3 判据

```
先看：三量与卡的差是否在测量复现性以内（不在 ⇒ 才算差）
再看：目检（像不像这张卡的质感）
```

## 9 失效与坑

| 情况 | 后果 | 处置 |
|---|---|---|
| `print_render.glare` | 永不可复现（numba RNG） | 同参两渲取差前先关 glare |
| `film_format_mm` | 改画幅 ⇒ σ_px 等比变 | 颗粒/锐化参数跟着换算 |
| `run_shards` | 不可靠 | 逐张直调或手分片 |
| Windows `glob('*.jpg')` + `'*.JPG'` | 不分大小写，双计数 | 小写后缀过滤一次 + set 去重 |
| 中文标签 | PIL 默认字体没汉字 | 走 `_lib.label.text()` |
| 天花 <100 | `clip` 结构性恒 0 | sidecar 标 `valid/why` |
