# 引擎设计（服从 `设计真源.md`）

> **宪法 = `设计真源.md`**。本文件只写介质级"怎么做"；冲突时改本文件。
> 引擎只管**材质签名**：卷/纸、颗粒、光晕、锐度、化学曲线、自己的测光。

---

## 1 职责边界

| 管 | 不管 |
|---|---|
| 介质（卷/纸/画幅）· 质感（颗粒/光晕/柔光/锐度）· 化学曲线 · 自己的曝光落点（PE）· 白点 | 逐图曲线 · 白端求解 · 颜色分级 · 冷暖 · 构图 |

**"回引擎"只有两层意思**：换卷/换纸（人的决定）；让引擎多留余量（余量是产物，不是目标）。

---

## 2 输入与渲染

```
输入：相机原片目录（RAF/JPG，未经外部调色）+ 卡 + 人确认的批边界 + peer target
① 正式出片：人选卡之后，用 §3 这个目录的介质 + 逐图 PE（锚脸求根）渲出
不再有 ①′ 基线；匹配 A 用机内 JPG；引擎**读脸**（渲出来再量，见 §5）
```

## 3 介质（按目录算；人只选卡）

**每个目录（卡）一份介质**，从引擎 profile / 参数面 + 这张卡的目标值推：

```
卷     ← 卡暗部色偏轴 → 引擎中性滤片数据库里最近的卷（推导，不是唯一解）
纸     ← 卷的 target_print + 纸的 Dmax / 形状（分位匹配）
amount ← 这张卡的脸 C（点值，不用带中点）/ 同语料中位 × 语料标定值（夹边界）
PE     ← 卡上一个 nominal（18.4% 参考灰 → L*50；按介质，不按卡的 p50 反解）
         ★ 2026-11-04：卡的 pe 只作起点；逐图 PE **锚脸求根**（§5）：
            标定表 = 36 级灰阶 ramp，PE 七档 [0.0625..4]，log2 PE 上 PCHIP；
            渲一版（同成品尺寸）→ 量脸 → 割线求根 → 取最近的一版作 ①；
            ≤3 次渲染；不可达/检不到脸落到状态，不中止整批。
空间族 ← 固定值（柔光/光晕/眩光；验收可调）
滤片   ← 中性轴 → CC → simulation.print_y / m_filter_shift
产物：analysis/corpus/kurai/cards/<card>.json 的 `medium` / `pe` 字段；渲染只吃这一份
```

不再"候选 × 本批代表图 → 渲 → 量 → 最近者"；那是把介质当匹配结果，不是从卡推。
匹配 A 用机内 JPG；选卡后按本目录介质 + peer target + 逐图 PE 渲一次 ①。
10-19 的"留一图不稳"是针对"给大师挑身份"；现在是从卡推，不是渲染试。

### 3.1 介质事实：从作者 profile 读，不靠试

| 事实 | 从哪读 | 用来定什么 |
|---|---|---|
| **配对** | 每个卷的 `info.target_print` | 卷 → 纸（Kodak 卷 → Portra Endura；Fuji 卷 → CAII） |
| **纸反差** | 纸 profile 的密度曲线 γ（实测 2.61–3.72） | 印相反差：Portra Endura 最软、Ultra Endura 最硬 |
| **光晕** | `(use, antihalation)` → `_HALATION_PRESETS` | 强 AH = 0.015 / 弱 AH = 0.08（消费卷全是 weak） |
| **颗粒** | `grain.toml` 的公开 rms | 颗粒粗细（按卷查表） |
| **色平衡** | `neutral_print_filters.json`（纸, 光源, 卷） | 中性滤片 C/M/Y |

**读不出来的只有一件事：色彩性格**——肤色 h/C 怎么渲是光谱仿真，只有引擎自己算得出来。
所以能力的边界是：

```
可读事实：配对 / 纸反差 / 光晕 / 颗粒  → 查表，能给**方向与排序**
色彩性格：从 profile 的 log_sensitivity / 中性滤片数据库推方向；不跑渲染试
合起来：到"方向"为止，到不了"名次"（留一图不稳就是证据）
```

## 4 参数组（谁定、什么单位、什么约束）

| 键 | 管什么 | 单位 / 约束 | 谁定 |
|---|---|---|---|
| `simulation.film_stock` / `print_paper` | 卷 / 纸 | 枚举 | **目录介质**（§3；人只选卡） |
| `simulation.film_format_mm` | 画幅**长边** | mm（70 vs 36 ⇒ σ_px ×0.514） | 卡的来源事实 |
| `simulation.scan_unsharp_mask` | 中频对比 | `(σ_px, amount)`，σ 是**像素**、不缩放 | 引擎默认 + 记账 |
| `grain.rms_granularity` | 颗粒（48µm 孔径） | 按卷的公开规格 | **不能匹配**（1080 测不到） |
| `grain.blur_dye_clouds_um` | 染料云 | µm | 引擎默认 + 记账 |
| `halation.strength/sigma` | 高光渗色 | 按卷表 | 引擎默认 + 记账 |
| `camera.lens_blur_um` · `*.diffusion_filter` | 光学柔 | µm / BPM | 引擎默认 + 记账 |
| `scanner.black_level/white_level` · `lc` | 黑白端 | `lc` 默认 off | agent（物理约束） |
| `couplers.amount` | 彩度分配 | 无量纲 | **每目录按卡算**（§3） |
| `film_chemistry.gamma_factor_{rgb}` | 色相配比 | 3 元组 | **每目录按卡算**（§3） |
| `export` | 交付规格 | 长边 / jpeg / px_ref | 人 |
| `wb` | 目录级 custom（temperature/tint） | 引擎解码层 | 预设/同光值（不是成片 CCT） |

**换卷 / 换纸 = 大动作**：动 4 组 couplers γ + halation σ/strength，还强制 `scan_film` ⇒ 下面两层全部重解。

### 4.2 参数从哪来：作者已经用 `digest_params()` 组装好了

**不要自己重写组装逻辑**。作者的 `runtime/params_builder.py` 就是干这个的：

```
init_params(film, print)      → 两个 Profile + 各段默认
digest_params(params)         → ① 查中性滤片表 ② 按 (use, antihalation) 上光晕档
                                ③ 按 film.type 上 couplers γ ④ 每卷的覆盖项
                                （之后 pipeline 再按长边缩放像素键）
```

所以引擎求解 = **给 `init_params` 一对 Profile + 一个卡向量**，其余交给作者的 digest。

| 组 | 参数 | 来源 |
|---|---|---|
| 底片 / 相纸 | `film` · `print` | **卡 → 目录介质**（§3） |
| 画幅 | `camera.film_format_mm` | 卡的来源事实（35 / 70） |
| 中性滤片 | `enlarger.y/m_filter_neutral` | **profile 数据**：`neutral_print_filters`（纸 × 卷 × 光源） |
| 光晕 | `halation.strength / first_sigma_um` | **profile**：`(use, antihalation)` 内置档（强 0.015 / 弱 0.08） |
| 颗粒 | `grain.*`（dev 是 `rms_granularity`） | **卷的公开规格**（`grain.toml`） |
| 耦合 γ | `dir_couplers.gamma_*` | **`film.type`**（负片/正片）+ 每卷覆盖 |
| 饱和度 | `dir_couplers.amount` | 卡的脸 C / 同语料中位 × 标定值（§3） |
| **柔光** | `camera/enlarger.diffusion_filter` | **固定值**（相机端 BPM 1/4 黑柔；印放端关；验收可调） |
| **眩光** | `print_render.glare.*` | **固定值** percent 0.03；生产**开**，只在取差对照时关 |
| 锐化 | `scanner.unsharp_mask` | 像素键：按出图长边缩放 |
| 扫描端点 | `scanner.white/black_level` | 常量 0.98 / 0.01 |
| 颜色管理 | `io.*` | 常量：ProPhoto → sRGB，gamut compress 开 |

### 4.3 卡向量 = 引擎求解的**全部输入**

```
必填：film · print · format_mm · amount（由 §3 从卡推出）
空间族：固定值（不按卡量；验收可调）
风格开关：preflash（默认 0；卡上测不到，人可开）
```

**逻辑词只有一个**：`init_params(film, print)` → 填卡向量 → `digest_params()` → 渲。
别的参数**没有一个是"求解"出来的**——要么 profile 里有，要么是物理常量。

### 4.4 像素键与出图尺寸（一条不能含糊的）

```
像素键：grain.blur · scan_unsharp_sigma · lens_blur · scan_lens_blur · grain 的团径
引擎按 REF_LONG_SIDE = 6264 定义，出图时 ×（实际长边 / 6264）
```

所以**"渲多大"会改变成品**，两条路只能选一条：

| 路 | 做法 | 代价 |
|---|---|---|
| **A（默认）** | 直接按**交付尺寸**渲（1080） | 与大师同尺寸、同生产方式；大图要另渲 |
| B | 大图渲（2048+）再缩 | **必须"渲→缩"整条链一起标定**；否则锐度/颗粒与 A 不同 |

规则：

```
① 生产默认走 A：交付尺寸 = 1080，和大师同域
② 要出大图（打印）⇒ ① 也必须在那个尺寸出，且**对照的大师件要按同一条链降采样**
   拿不到同链降采样的对照 ⇒ 高频（锐度/局部对比）只当线索
③ 空间族用固定值 ⇒ 不做逐卡标定；换出图链时只需确认固定档在成品里成立
④ film_format_mm 也会改 σ_px（36→70 时 ×0.514）——换画幅等于换一条链
```

## 5 曝光（整幅直方图对齐 + 交接契约）

> 2026-11-04 重写（第二版）。第一版锚脸，**作废**：PE 是**全局曝光**，锚脸会把整幅抬起来；
> 脸由 LR 的局部提亮兜底，裙子由人物蒙版压高光兜底，所以引擎应该对齐**整幅直方图**。
> 更早那版"解整幅 p50 → peer 组中位"同样作废（单根分位会被背景面积带走）。

### 5.1 目标

```
target = 这一张 peer 的**五分位**（p5 / p25 / p50 / p75 / p95）
         · peer = 同光位（front/side/back/dappled）里距离最近的一张（**只取一张**）
         · 没有同光位 peer ⇒ 常数分布（746 张大师片的中位：
           p5 8.2 / p25 21.8 / p50 51.8 / p75 75.7 / p95 91.0）

为什么对齐整幅：PE 是全局曝光，一动整幅都动；脸、裙子、肤色由 LR 兜底。
         单锚中位会被背景面积带走（高反差场景把脸抬到 90+）；
         单锚脸又会把整幅抬亮、暗部一起发灰。两者都被实测证伪。
```

### 5.2 求解（渲了再量，最小化直方图距离）

```
目标函数：d(PE) = Σ |q_i(渲出来) − q_i(peer)|，i = p5,p25,p50,p75,p95      （L1）
① 起点：按 peer 五分位解一个 PE₀（表算，只用来定方向）
② 渲一版（与成品同尺寸）+ 同一套 measure_all 量整幅分位
③ 往目标方向探 0.7 档再量一次；两点定方向后用抛物线插值定第三点
④ 取 d 最小的那一版作 ①（≤3 次渲染）
```

- **L1 而不是 L2**：五根分位一起说话，但不让某一根尾巴把整体拖走
  （= 离散 Wasserstein-1，比"只对中位"或"只对脸"都稳）；
- **不从 RAW 推**：曝光表是中性色卡标的，脸是彩色，直接投影有 5~30 L* 误差；
- **不做小图代理**：480 上脸宽常低于测量层的 80px 门，会切到另一档口径；
- **不用 skin.L 当控制量**：它顶到肩部后不再随曝光变化。

### 5.3 状态机（梯子，每级都是通用规则）

| 级 | 触发 | 动作 | status |
|---|---|---|---|
| 1 | 正常 | 三点求根 | `ok` |
| 2 | 三次都没把 d 降下来 | 已测点里取 d 最小 | `face_unreachable` |
| 3 | 某次探测检不到脸 | 不影响：本版**不读脸**，照常量分位 | `ok` |
| 4 | 起点就测不到整幅分位 | 用 peer 直方图的 PE 出片 | `fallback_hist` |
| 5 | 皮肤 p99 ≥ 99 | 交给 LR 的 Highlights，不改 PE | `ok` |

**每张一定落到一个状态 + 一个 PE，整批永不中止。**

### 5.4 标定表

```
36 级灰阶 ramp（log2 输入 −0.07 ~ −11.75），7 个 PE 档 [0.0625,0.125,0.25,0.5,1,2,4]
→ input_luminance × PE → output_L*；在 log2(PE) 上 PCHIP 插值
```

旧版（ColorChecker + 21 级楔子）作废：楔子暗端只到 y=0.0148（−3.6 EV），
20 张里 12 张的中位落在它下面 ⇒ p50_pred 全部塌到楔子底、7 张解出同一个 PE。

### 5.5 交接契约（给 LR）

```
_render.json / <stem>_exposure.json：
  pe · status · q_peer（五根靶）· q_render（五根实测）· hist_dist（L1 距离）
  face_mid（诊断，不再是靶）· face_gap（诊断，LR 局部提亮用它估余量）
  shadow_gap = 渲出来的 p5 − peer 的 p5   ← 引擎补不了，交给 LR 的曲线
  clip_skin · frame_q · face_q
```

`hist_dist` 是这版的"做得像不像"的总分（L1，越小越像）；
`shadow_gap` / `face_gap` 是两个方向的具体残差，分别交给**曲线**和**局部提亮**。

### 5.6 不做

- 不重算全局 EV（LR 侧 EV 恒 0）；
- 不针对脸/裙子做全局补偿（那是 LR 的局部活）；
- 不为单张照片加特判（任何新情况必须落进 5.3 的某一级）。

## 7 卡 → 质感（"引擎匹配卡"到底能做什么）

### 7.1 能做：两件事

**① 介质：目录介质（§3）**

介质**不写进卡**，由 §3 从这张卡的目标值推出来（卷/纸/amount/PE/滤片）。

```
texture 的离散档（柔光/染料云/颗粒倍率）用**固定值**（§7.5），不用卡字段
```

**② 相对质感阶梯：实测不可行（`texture_stats.py`）**

743 张 / 62 卡，三个量都测了：

| 量 | 卡间 IQR | 卡内 IQR 中位 | 结论 |
|---|---|---|---|
| `grain` | 0.512 | **0.546** | 卡内 ≥ 卡间 |
| `ratio` | 0.065 | **0.064** | 一样大 |
| `edge` | 2.367 | **2.497** | 卡内更大 |

⇒ **成片域测不出"卡级质感"，连排序都不成立。** 不是尺子不够精：1080 网络图里，
每张图自己的内容差异（景深、光线、压缩）已经盖过卡与卡之间的差异。

### 7.2 结论：质感只能走**方向 + 引擎链标定**

手册 §四写死了：**空间族（颗粒/柔光/halation）没有跨链等价**——
真实胶片是"记录进去的"，引擎是"后期叠上去的"，**"对上去"本身没有定义**（`引擎手册.md` §四）。
器材值也不能移植：他的 Pro-Mist 1/8 是在他的镜头+他的胶片上，同档参数在数码图上**效果不等价**。

```
能做的：① 从成片量出**方向**（更糊/更晕/更纱）
        ② 在**引擎这条链**上标定「参数 → 同一个量」，再反解到参数
```

### 7.3 执行通道

```
可覆盖（运行时属性）：film_render.grain.rms_granularity ·
                     film_render.grain.blur_dye_clouds_um ·
                     film_render.halation.* · diffusion · mult_usm
不可覆盖（构建时）：  film_stock / print_paper / film_format_mm   ← 换 = 换预设
```

★ `grain.blur` 默认**不动**（它会糊整张密度场：梯度 p90 掉到 0.58）。

### 7.4 判据

```
脸的 face_mid = peer 的 face_mid（§5；唯一曝光判据）
+ 介质与卡一致（目录介质，§3）
+ 颗粒 = 卷的 rms 规格（§7.6）；柔光/光晕/眩光用固定值（§7.5；验收可调）
+ 目检（像不像这张卡的质感）
```

★ 不剪死/死白/p1 只报事实（出片后诊断），不挡曝光、不自动改 PE。

★ 不再有"相对阶梯方向对"这一条——成片域测不出卡级质感（§7.1）；颗粒按卷规格（§7.6），柔光/眩光是固定值（§7.5）。

### 7.5 柔光 / 眩光 / 光晕：**固定值**（不按卡量；验收时可调）

```
相机柔光 BPM 1/4 + 印放柔光 BPM 1/8
光晕：按卷的 AH 档（profile 给，不逐卡）
眩光：percent 0.03（固定）
```

**为什么不做逐卡反解**：空间族没有跨链等价，逐卡量出来的"方向"也不稳；
与其假装在匹配，不如**固定一套，验收时人可调**。反解公式与 3 点标定表**作废**（git 历史留档）。

代码里的物理含义（读源码；调值时参考，不做反解）：

| 效果 | 源码 | 物理形式 |
|---|---|---|
| 柔光 | `model/diffusion.py` | **能量守恒**：把 `p_s` 比例的光子散射进 core/halo/bloom；`p_s = f(档位) × 家族增益`（BPM 0.75 / pro_mist 1.05 / cinebloom 1.00）；档位 `[1/8,1/4,1/2,1,2]` → `p_s=[0.10,0.20,0.35,0.55,0.75]` |
| 眩光 | `model/glare.py` | **加性**：`xyz += glare × illuminant`；`glare ~ lognormal(percent, roughness)` 再模糊，`/100` |
| 光晕 | `model/halation.py` | 加性高斯（片基背反射）：`strength` 与 `sigma_um` |

★ **BPM 的"压黑"不是吸光**（源码注释：散射增益低 + bloom 权重小）。
★ **glare 生产要开**：不可复现只影响"同参两渲取差"（max|Δ|=22 码），不影响一次出片。
★ halation 是带色的（G 核收窄到 0.45σ_R）⇒ 调它要同时看肤色 / 中性轴。

**验收界面必须写一句**：*柔光 / 光晕 / 眩光可在验收时重新调整*（调完记账，不回头改卡）。

### 7.6 颗粒：按**卷的公开规格**，不按卡测

- `grain.rms_granularity` 是 **ISO 6328** 的规格（σ_D×1000，48 µm 孔径、净密度 1.0），量程 4–44；`a₁ ∝ rms²`（`model/grain.py:44-59`）。
- `particle_area_um2` 是**已删除字段**：`grain.py` 从不读它，`GrainParams` 无 `__slots__` ⇒ 写旧名**不报错也没人读**。medium 里写它等于没写。
- 介质按**卷**从作者数据 `data/presets/grain.toml` 读 rms（Ektar 100 = 4 / Portra 800 = 6 / Portra 800 push2 = 9 / Vision3 500T 等），**不是按卡从成片反解**。换卷 = 换 rms；不要拿 rms 当风格旋钮微调单张/单卡。
- 大师成片 1080 上的颗粒量只做**诊断**（`amp/acf1/coarse_px/ratio/edge`）：交付物功率谱陡降来自 `grain.blur`（扫描/压缩 PSF），不是乳剂颗粒（§四）。实测 765 张：
  - `amp` 卡间 IQR ≈ 卡内 IQR（比 1.00）⇒ 不能当卡目标；
  - `coarse_px` 卡间/卡内 ≈ 2.53，但那是同一批卡的扫描/内容差异，不能反解成 rms。
- 引擎链标定只用于**验证**：同介质改 rms，`amp` 1.88（rms 4）→ 3.43（rms 30），动态范围 72%；`coarse_px` 反而略降（1080 上引擎颗粒接近白噪声，lag-1 自相关为负）⇒ **“粗细”在 1080 成片上不可反解**。
- 结论：颗粒的唯一可执行目标是**卷的 rms 规格**；成片颗粒测量只回答“我们的颗粒比大师强/弱”，不改参数。

## 9 失效与坑

| 情况 | 后果 | 处置 |
|---|---|---|
| `print_render.glare` | 永不可复现（numba RNG） | 同参两渲取差前先关 glare |
| `film_format_mm` | 改画幅 ⇒ σ_px 等比变 | 颗粒/锐化参数跟着换算 |
| `run_shards` | 不可靠 | 逐张直调或手分片 |
| Windows `glob('*.jpg')` + `'*.JPG'` | 不分大小写，双计数 | 小写后缀过滤一次 + set 去重 |
| 中文标签 | PIL 默认字体没汉字 | 走 `_lib.label.text()` |
| 天花 <100 | `clip` 结构性恒 0 | sidecar 标 `valid/why` |
| 色卡标定缺失 | 没有 `input_luminance × PE → output_L*` 表 | 停；不允许退回脸测光 |
| 同光位 peer 一张都没有 | 没有 per-peer 靶 | 常数靶 face_mid=60.3，status=constant |
| 起点或探测检不到脸 | 量不到 | 找有效域再求根；全找不到 → fallback_hist |
| 两点无响应 | 靶在射程外 | status=face_unreachable，取最近点 |
| 皮肤 p99 ≥ 99 | 打爆不可逆 | status=clip_limited，交给 LR 的 Highlights |
| PE hit_bound | 卡/场与 target 不匹配 | 报“卡/场不匹配”，换卡或拆批 |
| 整帖拼图当 peer | p50 是整个拼图的 | 排除 `01-05.jpg` 这类整帖图 |
