# 卷纸测量（引擎参数，不是现实胶卷）

> 状态：living doc。2026-11-03 第一版；后面继续迭代。
> 目的：给每个目录选一组**胶片引擎的卷/纸参数**，让引擎的质感接近该目录的大师作品。
> 边界：卷/纸是作者引擎里的 **profile 选择器**，不是现实世界的 Portra/C200/Endura；现实胶卷名字只是标签。

---

## 0 一句话

**同一张作者测试图，同一曝光/PE，只换 `(film_stock, print_paper)`，量引擎渲出来的颜色/影调；再用大师样片做视觉目标选配方。**

不用大师 JPG 的统计反推卷纸；不用旧预设；不用现实胶卷性格。

---

## 1 唯一真理与禁止项

### 1.1 唯一真理

只依据作者 `spektrafilm` 源码：

- `init_params(film_profile, print_profile)`；
- `digest_params`：中性滤片按 `(纸, 光源, 卷)`；halation 按 `(use, antihalation)`；负片 couplers 共用；grain 按卷表；
- profile 数据：`log_sensitivity`、`channel_density`、`base_density`、`density_curves`、`density_curves_model`；
- `ProfileInfo.target_print`：卷→纸的配对元数据；
- taps：`log_e_film` / `cmy_film` / `log_e_print` / `cmy_print`；
- 作者回归基线：16 级灰阶 + green patch；作者测试图 `img/test/portrait_leaves_32bit_linear_prophoto_rgb.tif`。

### 1.2 禁止项

以下都不是“作者源码”，不得作为测量依据：

- `design/derive_medium.py` 的“暗部 CC 推卷 / p5 Dmax 推纸”；
- `card_medium.json`、`卡38`、`xhs预设`、旧 `amount`；
- `card_tone.py` / `measure_v7.py` / `cards/*.json` 的卡统计（p5/p95/contrast/shadow/highlight/face）**用于反推卷纸**；
- 现实胶卷/纸的性格（“Fuji 绿、Ektar 饱和、push 更暗”等）作为结论；
- 从大师 JPG 输出统计反解引擎参数。

> 这些可以作为“看图的提示”，但不能当测量结论；结论必须来自同输入下的引擎渲染。

## 2 参数空间

```
film_stock: 11 支负片 still
  Kodak: Ektar 100, Gold 200, Portra 160/400/800, Portra 800 push1/push2, Ultramax 400
  Fuji:  C200, Pro 400H, Xtra 400
print_paper: 6 种 still
  Kodak: Portra Endura, Supra Endura, Ultra Endura, Endura Premier, Ektacolor Edge
  Fuji:  Crystal Archive Type II
```

- 第一轮只取 **11 个 `target_print` 对**（Kodak→Portra Endura；Fuji→CAII），不自由组合 66 个。
- 跨配对只在明确需要时使用（例如 `Portra 400 + CAII` 的“绿纸”配方）；跨配对必须单独标注。
- 纸不是逐卡自由参数；它是卷的配对/明确例外。

## 3 测量口径

### 3.1 输入

- 作者测试图：`E:\spektrafilm\img\test\portrait_leaves_32bit_linear_prophoto_rgb.tif`
- 尺寸 1000×667，线性 ProPhoto RGB，float32。
- 所有 profile **同一张图**；不允许换图后比较。

### 3.2 渲染

```
engine: vendor 0.3.3（生产引擎；公开 0.3.4 与之不同，不混用）
init_params(stock, target_print)
auto_exposure = True, method = center_weighted   # 只算一次，所有 profile 相同
exposure_compensation_ev = 0
print_exposure = 1.0
print_exposure_compensation = True
normalize_print_exposure = True
input_color_space = 'ProPhoto RGB'
input_cctf_decoding = False
output_color_space = 'sRGB'
output_cctf_encoding = True
grain/halation: 作者默认（开）
use_enlarger_lut = False
use_scanner_lut = False
```

- **同一 auto exposure/PE** 是可比性的前提；换曝光模式/PE 必须整批重渲。
- auto exposure 会归一化亮度，所以“push 更暗”这类结论不成立；要看 contrast/C/hue。

### 3.3 输出/色彩

- 引擎输出 sRGB display 0–1。
- 测量转 **sRGB D65 Lab**（与 `card_tone`/`measure_v7` 同一把尺子）。
- 不拿 ProPhoto D50 Lab 与卡 D65 Lab 直接比。

### 3.4 固定区域/特征

测试图 667×1000（宽×高）。固定区域：

```
face:  forehead (250,430)-(400,520)
       nose     (300,620)-(380,700)
       cheekR   (390,620)-(460,700)
leaf:  top-right (500,80)-(650,250)
       bottom-left (0,650)-(100,800)
whole: 整幅
```

- `face L/C/h`：三块皮肤区域像素合并后的中位 Lab；
- `leaf a/b/C`：两块绿叶区域合并后的中位 Lab；
- `contrast = L* p95 − p5`（整幅）；
- 只写这些量；不写“偏冷/偏绿/更饱和”这种没有数的形容词。

## 4 方法

### 4.1 Look book（引擎侧）

1. 对 11 个 `target_print` 对，用同一张作者测试图渲 11 张；
2. 量 `face L/C/h`、`leaf a/b`、`contrast`；
3. 生成 contact sheet + face crop + 测量表；
4. 肉眼先看族（neutral / push / Fuji / Ektar），再看单支。

### 4.2 纸/卷分离（必须）

至少做 4 个交叉配对：

```
Portra 400 + Endura
Portra 400 + CAII
C200 + Endura
C200 + CAII
```

用同一张图、同一曝光/PE 渲；比较：

- 同卷换纸 → 纸的影响；
- 同纸换卷 → 卷的影响。

**结论必须写明是“卷”还是“纸”**；不能把纸的绿算到 Fuji 卷上。

### 4.3 视觉选配方（卡侧）

1. 每张卡取大师样片（第一张/代表图）；
2. 与 look book 的 11 张 + 交叉配对并排看；
3. 选一个**配方**（卷 + 纸），不是“现实卷名”；
4. 记录“视觉提案”，不是自动结论；
5. 人确认后写卡。

### 4.4 粒度

- 卡是单位；但**不要求 64 个唯一配方**；
- 配方可以共享；
- Kodak 单支卷差异很细时，只认“族/配方级”，不硬给单支；
- 逐卡风格由 `amount` / PE / WB 承担，不由卷纸硬扛。

### 5.3 由数得出的结论

- **“Fuji 绿”主要是纸**：Portra 400 换 CAII，leaf a −6.5→−10.5；C200 换 CAII，−4.2→−7.4；C200 在 Endura 上反而比 Portra 400 **更不绿**（−4.2 vs −6.5）。
- **“Ektar 最饱和”不成立**：Ektar face C 13.2；C200 16.6、push2 17.6；Ektar 是 hue 更红（38.2）。
- **“push 更暗”在 auto exposure 下不成立**：push2 face L 68.9 vs Portra 400 66.5；push 是 contrast 更高（64.9 vs 58.5）。
- **“800 对比更高”不成立**：800 contrast 57.2，低于 Portra 400 58.5；push1/2 才高。
- **成立**：Gold 更黄（hue 40.7）；Portra 160 最低 C（11.4）；Fuji C200/Xtra 更高 C；CAII 加绿；push1/2 更高 contrast。
- **Kodak 单支差异很细**：单支不可辨识时，只认族/配方。

## 7 迭代协议

1. **版本钉死**：换引擎版本/换 profile → 全部重渲，不能混用 0.3.3/0.3.4。
2. **同一输入/曝光/PE**：换测试图、auto exposure、PE → 整批重渲。
3. **先纸后卷**：先同卷换纸，再同纸换卷；结论必须写明是卷还是纸。
4. **只写测量值**：`face L/C/h`、`leaf a/b`、`contrast`；不写没有数的形容词。
5. **不自动反推**：大师 JPG 只做视觉目标；不做数值反解、不写 64 卡自动表。
6. **低置信只认族**：Kodak 单支不可辨识时，只写族/代表，不硬给单支。
7. **每次更新**：更新本 MD 的测量表 + lookbook HTML + 64 卡页；保留旧版做对比。

## 9 一句话总结
