## 0 目的

一组人像 → 匹配卡（人拍板）→ 引擎出质感 → LR 出风格 → 人好看。

1. **匹配**：对一批图排序出候选"大师作品目录"（一张卡 = 一个目录），**人拍板一张卡**。
2. **引擎**：把这张卡的**胶片质感**做出来。
3. **LR**：对齐这张卡的**曝光规律 / 颜色特点 / 明暗层次 / 冷暖层次**，并保证**人好看**。
4. **全程**：人优先，但背景同样要成立。

## 1 原则

| # | 原则 | 执行含义 |
|---|---|---|
| **P1** | **不打数值靶** | 卡给的是带 / 关系 / 形状 / 配比；判"在不在带内"，不判"离中点几格"；多解取**动得最少**的 |
| **P2** | **先查资料再定系数** | 旋钮规律优先找公开公式 / 官方文档 / 开源实现；查不到才标定，且标定必须写清"对哪个量、哪张图、几档" |
| **P3** | **每步都对齐卡上的量** | 说不出"对齐卡的哪一项"，这一步不许存在（物理不变量除外，须标明） |
| **P4** | **人优先 ≠ 背景可牺牲** | 脸的错误先修；背景的爆白 / 死黑同样算错，只是**排在后面** |

**三条执行检验**（写任何判据前先过）：

```
平移检验（P1）：把卡带整体平移 2 L*，若输出跟着变 ⇒ 在打靶，不行。
常数检验（P2）：每个常数必须落在五类之一
               物理 / 量化下限 / 公开资料 / 本机标定（附文件）/ 工具量程
指认检验（P3）：每条判据必须写出"卡上的字段名"；写不出 ⇒ 降为线索，或删。
```

## 2 流程

```
① 整批渲状态①（基线卡）→ 测 → 匹配排序 → 人拍板一张卡
② 用这张卡的介质渲全批状态①
③ 用同一张卡出 LR 计划（残差表，一次算）→ 执行 → 出状态③
④ 测状态③ → 报"每个量在带内 / 出多少" → 目检 → 交付
```

（① = 引擎出片 · ③ = LR 出片；数字 ①②③④ 是步骤号，别混。）

两条不能破：**一次算、一次验**（不许导出来看再调）· **交付判决只有目检**（卡带是约束，物理门只防事故）。

## 3 卡

### 3.1 定义

**匹配卡 = 一套大师作品 = 一个目录。** 鹿井按子目录（62 张）、滨田 / 小红书整套各 1 张，共 64 张。
`n_skin < 8` 的薄卡不进匹配，只留档。

### 3.2 卡里装什么（`cards_v3.json`）

| 字段 | 内容 | 口径 | 用法 |
|---|---|---|---|
| `face_L` `face_C` `face_h` | 脸 | 肤色取样点，套内 **P10~P90** | **门**（人好看） |
| `face_over_bg` | 脸÷背景亮部 | `skin.L / bg.L_p90`，分母 `bg.L_p90 ≥ 20`，套内 **P25~P75** | **门**（曝光规律） |
| `toe` `contrast_win` `shoulder` | 形状三段 | `p25−p5` / `p75−p25` / `p95−p75`，套内 P10~P90 | **门**（明暗层次） |
| `warm_cool_b` | 冷暖 | 亮部 b\* 中位 − 暗部 b\* 中位，套内 P10~P90 | **门**（冷暖层次） |
| `neutral_axis` | 中性轴 | 五个亮度段的 a / b 中位 | **色锚** |
| `hue_bands` | 色相六段 | 每段 share + C 中位 | 线索 |
| `clip` | 整幅爆白 | `clip_pct`，套内 P10~P90 | **门（单边）** |
| `p5` `p50` `p95` `contrast` `skew` | 分布 / 跨度 | 套内 P10~P90 | **线索**（宽，随拍什么变） |
| `person_over_bg` `light_ratio` | 关系 / 光比 | 同上 | 线索 |
| `light` | 光位标签计数 | 四分量近似 | 匹配用 |
| `samples` `n` `thin` | 样片 / 张数 | — | 匹配页展示 |

### 3.3 卡里**没有**什么（写清，别假装有）

| 缺 | 后果 |
|---|---|
| **质感量**（颗粒 / 锐度 / 光晕 / 色云） | 目的 2 目前只能做到"按语料三档"，做不到"按卡" |
| **人 / 背景分开的 clip 带** | 只能整幅对齐卡的 clip，人/背景分计只作诊断 |
| **轮廓亮边的带** | 轮廓光只能记账，进不了判据 |
| 逐图配方 | 介质按语料给（见 3.4） |

### 3.4 介质从哪来

卡**不装**卷/纸：按语料给默认值，人可覆盖。

```
鹿井 / 滨田 → kodak_portra_400 + kodak_portra_endura
xhs        → kodak_gold_200  + kodak_portra_endura   ← 必须与 presets/xhs预设/preset.json 一致
```

（★ 旧代码 `matchcard._medium_by_corpus` 把 xhs 写成 `kodak_ultramax_400`，与预设不符，见 §13。）

### 3.5 加一张卡

```
一个目录 ≥ 8 张有脸 → m_<语料>_v3.json → cards_build.py → cards_v3.json
命名唯一；`thin` 自动标；样片取前 3 张。
```

## 4 分工

| | 引擎 | LR | 人 |
|---|---|---|---|
| 管 | 卷 / 纸 / 颗粒 / 光晕 / 柔光（**质感**）· 中灰归一 | **残差**：把出带的量推回卡的带内 | 选卡 · 意图 · 目检 |
| 不管 | 逐图落点 · 追某个数 | 质感 · 重设风格 | 数值 |
| 判据 | 物理（不剪死） | 卡的带 + 物理 | 好看 |

**LR 是修补，不是主笔**：它只把"出带"的量推回带内；带内不动、不排名、不复刻形状。

## 5 LR 的唯一工作方式：残差

### 5.1 残差表

> 每一行 = 一个量 + 卡上的带。**带内不动**；出带才修，修到**最近带边**为止。

| # | 量 | 卡上的带 | 角色 | 出带怎么办 | 旋钮 · 作用域 |
|---|---|---|---|---|---|
| 1 | 脸内死白（≥254 的像素） | 0 | 物理门 | 提亮过头 ⇒ **回退提亮** | — |
| 2 | 整幅 `clip` | ≤ 卡带上沿 | 门（单边） | 高 ⇒ 压高光；人身上高 ⇒ 回退提亮 | 背景蒙版 |
| 3 | `p1` | ≥ 1 | 物理门 | 低 ⇒ Blacks 加（抬黑）；其余不动 | 全幅 |
| 4 | 形状 `toe` `contrast_win` `shoulder` | 卡带 | 门（区间） | 低 / 高 ⇒ 曲线对应段 | 全幅曲线 |
| 5 | `face_L` | 卡带 | 门（人） | 低 ⇒ **全局曝光**；高 ⇒ 压曝光 | 全幅 |
| 6 | `face_over_bg` | 卡带 | 门（关系） | 见 5.2 的表 | 主体 / 背景 |
| 7 | 中性轴 a / b | 卡五段 | 色锚 | 偏 ⇒ WB 双轴；**无中性面 ⇒ 不动** | 全幅 |
| 8 | `face_C` `face_h` | 卡带 | 门（肤色） | 低 / 高 ⇒ HSL 橙（只动 S / H） | 全幅 |
| 9 | `warm_cool_b` | 卡带 | 门（冷暖） | 低 / 高 ⇒ 颜色分级 | 背景蒙版 |
| 10 | 跨度 `p95−p5` | 卡 `contrast` 带 | 线索 | 只记账 | — |
| 11 | 轮廓亮边 | 卡无 | — | 只记账 | — |

### 5.2 两条不变式（决定"全局还是局部"）

```
① 全局曝光保比值：Y 等比 ⇒ 脸/背景的**比值几乎不动**（L* 比值只动几个百分点，
   方向是略降，因为亮的分量斜率大）。
② 局部（主体蒙版）改比值：只动脸 ⇒ 比值大幅变，同时**脸与贴脸圈的差拉开**
   （1608 实测：到同一脸亮度，全局的边差 30.9，局部的边差 46.7）。
```

**推论（这张表替代了旧的"分类树"）**：

| 情形 | 动谁 |
|---|---|
| 脸出带 + 比值出带 | **主体局部**（一次同时改两个量） |
| 脸出带 + 比值在带 | **全局曝光**（保比值） |
| 脸在带 + 比值低 | **背景压暗**（保脸） |
| 脸在带 + 比值高 | 只记账（压脸会破坏"人好看"，提背景会爆） |
| 两个都在带 | **不动** |

★ 局部（或压背景）会把"脸与贴脸圈的差"拉开。**这不设门，只记账**：记"边差从 X 变 Y"，由目检判。

### 5.3 顺序（前者改后者的输入，后者覆盖前者的同域）

```
曲线（形状） → 全局曝光（脸绝对亮度） → 黑端 → 主体 / 背景（比值、肤色） → 背景（clip、冷暖） → 预测验收
```

**曲线在前、补跨度在后**：先有形状，才谈"在哪段补跨度"。

### 5.4 冲突优先级

```
物理（死白 / p1） > 人（face_L / C / h） > 背景（clip / 冷暖） > 线索
```

**一次算**：全部用前向模型预测后写参数，不导出回看。预测误差必须报（见 §10）。

## 6 判据与约束

### 6.1 三种角色（别混）

```
判决   物理（死白 / p1 / 量程 / 单调）—— 破了就是错，没有"接近"
约束   卡带 —— 出带才动，动到最近带边；交付时逐项报，不排名
死区   量化下限（u8 一个编码：L* ≈ 0.4、a/b ≈ 0.5、C ≈ 0.2）—— 小于一格不动
```

**判决只有两条：物理 + 目检。** 卡带是求解约束，不是"合格证"。

（本文其余地方写的"门"一律指**约束**；写"物理门"的指**判决**。）

### 6.2 约束的用法

```
区间约束：出带才动，动到最近带边；带内不排名、不复刻。
单边约束：clip 只看上沿（0 爆白不是缺陷）。
物理判决：只有一种结果，破了就是错，没有"接近"。
```

### 6.3 对齐 vs 打靶（自检）

```
平移卡带 2 L*：输出不变 ⇒ 对齐；跟着变 ⇒ 打靶。
域内多解：取旋钮动得最少的。
解不唯一不是缺陷：说不唯一就说明这一步不该再动。
```

### 6.4 本版删掉的阈值（不许复活）

```
p95 ≤ 93 · 人 clip < 0.5% · LocalHighlights = −30 · 贴脸圈 +25 · clip 2.5%
边差 >10 格 · 脸 L 变化 >1 · 脸 b* 变化 >2 · 跨度回到 0.9 · 轮廓比 0.7
中性面 5% · 逆光脸 45~70 / 顺光 55~85 · 分类树 12 / 35 / 0.35 / 0.12
```

## 7 通道能力表（设计必须服从）

| 能力 | 事实 | 设计后果 |
|---|---|---|
| **一图一个蒙版组** | `MASKPARAM` 只写第 1 组 | 主体与背景**不能同图**；按 5.2 选一个 |
| 局部曝光刻度 | `LocalExposure2012 = EV / 4`（0.5 档 = 0.125） | 写 XMP 直接换算 |
| 回读 | `MASKPARAM` 必须回读；**回读 nil ≠ 没写**（v18 成片 XMP 里 `LocalShadows2012="1"` 确实落下了） | 以**成片 XMP / 测量**为准，不以回读为准 |
| 局部选择性 | `LocalShadows` 满档：人 p99 **+0.1**、clip +0.5；`LocalExposure` 1 档：p99 **+11.2** | "局部必爆"不是物理，是 `LocalExposure` 的性质 |
| 桥写值 | `MASK ... LocalExposure2012=` 走 setValue **不落地**，必须 `MASKPARAM` | — |
| 曲线 / HSL / 分级 | 16 点 XMP；HSL 三分量独立；分级两轮 + 平衡 | — |

## 9 检测

**检测不是判据。** 只做两件事：防物理事故、定位问题。

| 级别 | 量 | 防什么 / 定位什么 |
|---|---|---|
| **必算** | 脸 `L/C/h` | 人好看 + 关系要动多少 |
| 必算 | 背景 `L_p90` | 关系的分母 |
| 必算 | `clip`（整幅 + 人/背景分计） | 物理（死白）+ 归属（该压谁） |
| 必算 | 脸内死白 | 不可逆 |
| 必算 | `p1` | 黑端 |
| 按需 | `near_bg` | "脸和背景关系看着不对" |
| 按需 | 中性面 | "颜色不正" |
| 按需 | `rim` 分位 | "逆光的光没了" |
| 按需 | 光位标签 | 匹配 / 分类 |

## 10 验收

```
物理：脸内死白 = 0；p1 ≥ 1
卡带：逐项报"在带内 / 出多少"（不排名、不打分）
目检：只有人
误差：预测 vs 实测，逐图报（今天实测 ±50%，见 §12）
```

**不算"成"的情况**：出带但没修（必须写"为什么没修"：物理截断 / 通道不允许 / 会破坏另一个门）。
