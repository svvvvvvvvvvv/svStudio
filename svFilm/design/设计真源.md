# 设计真源（2026-10-30 · 条件对齐版）

> **唯一执行真源**。代码与本文冲突 ⇒ **改代码**。
> 本版是**全盘转向**：把"对着卡的带打靶"整个拿掉。
> 证据：`cond_bands_v2.json` / `m_鹿井_v4.json`（672 张鹿井大师图，2026-10-30 晚）。
> 旧版：`_archive_设计真源_20261030.md`（789 行）· 中间版：git `d967b7b`。

---

## 0 目的

一组人像 → 匹配卡（人拍板）→ 引擎出质感 → LR 出风格 → 人好看。

1. **匹配**：对一批图排序出候选"大师作品目录"（一张卡 = 一个目录），**人拍板一张卡**。
2. **引擎**：把这张卡的**胶片质感**做出来。
3. **LR**：对齐这张卡的**曝光规律 / 颜色特点 / 明暗层次 / 冷暖层次**，并保证**人好看**。
4. **全程**：人优先，但背景同样要成立。

---

## 1 原则

| # | 原则 | 执行含义 |
|---|---|---|
| **P1** | **不打数值靶** | 卡给带 / 关系 / 形状 / 配比；判"在不在带内"，不判"离中点几格"；多解取**动得最少**的 |
| **P2** | **先查资料再定系数** | 旋钮规律优先找公开公式 / 官方文档 / 开源实现；查不到才标定，且标定必须写清"对哪个量、哪张图、几档" |
| **P3** | **每步都对齐卡上的量** | 说不出"对齐卡的哪一项"，这一步不许存在（物理不变量除外，须标明） |
| **P4** | **人优先 ≠ 背景可牺牲** | 脸的错误先修；背景的爆白 / 死黑同样算错，只是**排在后面** |

三条执行检验：平移检验（卡带平移 2 L\*，输出跟着变 ⇒ 打靶）· 常数检验（五类之一）· 指认检验（写出卡字段名）。

---

## 2 架构

```
卡   = 不变量层（风格：色彩 / 冷暖 / 对比 / 形状 / 纹理） + 条件表（光位 → 关系）
引擎 = 把不变量层做出来（介质 · 质感 · 形状）        ← 这是"像不像"的主体
LR   = 按条件表修关系（脸÷背景），其余只记账          ← 这是"补差"，不是主笔
人   = 选卡 + 目检                                    ← 这是"好不好"
```

**一句话**：能对齐的是**风格层**（卡解释 0.33–0.42、光位解释 ≈0）；需要逐图修的是**关系层**（光位解释 0.30）；**脸的绝对亮度谁都不该硬管**（光位只解释 0.41，其余 59% 是大师自己的选择）。

## 3 证据（672 张鹿井，新尺子）

### 3.1 方差分解（eta²）

| 量 | 卡解释 | 光位解释 | 判读 |
|---|---|---|---|
| `warm_cool_b` | **0.418** | 0.018 | 卡的风格，与光位无关 |
| `contrast` | **0.412** | 0.075 | 介质 |
| `toe` / `shoulder` | 0.375 / 0.287 | 0.106 / 0.153 | 形状偏介质 |
| `face_C` | 0.328 | 0.035 | 介质，不是光位 |
| `face_h` | 0.287 | 0.003 | 与光位**完全无关** |
| `face_L` | 0.347 | **0.414** | 光位主导，但 59% 解释不了 |
| `face_over_bg` | 0.235 | **0.298** | 一半场景一半风格 → LR 的主战场 |

**结论**：风格层（冷暖/对比/色彩/形状）是卡的活；关系层（脸÷背景）是 LR 的活；脸绝对亮度是"大师的选择"，只做弱约束。

### 3.2 条件表（P25–P75）

| 光位 | n | `face_L` | `face_over_bg` |
|---|---|---|---|
| `back` 逆光 | 84 | 47.1–54.5 | **0.53–0.60** |
| `mid` 中间 | 406 | 59.0–66.7 | 0.68–0.78 |
| `front` 顺光 | 152 | 65.7–73.0 | **0.89–1.08** |
| `unknown` | 30 | 57.1–68.3 | 0.67–0.83 |
| 全局（不用） | 672 | 57.9–68.3 | 0.67–0.86 |

**旧法用全局中点 0.85 当目标，在逆光类上偏高 +50%、顺光类偏低 −14%**——同一个常数在两个分布上方向相反，这是"点靶"的必然错误，不是调参能修的。

### 3.3 什么条件化不了

- **天空**：747 张里只有 10 张天空占比 ≥20%，eta²≈0 → 不是条件。
- **第二维候选**（主体占比 / 环境占比 / 近场比 / 背景结构）：只把 `face_L` 从 0.414 抬到 0.420 → 条件化到此为止。
- 剩下的 59% 是"选择"（内容/构图/曝光偏好），规则预测不了，只能目检。

## 6 LR：条件残差

### 6.1 唯一的光位标签（双区判据）

```
gap  = 背景亮部 p90 − 脸 L
dark = 脸掩膜内 L ≤ 40 的占比
back  ：gap ≥ 35，或（dark ≥ 0.35 且 gap ≥ 12）
front ：dark ≤ 0.12 且 gap ≤ 12
其余   ：mid（不硬判）
```

**只有这一套。** 旧的"近场比 / clump / 左右差"那套作废（它在 1608 上判成顺光，实际是逆光）。标签必须从**输入 ①** 判，不能从成片 ③ 判（③ 已被处理污染）。

### 6.2 残差表

> 每一行 = 一个量 + 卡上的带（或条件带）。**带内不动**；出带且**偏出量 > 半个带宽**才修，修到带边为止。

| # | 量 | 带的来源 | 角色 | 出带怎么办 | 旋钮 · 作用域 |
|---|---|---|---|---|---|
| 1 | 脸内死白 | 0（物理） | 判决 | 提亮过头 ⇒ **回退提亮** | — |
| 2 | 整幅 `clip` | 卡带（单边） | 约束 | 高 ⇒ 压高光；人身上高 ⇒ 回退提亮 | 背景蒙版 |
| 3 | `p1` | ≥ 1（物理） | 判决 | 低 ⇒ Blacks 加 | 全幅 |
| 4 | 形状 `toe/contrast_win/shoulder` | 卡带 | 约束 | 低/高 ⇒ 曲线对应段 | 全幅曲线 |
| 5 | **`face_over_bg`** | **条件表** | **主约束** | 见 6.4 的六格 | 主体 / 背景 |
| 6 | `face_L` | 条件表 | **弱约束** | 只有偏出量 > 半个带宽才动 | 全幅曝光 |
| 7 | 中性轴 a/b | 卡五段 | 色锚 | 偏 ⇒ WB；无中性面 ⇒ 不动 | 全幅 |
| 8 | `face_C` `face_h` | 卡带 | 约束 | 低/高 ⇒ HSL 橙（只动 S/H） | 全幅 |
| 9 | `warm_cool_b` | 卡带 | 约束 | 低/高 ⇒ 颜色分级 | 背景蒙版 |
| 10 | 跨度 `p95−p5` | 卡 `contrast` 带 | 线索 | 只记账 | — |
| 11 | 轮廓亮边 | 卡无 | — | 只记账 | — |

### 6.3 阈值 = 半个带宽（不是"1 档"）

```
带宽 w = 条件带的上沿 − 下沿
显著偏 = 值跑出带，且 超出的量 > w/2
```

理由：带宽本身就是"这个量在这类场景下的自然离散"；超出半个带宽，说明它已经靠近"下一类"了。**用卡自己的量当阈值，不另编常数。**

例：`back` 的 `face_over_bg` 带宽 0.07 ⇒ 偏出 0.035 才算显著；`face_L` 带宽 7.4 ⇒ 偏出 3.7 格才算显著。

### 6.4 两条不变式 + 六格

```
① 全局曝光保比值：Y 等比 ⇒ 脸/背景比值几乎不动（L* 比值只动几个百分点）。
② 局部（主体蒙版）改比值：只动脸 ⇒ 比值大幅变，同时脸与贴脸圈的差拉开。
```

| 情形 | 动谁 |
|---|---|
| 比值低 + 脸也低 | **主体局部**（一次改两个量） |
| 比值低 + 脸在带内 | **背景压暗**（保脸） |
| 比值高 + 脸也高 | **主体局部压暗** |
| 比值高 + 脸在带内 | 只记账 |
| 比值在带 + 脸显著偏 | **全局曝光**（保比值） |
| 其余 | **不动** |

★ 局部（或压背景）会把"脸与贴脸圈的差"拉开。**不设门，只记账**：记"边差从 X 变 Y"，由目检判。

### 6.5 顺序

```
曲线（形状） → 全局曝光（脸） → 黑端 → 主体/背景（关系、肤色） → 背景（clip、冷暖） → 预测验收
```

**一次算**：全部用前向模型预测后写参数，不导出回看。预测误差必须报（今天实测 ±50%）。

## 7 判据与约束

### 7.1 三种角色

```
判决   物理（死白 / p1 / 量程 / 单调）—— 破了就是错，没有"接近"
约束   卡带 / 条件带 —— 出带且偏出 > w/2 才动，动到带边；交付时逐项报，不排名
死区   量化下限（u8 一个编码：L* ≈ 0.4、a/b ≈ 0.5、C ≈ 0.2）—— 小于一格不动
```

**判决只有两条：物理 + 目检。** 卡带是求解约束，不是合格证。

### 7.2 匹配 vs 求解（P1 的适用范围）

```
匹配：可以用卡的中位/分布距离 —— 那是"像不像"的度量，不是靶。
求解：不许用中位/中点 —— 只能"出带才动、动到带边"。
```

（`eta²(卡)=0.24–0.42` ⇒ 卡与卡是分得开的，所以匹配用中位是合法的。）

### 7.3 本版删掉的阈值

```
p95 ≤ 93 · 人 clip < 0.5% · LocalHighlights −30 · 贴脸圈 +25 · clip 2.5%
边差 10 格 · 脸 L 变化 1 · 脸 b* 2 · 跨度 0.9 · 轮廓比 0.7 · 中性面 5%
逆光脸 45~70 / 顺光 55~85 · 分类树 12/35/0.35/0.12 · R = 0.85（全局中点）
"全局带当目标" · "显著偏 = 1 档"
```

## 11 验收

```
物理：脸内死白 = 0；p1 ≥ 1
约束：逐项报"在带内 / 出多少（相对带宽）"
目检：只有人
误差：预测 vs 实测，逐图报
```

不算"成"：出带但没修（必须写原因：物理截断 / 通道不允许 / 会破坏另一个约束）。
