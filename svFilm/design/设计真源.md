# 设计真源

> **唯一设计真源。** 纪律在 `纪律.md`（先读）。代码与本文冲突 ⇒ 改代码。
> 历史版本在 `_archive_20261101/`；分析/标定过程不进本文。
>
> 三句话：**选卡 → 引擎给介质基线 → LR 对齐卡 → 人目检。**

---

## 0 目的

一组人像：

1. **匹配**：从大师目录里选出**一张卡**（人拍板）；
2. **引擎**：把这张卡的胶片质感做出来（①）；
3. **LR**：把 ① 对齐到这张卡的**明暗 / 颜色 / 肤色 / 冷暖**，并保证**背景和脸都成立**；
4. **验收**：量 ③ + 人目检。

---

## 1 最高规则

| # | 规则 | 含义 |
|---|---|---|
| **R0** | **对齐人选的那张卡** | 卡是风格/关系的唯一目标；不是合格证，不是单点数值 |
| **R1** | **物理底线** | 死白 / p1 死黑 / 量程 / 非单调 / 肤色崩；只拦事故 |
| **R2** | **WB 目录级/组级** | 一个目录一个 cast + 引擎 WB；同光整组共用；不逐图调 |
| **R3** | **先全局，后局部** | WB → 曝光/明暗 → 颜色 → 局部 → 细节 |
| **R4** | **脸和背景都成立** | 不用背景换脸，也不用脸换背景 |
| **R5** | **不打数值靶** | 用卡的关系/形状/配比/分布；不设区间靶、不设单点目标 |
| **R6** | **人目检是唯一验收** | 机器只出片 + 目检页 + 诊断；不宣布“过/不过”，不代替人审片 |

卡的“关系”指：明暗分布（p5/p50/p95/对比/肩趾）、背景结构、`face_h/face_C`、`warm_cool_b`、色相带。
**不是**“背景 L=30”“face L=66”这种单点。

---

## 2 三级架构

| 级 | 谁 | 管什么 | 频率 |
|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/化学曲线；介质按目录（卡）算 | 每目录一次 |
| **批级** | LR-A | 只报批级护栏（曲线参数 IQR/反折/预算/离散度），不下发公共曲线 | 每批一次，只报告 |
| **图级** | LR-B | 曝光/明暗、曲线、肤色、冷暖、脸/背景局部 | 每图一次 |
| — | 人 | 选卡 / 选 hero / 批边界 / 意图 / **目检（唯一验收）** | — |

边界：

- A 不决定单张亮度/曲线；只报告。
- B 不动介质/颗粒；只在 LR 里对齐卡。
- **WB 不属于 B 的逐图量**：它是卡级参数（见 `LR设计.md` §2）。
- 光位/光向量不驱动影调；`light_probe` 只做诊断，`source_deg` 只驱动光晕/柔光。

## 3 流程

```
0 原片 + 批定义（同一场 / 同一套光；跨光/跨场景先拆批）
1 读 RAW 内嵌 JPG → 每批一个 batch_content → 内容匹配选卡（人拍板卡 + hero）
2 按卡的介质渲 ①（只渲一次；没有 ①′）
3 测 ①（与 ③ 同一把尺子）
4 匹配 B：卡内同构图 + 同场景/背景的 peer 组
   → peer 的明暗形状、背景关系、肤色 H/C 作为这张的目标
   → peer_n<3 时回退卡点值，记账；不猜
5 LR-A：只报批级护栏（IQR/反折/预算/离散度）
6 LR-B：WB（卡级）→ 曝光/明暗 → 颜色/肤色 → 局部 → 细节
   → plan_<stem>.json（带 peer_ids / target / 卡偏差）
7 执行（XMP/桥）→ ③；回读失败中止并记账
8 执行（XMP/桥）→ ③；回读失败中止并记账
9 出目检页：③ + ① + 测量（只做诊断，不宣布过/不过）→ **人目检**
10 记账：一图一行；人说不达标，写“哪一段没做到”，不是机器判
```

**批内一次算，不迭代；跨批才回灌。**
`--push` 是唯一例外：人明确要求时才用，每轮量 ③ 并记账，不是常规流程。

## 4 卡

**卡 = 大师成片数据库里的一个目录。** 卡不是我们建的，是从库里选的。

卡里存：

```
明暗：p5 / p50 / p95 / contrast / toe / shoulder / skew
肤色：face_L / face_C / face_h（关系，不是单点靶）
颜色：warm_cool_b / hue_bands / neutral_axis
WB：cast(a*/b*，目录级诊断) / temperature / tint（目录级引擎输入；不拿白点反解）
引擎 PE：每个内容目录一个（print_exposure；标卡时定，错了会逼 LR 硬拉）
内容：card_content（目录级，用于匹配 A）
```

卡里不存：介质参数、peer 目标、逐图曲线。

- **hero 只做目检参考**，不拿来做拟合；人选卡时一起指定。
- 整卡中位不用于匹配/曝光/曲线；只用于介质推导与风格展示。
- 卡内逐片目标用 peer（同构图 + 同场景/背景），不用整卡中位。

### 4.1 加一张卡

```
≥8 张有脸 → 新尺子测 → 卡 + card_content + wb（中性轴/白点）
逐片 tone 进 photos_tone；peer 目标临时算，不写进卡
```

## 5 引擎

- 一次渲染：① 正式（卡的介质）；匹配 A 用机内 JPG，不渲 ①′。
- 测光只保证“余量一致 + 不剪死”；介质按目录（卡）算。
- **PE（print_exposure）是目录级参数**：每个内容目录/卡标一个；PE 合适，底片落在好位置，
  LR 就不用靠大曝光/大局部硬拉；PE 不对，先修 PE，不拿 LR 补。
- 判据：不剪死 + 质感量 + 目检；引擎不管脸、不管落点。

详见 `引擎设计.md`。

## 6 LR

**详见 `LR设计.md`。** 宪法只定：

```
WB 目录级/组级，一个目录一个值；不逐图调。
一张卡用一个局部蒙版（脸/肤色），不逐图换多组。
图级顺序：曝光/明暗（Basic 为主，曲线补）→ 肤色（蒙版里的 Point Color，不做 HSL）→ 局部 → 细节。
先让背景/整幅成立，再补脸；局部不能扫到背景。
卡是目标；不设数值靶/区间靶。
```

---

## 7 交付与目检

```
机器只做：出片 ③ + 目检页 + 测量（诊断）
人做：目检；人说“过”才是过；人说“不过”就写哪一段不对
```

- 物理测量只用来**定位事故**（死白/p1/肤色崩），不宣布过/不过；
- 卡对齐只用来**描述偏差**（哪一项、差多少），不宣布过/不过；
- 没有自动验收、没有“物理底线过了就算交付”。

## 8 失效清单

| 情况 | 处置 |
|---|---|
| 批内异质（两套光/场景/服装） | 先拆批；不硬压一个 batch_content |
| 无中性面 | WB 只做保守偏移，记账；不编色温 |
| 无脸 / 脸太小 | 跳过图级脸修正，记账 |
| peer_n<3 | 回退卡点值，记账；不猜 |
| 主体已削顶 | 物理不可逆；图级截断，记账 |
| 脸和背景同时要局部 | 分组/分次；一组蒙版只做一件事 |
| 卡本身与批不匹配 | 报“卡/批不匹配”，换卡或拆批；不硬修 |
