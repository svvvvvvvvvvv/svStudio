# 设计真源

> **唯一设计真源。** 纪律在 `纪律.md`（先读）。代码与本文冲突 ⇒ 改代码。
> 历史版本在 `_archive_20261101/`；分析/标定过程不进本文。
>
> 三句话：**选卡 → 引擎给介质与曝光落点 → LR 对齐形状/肤色/颜色 → 人目检。**

---

## 0 目的

一组人像：

1. **匹配**：从大师目录里选出**一张卡**（人拍板）；
2. **引擎**：把这张卡的胶片质感做出来（①）；
3. **LR**：补齐 ① 相对卡/peer 的**形状 / 肤色 / 颜色**残差；曝光由引擎按 peer 落点定，LR 不再重算；
4. **验收**：人目检（唯一验收）。

---

## 1 最高规则

| # | 规则 | 含义 |
|---|---|---|
| **R0** | **对齐人选的那张卡** | 卡是风格/关系的唯一目标；不是合格证，不是单点数值 |
| **R1** | **物理底线（出片后诊断）** | 人/脸死白、p1 死黑、量程、非单调、肤色崩；**引擎不读脸，R1 由目检页报事实，不自动改曝光**；背景过曝只诊断 |
| **R2** | **WB 目录级/组级** | 一个目录一个引擎 WB（预设/同光值）；`cast` 只诊断；同光整组共用 |
| **R3** | **先全局，后局部** | WB → 曲线形状 → 肤色局部/颜色 → 白裙 Highlights → 细节 |
| **R4** | **人优先，背景允许过曝** | 先保人/脸；背景可以过曝；脸和背景各自成立 |
| **R5** | **用关系/形状/分布** | 目标来自卡/peer 的形状比例、**人/背景与脸/背景的明暗比例**、区域关系、背景结构；绝对分位只做诊断 |
| **R6** | **人目检是唯一验收** | 机器只出片 + 目检页 + 诊断；不宣布“过/不过”，不代替人审片 |

卡的“关系”指明暗**形状比例**（toe/shoulder）、**人/背景与脸/背景的比例**、背景结构、`face_h/face_C`、`warm_cool_b`、色相带；  
**不是** p50/p95 中值，也不是“背景 L=30”“face L=66”这种单点。

## 2 三级架构

| 级 | 谁 | 管什么 | 频率 |
|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/化学曲线；介质按目录（卡）算 | 每目录一次 |
| **批级** | LR-A | 只报批级护栏（曲线参数 IQR/反折/预算/离散度），不下发公共曲线 | 每批一次，只报告 |
| **图级** | LR-B | 曲线、肤色、冷暖、脸/背景局部（全局曝光归引擎） | 每图一次 |
| — | 人 | 选卡 / 选 hero / 批边界 / 意图 / **目检（唯一验收）** | — |

边界：

- A 不决定单张亮度/曲线；只报告。
- B 不动介质/颗粒；只在 LR 里对齐卡。
- **WB 不属于 B 的逐图量**：它是卡级参数（见 `LR设计.md` §2）。
- **peer 距离用曝光不变量**（构图、场景结构、人/背景与脸/背景的明暗比例）；连续光向量、四分组、`light_probe` 只做诊断；`source_deg` 只驱动光晕/柔光。
- **PE 逐图求解**：卡的 `pe` 只作 nominal/起点；逐图 PE 由 peer target 解，不再靠脸测光。

## 3 流程

```
0 原片 + 批定义（同一场 / 同一套光；跨光/跨场景先拆批）
1 读 RAW 内嵌 JPG → 测量 → 每批一个 batch_content → 内容匹配选卡（人拍板卡 + hero）
2 peer（JPG 测量 + 卡内单帧）：
   → 关系比（人/背景、脸/背景）+ 构图/场景/服装过滤
   → 最近 k 张的整幅 p50 中位 = target_p50；IQR/置信度记账
   → 卡内没有同场景同反差的 peer ⇒ 借最近比值 peer，标低置信；一张都没有 ⇒ 停（报卡无测量）
3 渲 ①：卡的介质 + WB + 逐图 PE（解到 target_p50）
   → auto_exposure=False；不建脸 mask；色卡标定 + 输入亮度分布 → 直接算 PE，只渲一次
   → 没有 ①′；卡的 pe 是 nominal，±4 EV 夹，hit_bound 记账
4 测 ①（与 ③ 同一把尺子）；脸 L/clip 只报
5 LR-A：只报批级护栏（IQR/反折/预算/离散度）
6 LR-B：WB（卡级）→ 曲线（peer→hero）→ 肤色组三轴 → 白裙检查/Highlights → 细节
   → EV 0；不重算全局曝光；不读脸
   → plan_<stem>.json（带 peer_ids / target_p50 / pe_solved / 卡偏差）
7 执行（XMP/桥）→ ③；回读失败中止并记账
8 出参考页：③ + peer + ①；整组 ③ 并排
9 人目检：先看整体，再看脸；机器不宣布过/不过
10 记账：一图一行；人说不达标，写“哪一段没做到”，不是机器判
```

**批内一次算，不迭代；跨批才回灌。**
`--push` 是唯一例外：人明确要求时才用，每轮量 ③ 并记账，不是常规流程。

## 4 卡

**卡 = 大师成片数据库里的一个目录。** 卡不是我们建的，是从库里选的。

卡里存：

```
明暗：p5 / p50 / p95 / contrast / toe / shoulder / skew
肤色：face_L / face_C / face_h（关系，不是单点靶）
颜色：warm_cool_b / hue_bands / neutral_axis
WB：cast(a*/b*，目录级诊断) / temperature / tint（目录级引擎输入；不拿白点反解）
引擎 PE：卡上一个 nominal（print_exposure；标卡时定，作逐图求解的起点/夹边界）
标准色卡：每个 medium 一份（ColorChecker Classic + 21 级灰阶；5 个 PE 档）
内容：card_content（目录级，用于匹配 A）
```

介质参数、peer 目标、逐图曲线放在卡外（介质 / peer / plan）。

- **hero**：人选的卡内代表片；① 目检参考；② peer 不足时的关系兜底：取 hero 的形状 / `face_over_bg` / 肤色 C/L / 冷暖方向作为目标。
- 整卡点值只用于介质推导/展示；逐张**曝光**目标用 peer 组整幅 p50 中位。
- 卡内逐片 peer 用曝光不变量（构图/场景/服装 + 人/背景、脸/背景比例）；peer 不足 → 借最近比值 peer（低置信）；一张都没有 → 停（卡不当靶）。
- 卡的 `pe` 只是 nominal；逐图 PE 由 peer target 解，不再用 subject-face。

### 4.1 加一张卡

```
≥8 张有脸 → 新尺子测 → 卡 + card_content + wb（中性轴/白点）
逐片 tone 进 photos_tone；peer 目标临时算，不写进卡
```

## 5 引擎

- 一次渲染：① 正式（卡的介质 + 逐图 PE）；匹配 A 用机内 JPG，不渲 ①′。
- 曝光：**peer 组整幅 p50 中位 = target**；引擎不读脸、不建 mask；按色卡标定的
  “输入亮度 × PE → 输出亮度”表 + 这张 RAW 的输入亮度分布，直接解 PE，只渲一次。
- **卡的 `pe` 是 nominal/起点**：±4 EV 夹，hit_bound 记账；PE、WB、印相滤片仍按目录。
- 判据：不剪死 + 质感量 + 目检；脸 L/clip 只在出片后报事实，不挡曝光。
- LR 不再重算全局曝光；① 的 PE 落点保留；Basic 0；只做曲线形状。

详见 `引擎设计.md`。

## 6 LR

**详见 `LR设计.md`。** 宪法只定：

```
引擎管卷/纸/扫描/WB/PE/peer 落点；LR 补齐三项残差：形状、肤色、颜色（曝光归引擎）。
WB 目录级；cast 只诊断。
人/脸/皮肤高光是出片后的诊断；背景不忽略，但不拿它压掉人；白裙允许先亮，再由人物蒙版 Highlights 压。
不重算全局 EV；① 的 PE 落点保留；不拿卡/peer 绝对分位、也不拿 Auto Tone 当靶。
Basic 四根默认 0，归通用修图；卡只定介质/卷纸/WB，逐图关系走 peer，不套卡的绝对分位。
曲线只套 peer→hero 的肩趾比例；曲线只补形状。
Point Color 三轴：HueShift / LumScale / SatScale；在肤色局部之后算，不只改饱和。
局部顺序：肤色组（曝光 + 三轴）→ 白裙检查 → 过曝才压人物蒙版 Highlights；两组共用人物选择。
补脸只抬；余量用肤色窗自己的；肤色窗没落成 ⇒ 停。
卡只定介质/卷纸/WB/PE nominal；逐图明暗形状/肤色/冷暖/色相走 peer。
```

## 7 交付与目检

```
机器只做：出片 ③ + 目检页 + 测量（诊断）
人做：目检；人说“过”才是过；人说“不过”就写哪一段不对
```

- 物理测量用来**定位事故**（死白/p1/肤色崩），报告事实；
- peer/卡偏差用来**描述偏差**（哪一项、差多少）；
- 人目检是唯一验收；机器出片 + 参考页 + 诊断。

## 8 失效清单

| 情况 | 处置 |
|---|---|
| 批内异质（两套光/场景/服装） | 先拆批；每批一个 batch_content |
| 无中性面 | WB 做保守偏移，记账 |
| 无脸 / 脸太小 | 不影响曝光（引擎不读脸）；只影响肤色局部，记账 |
| peer 不足 / 无同场景同反差 | 借最近比值 peer，标低置信；一张都没有 → 停（报卡无测量）；记账 |
| 色卡标定缺失 | 停；不允许退回脸测光 |
| PE hit_bound | 报“卡/场不匹配”，换卡或拆批 |
| 主体已削顶 | 物理不可逆；图级截断，记账 |
| 脸和背景同时要局部 | 分组/分次；一组蒙版只做一件事 |
| 卡本身与批不匹配 | 报“卡/批不匹配”，换卡或拆批 |
