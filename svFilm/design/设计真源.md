# 设计真源

> **唯一设计真源。** 纪律在 `纪律.md`（先读）。代码与本文冲突 ⇒ 改代码。
> 历史版本在 `_archive_20261101/`；分析/标定过程不进本文。
>
> 三句话：**选卡 → 引擎给介质基线 → LR 对齐卡 → 人目检。**

---

## 0 目的

一组人像：

1. **匹配**：从大师目录里选出**一张卡**（人拍板）；
2. **引擎**：把这张卡的胶片质感做出来（①）；
3. **LR**：补齐 ① 相对卡/peer 的**曝光 / 形状 / 肤色 / 颜色**残差，产出一张对齐卡风格、好看的照片；
4. **验收**：人目检（唯一验收）。

---

## 1 最高规则

| # | 规则 | 含义 |
|---|---|---|
| **R0** | **对齐人选的那张卡** | 卡是风格/关系的唯一目标；不是合格证，不是单点数值 |
| **R1** | **物理底线** | 人/脸死白、p1 死黑、量程、非单调、肤色崩；**背景过曝只诊断，不挡曝光/局部** |
| **R2** | **WB 目录级/组级** | 一个目录一个引擎 WB（预设/同光值）；`cast` 只诊断；同光整组共用 |
| **R3** | **先全局，后局部** | WB → 曲线形状 → 肤色局部/颜色 → 白裙 Highlights → 细节 |
| **R4** | **人优先，背景允许过曝** | 先保人/脸；背景可以过曝；脸和背景各自成立 |
| **R5** | **用关系/形状/分布** | 目标来自卡/peer 的形状比例、区域关系、背景结构；分位只做诊断 |
| **R6** | **人目检是唯一验收** | 机器只出片 + 目检页 + 诊断；不宣布“过/不过”，不代替人审片 |

卡的“关系”指明暗**形状比例**（toe/shoulder）、背景结构、`face_h/face_C`、`warm_cool_b`、色相带；  
**不是** p50/p95 中值，也不是“背景 L=30”“face L=66”这种单点。

## 2 三级架构

| 级 | 谁 | 管什么 | 频率 |
|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/化学曲线；介质按目录（卡）算 | 每目录一次 |
| **批级** | LR-A | 只报批级护栏（曲线参数 IQR/反折/预算/离散度），不下发公共曲线 | 每批一次，只报告 |
| **图级** | LR-B | 曝光/明暗、曲线、肤色、冷暖、脸/背景局部 | 每图一次 |
| — | 人 | 选卡 / 选 hero / 批边界 / 意图 / **目检（唯一验收）** | — |

边界：

- A 不决定单张亮度/曲线；只报告。
- B 不动介质/颗粒；只在 LR 里对齐卡。
- **WB 不属于 B 的逐图量**：它是卡级参数（见 `LR设计.md` §2）。
- **连续光向量用于 peer 距离**（不是四分组/标签）；四分组、`light_probe` 只做诊断；`source_deg` 只驱动光晕/柔光。

## 3 流程

```
0 原片 + 批定义（同一场 / 同一套光；跨光/跨场景先拆批）
1 读 RAW 内嵌 JPG → 每批一个 batch_content → 内容匹配选卡（人拍板卡 + hero）
2 按卡的介质 + PE 基准 + subject-face 渲 ①（只渲一次；没有 ①′）
3 测 ①（与 ③ 同一把尺子）
4 匹配 B：卡内同构图 + 连续光向量的 peer 组
   → peer 的明暗形状、背景关系、肤色 C/L 作为这张的目标
   → peer_n<3 时回退 hero 的关系值；hero 也没有 → 回退卡的关系；不拿卡中位/点值
5 LR-A：只报批级护栏（IQR/反折/预算/离散度）
6 LR-B：WB（卡级）→ 曲线形状（peer→hero→卡）→ 肤色组三轴 → 白裙检查/Highlights → 细节
   → plan_<stem>.json（带 peer_ids / target / 卡偏差）
7 执行（XMP/桥）→ ③；回读失败中止并记账
8 出参考页：③ + 卡 hero + ①；整组 ③ 并排
9 人目检：先看整体，再看脸；机器不宣布过/不过
10 记账：一图一行；人说不达标，写“哪一段没做到”，不是机器判
```

**批内一次算，不迭代；跨批才回灌。**
`--push` 是唯一例外：人明确要求时才用，每轮量 ③ 并记账，不是常规流程。

## 4 卡

**卡 = 大师成片数据库里的一个目录。** 卡不是我们建的，是从库里选的。

卡里存：

```
明暗：p5 / p50 / p95 / contrast / toe / shoulder / skew
肤色：face_L / face_C / face_h（关系，不是单点靶）
颜色：warm_cool_b / hue_bands / neutral_axis
WB：cast(a*/b*，目录级诊断) / temperature / tint（目录级引擎输入；不拿白点反解）
引擎 PE：每个内容目录一个（print_exposure；标卡时定，作 subject-face 的基准）
内容：card_content（目录级，用于匹配 A）
```

介质参数、peer 目标、逐图曲线放在卡外（介质 / peer / plan）。

- **hero**：人选的卡内代表片；① 目检参考；② peer 不足时的关系兜底：取 hero 的形状 / `face_over_bg` / 肤色 C/L / 冷暖方向作为目标。
- 整卡中位用于介质推导与风格展示；逐张目标用 peer/hero/卡关系。
- 卡内逐片目标用 peer（同构图 + 连续光向量）；peer<3 → hero → 卡关系。

### 4.1 加一张卡

```
≥8 张有脸 → 新尺子测 → 卡 + card_content + wb（中性轴/白点）
逐片 tone 进 photos_tone；peer 目标临时算，不写进卡
```

## 5 引擎

- 一次渲染：① 正式（卡的介质 + PE 基准 + subject-face）；匹配 A 用机内 JPG，不渲 ①′。
- 测光：**subject-face**（每图脸皮肤 mask）；mask 太小回退 matrix，记账；介质按目录（卡）算。
- **PE（print_exposure）是目录级基准**：每个内容目录/卡标一个；最终落点由 subject-face 在基准上定，
  PE 只作基准，不拿它当 look 目标。
- 判据：不剪死 + 质感量 + 目检；引擎只用脸 mask 测光，不修脸、不做局部。
- LR 不再重算全局曝光；① 的 subject-face 保留；Basic 0；只做曲线形状。

详见 `引擎设计.md`。

## 6 LR

**详见 `LR设计.md`。** 宪法只定：

```
引擎管卷/纸/扫描/WB/PE 基准/subject-face；LR 补齐四项残差：曝光/明暗、形状、肤色、颜色。
WB 目录级；cast 只诊断。
人/脸/皮肤高光是硬底线；背景不忽略，但不拿它压掉人；白裙允许先亮，再由人物蒙版 Highlights 压。
不重算全局 EV；① 的 subject-face 保留；不拿卡/peer 绝对分位、也不拿 Auto Tone 当靶。
Basic 四根默认 0，归通用修图；卡对齐走卡的关系，不套卡的绝对分位。
曲线只套 peer→hero→卡的肩趾比例；曲线只补形状。
Point Color 三轴：HueShift / LumScale / SatScale；在肤色局部之后算，不只改饱和。
局部顺序：肤色组（曝光 + 三轴）→ 白裙检查 → 过曝才压人物蒙版 Highlights；两组共用人物选择。
补脸只抬；余量用肤色窗自己的；肤色窗没落成 ⇒ 停。
卡对齐用卡的关系（明暗形状/脸-背景/肤色 C/L/冷暖方向/色相带/介质/WB/PE）。
```

---

## 7 交付与目检

```
机器只做：出片 ③ + 目检页 + 测量（诊断）
人做：目检；人说“过”才是过；人说“不过”就写哪一段不对
```

- 物理测量用来**定位事故**（死白/p1/肤色崩），报告事实；
- 卡对齐用来**描述偏差**（哪一项、差多少）；
- 人目检是唯一验收；机器出片 + 参考页 + 诊断。

## 8 失效清单

| 情况 | 处置 |
|---|---|
| 批内异质（两套光/场景/服装） | 先拆批；每批一个 batch_content |
| 无中性面 | WB 做保守偏移，记账 |
| 无脸 / 脸太小 | 跳过图级脸修正，记账 |
| peer_n<3 | 回退 hero 的关系值；hero 也没有 → 回退卡关系；记账 |
| 主体已削顶 | 物理不可逆；图级截断，记账 |
| 脸和背景同时要局部 | 分组/分次；一组蒙版只做一件事 |
| 卡本身与批不匹配 | 报“卡/批不匹配”，换卡或拆批 |
