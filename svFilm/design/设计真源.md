# 设计真源（2026-10-30 · 三级对齐版）

> **唯一执行真源**。代码与本文冲突 ⇒ **改代码**。
> 三句话：**引擎给介质基线 · LR 批级收风格残差 · LR 图级收关系残差 · 人目检**。
> 证据：`cond_bands_v2.json` / `cond_table_鹿井.json`（672 张鹿井，新尺子）。
> 旧版：`_archive_设计真源_20261030.md`。

---

## 0 目的

一组人像 → 匹配卡（人拍板）→ 引擎出质感 → LR 出风格 → 人好看。

1. **匹配**：排序出候选大师目录（一张卡 = 一个目录），**人拍板一张**。
2. **引擎**：把这张卡的**胶片质感**做出来。
3. **LR**：对齐这张卡的**曝光规律 / 颜色特点 / 明暗层次 / 冷暖层次**，并保证**人好看**。
4. **全程**：人优先，但背景同样要成立。

---

## 1 原则

| # | 原则 | 执行含义 |
|---|---|---|
| **P1** | **不打数值靶** | 卡给带 / 关系 / 形状 / 配比；判"在不在带内"；多解取**动得最少**的 |
| **P2** | **先查资料再定系数** | 优先公开公式 / 文档 / 开源实现；查不到才标定，且写清"对哪个量、哪张图、几档" |
| **P3** | **每步都对齐卡上的量** | 说不出"对齐卡的哪一项"，这一步不许存在（物理不变量除外） |
| **P4** | **人优先 ≠ 背景可牺牲** | 脸先修；背景爆白/死黑同样算错，排在后面 |

三条检验：平移检验（卡带平移 2 L\*，输出跟着变 ⇒ 打靶）· 常数检验（五类之一）· 指认检验（写出卡字段名）。

## 2 三级对齐（架构）

| 级 | 谁 | 管什么 | 判据 | 频率 |
|---|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/锐度/化学曲线 = **材质签名** | 质感量（**待补**）+ 目检 | 每语料一次 |
| **批级** | LR-A | 颜色（中性/肤色）、明暗层次（曲线）、冷暖 | **卡的不变量带** | 每批一次，**全批中位、全批同参** |
| **图级** | LR-B | 曝光、脸÷背景、白端/黑端 | **条件表** + 物理 | 每图 |
| — | 人 | 选卡 / 意图 / 目检 | 好看 | — |

**三条边界**（这三条把"互相打架"从结构上消掉）：

```
① 空间：A 只用全局旋钮；B 用唯一那一组蒙版（MASKPARAM 只能写第 1 组）
② 时间：A 每批一次；B 每图一次
③ 物理量：A **不动亮度**（曲线保持 p50）；B **不动颜色**
   ⇒ A 改形状/颜色，B 改亮度/关系，两者永不重叠
```

**为什么这么切**（`eta²`，鹿井 672 张）：

| 量 | 卡解释 | 光位解释 | 归谁 |
|---|---|---|---|
| `warm_cool_b` | 0.418 | 0.018 | A（批级） |
| `contrast` | 0.412 | 0.075 | A |
| `face_C` / `face_h` | 0.328 / 0.287 | 0.035 / 0.003 | A |
| `face_over_bg` | 0.235 | **0.298** | B（图级） |
| `face_L` | 0.347 | **0.414**，其余 59% 不可解释 | B 的**弱约束**，只做护栏 |

## 3 证据：能对齐什么、对不齐什么

### 3.1 条件表（P25–P75，语料级，**不按卡**）

| 光位 | n | `face_over_bg` | `face_L` | 可用 |
|---|---|---|---|---|
| `back` 逆光 | 84 | **0.53–0.60** | 47.1–54.5 | ✅ |
| `mid` 中间 | 406 | 0.68–0.78 | 59.0–66.7 | ✅ |
| `front` 顺光 | 152 | **0.89–1.08** | 65.7–73.0 | ✅ |
| `unknown` | 30 | 0.67–0.83 | 57.1–68.3 | 只报 |

**旧法用全局中点 0.85 当目标：逆光类偏高 +50%、顺光类偏低 −14%** —— 同一个常数在两个分布上方向相反，这是点靶的必然错误。

### 3.2 对不齐的部分（写死，别再试）

- **天空不是条件**（747 张只有 10 张有天空，eta²≈0）。
- **第二维候选全部无效**（主体占比 / 环境占比 / 近场比 / 背景结构：`face_L` 只从 0.414 抬到 0.420）。
- **脸的绝对亮度**：59% 是大师自己的选择，任何条件表都预测不了。
- **小语料没有条件表**：滨田 15 张（0/8/7）、xhs 59 张（6/15/9），每格 <30 ⇒ 不可用，只能"全局带 + 目检"。

## 4 卡（两层）

### 4.1 不变量层（与光位无关，卡间可分）

`contrast` · `toe/shoulder/contrast_win/skew` · `face_C/face_h` · `warm_cool_b` · `hue_bands` · `neutral_axis` · 质感（**现缺**）。
用途：**LR-A 的目标**（批级）。

### 4.2 条件表指针（语料级）

卡里只存 `cond_table` 的键（语料名），不存表本身 —— 一张卡 8–20 张图，撑不起分位数。
用途：**LR-B 的目标**（图级）。

### 4.3 卡里没有的

| 缺 | 后果 |
|---|---|
| 质感量（颗粒/锐度/光晕/色云） | 目的 2 只能按语料三档 |
| 人/背景分开的 clip | 只能整幅对齐 |
| 轮廓亮边的带 | 只能记账 |

### 4.4 介质从哪来

```
鹿井 / 滨田 → kodak_portra_400 + kodak_portra_endura
xhs        → kodak_gold_200  + kodak_portra_endura   ← 与 presets/xhs预设 一致
```

### 4.5 加一张卡

```
≥8 张有脸 → 新尺子测 m_<语料>_v4.json → cards_v4（两层）→ 条件表用所属语料的
```

## 5 分工

| | 引擎 | LR-A（批级） | LR-B（图级） | 人 |
|---|---|---|---|---|
| 管 | 介质·质感·化学曲线·自己的测光 | 颜色/明暗层次/冷暖的**残差** | 曝光/关系/白黑端 | 选卡·意图·目检 |
| 输入 | 卡（→语料→介质）+ 原片 | 全批 ① 的**中位** | 单张 ① + 条件表 + 光位 | — |
| 输出 | ① + `engine_params.json` | `batch_grade.json`（全批同参） | `plan_<stem>.json` | 拍板 |
| 不动 | 逐图落点·白端·分级 | **亮度**（曲线保持 p50） | **颜色** | 数值 |
| 失败算谁的 | 整批同向出带 / 质感不像 | 批内颜色一致偏离 | 单图比值出带 | — |

## 6 引擎流程（介质级）

```
① 选介质：卡 → 语料 → 预设（xhs 映射要修）
② 质感：颗粒 rms / blur / dye / halation / USM / 柔光
   目标 = 卡的质感量（**现缺**）⇒ 现在用预设值 + 记账"未对齐"
③ 测光：中灰归一（锚 0.184），只保证余量一致、不剪死；不追逐图落点
④ 物理：p1 / clip 不剪死（引擎底线）
⑤ 输出 ①（16bit）+ engine_params.json（介质/质感/口径 sha）
```

**判据**：不剪死 + 质感量（待补） + 目检。
**不管**：逐图亮度、白端、颜色分级、冷暖。

★ 这条腿是"像不像"的主体（风格层卡解释 0.33–0.42），也是当前最大的缺口：**卡里没有质感量，所以目的 2 只能"按语料三档"**。要真对齐，卡必须补三个成片域的量：颗粒中频能量、MTF50、光晕半径。

## 7 LR 流程（A / B / C）

### 7.1 A 段：批级（一次，全批中位、全批同参）

```
输入：全批 ① 的测量 → 每个量取中位（抗单张异常）
算：WB（中性轴）· 曲线形状（toe/shoulder/contrast_win）· 肤色 C/h · 冷暖方向与强度
约束：曲线保持 p50 不动；HSL 不动 L；冷暖强度来自卡的 warm_cool_b 带
判据：卡的不变量带（出带才动，动到带边）
输出：batch_grade.json（一份，全批共用）
异常：批内 IQR 超过卡带宽 ⇒ 报告"批内异质"，先拆批，不许硬套一个分级
```

### 7.2 B 段：图级（逐图）

```
输入：单张 ① → 光位标签（从 ① 判，不能从 ③ 判）→ 条件表
算：六格决策（比值低/高 × 脸低/在带/高）
判据：条件带（偏出 > 半个带宽才动）+ 物理（死白/p1）
输出：plan_<stem>.json（光位、条件带、决策格、预测值）
```

六格：

| 情形 | 动谁 |
|---|---|
| 比值低 + 脸也低 | 主体局部（一次改两个量） |
| 比值低 + 脸在带内 | 背景压暗（保脸） |
| 比值高 + 脸也高 | 主体局部压暗 |
| 比值高 + 脸在带内 | 只记账 |
| 比值在带 + 脸显著偏 | 全局曝光（保比值） |
| 其余 | 不动 |

### 7.3 冷暖：**批级参数、图级应用**（已拍板）

它必须用背景蒙版（全局阴影轮漏脸 0.13 b\*/点），而蒙版一组只能用一次。
所以：**方向与强度由 A 按卡算好，写进 `batch_grade.json`；真正落到蒙版发生在 B**——哪张图要用蒙版，就顺手把这份冷暖挂上去。
代价：批级参数与图级执行不完全同步（某张图不需要蒙版时，冷暖要么不做、要么用全局并接受漏脸）。**这条要记账，不许悄悄换。**

### 7.4 C 段：验收（一次）

```
测 ③ → 逐项报"在带内 / 出多少（相对带宽）" → 预测 vs 实测 → 目检
```

### 7.5 顺序

```
A（形状/颜色，不动亮度） → B（亮度/关系，不动颜色） → C
```

**一次算**：全部用前向模型预测后写参数，不导出回看。预测误差必须报（今天 ±50%）。

## 8 判据与约束

```
判决   物理（死白 / p1 / 量程 / 单调）—— 破了就是错，没有"接近"
约束   卡带 / 条件带 —— 出带且**偏出 > 半个带宽**才动，动到带边；交付逐项报，不排名
死区   量化下限（u8 一个编码：L* ≈ 0.4、a/b ≈ 0.5、C ≈ 0.2）—— 小于一格不动
```

- **判决只有两条：物理 + 目检。** 卡带是求解约束，不是合格证。
- **匹配可以用卡的中位**（那是"像不像"的度量）；**求解不许用中点**（只能出带才动）。

## 12 变更纪律（这一节专治"迭代太多版"）

```
12.1 一条链
   一个实现（design/ 包）· 一把尺子（measure sha）· 一份真源（本文件）。
   出现第二套（临时脚本 / 旧口径 / 复制文档）⇒ 当天删或标废。

12.2 预注册（跑之前先写）
   预期结果 / 失败条件 / 最多渲几次。
   跑完只做"预测 vs 实测"；对不上就改模型，**不许当场改参数再跑**。
   上限：一轮 10 次渲染；超了必须停下来写原因（今天 40+ 次就是这么来的）。

12.3 误差预算（决定"值不值得动"）
   前向模型 ±50%；条件带半宽通常 3–6 L*（≈20–30%）。
   ⇒ 任何小于模型误差的差异，**不做决策**；带内不排名、不微调、不追"更接近"。

12.4 改动分级（越级 = 违规）
   介质级：卷/纸/颗粒/锐度 —— 人拍板，改一次重跑全量
   批级：WB/曲线/肤色/冷暖强度 —— 可试，一次算，全批同参
   图级：曝光/关系/白黑端 —— 自动，只动关系，不碰颜色

12.5 删除机制
   每条新规则必须：替换一条旧规则，或进 §14 已废。只加不删不算改完。

12.6 判决与数字分离
   判决 = 物理 + 目检；数字只报。禁止"硬门 10/10 就算好"。

12.7 一次只改一级
   跨级同时改 ⇒ 结果不可归因，等于没做。
```

## 13 失效清单（做了也会失效）

| 情况 | 为什么 | 处置 |
|---|---|---|
| 批内异质（一套两种场景） | 批级中位会平均掉 | 报 IQR，拆批 |
| 条件格 n<30 | 分位数不稳 | 不给带，只报（滨田/xhs 现状） |
| 无脸 / 脸太小 | 判据全基于脸 | 跳过图级，记账 |
| 无中性面 | 色锚不可信 | 只做保守修正 |
| 主体已削顶 | 物理不可逆 | 图级截断 |
| 冷暖与提脸同时要蒙版 | 一组蒙版 | 二选一，记账 |
| 前向模型 ±50% | 大动作会偏 | 动到带边即止，不追中点 |
| 质感量缺失 | 目的 2 无输入 | 只按语料，记账 |
