# 第一部分 · 纪律

> 优先级：**脸（主体）> 背景高光 > 其它**。任何一步把脸压暗就是做错。
> 换卷/换纸 = **人的决定**；让引擎改曝光或多留余量 = **越界**；
> 收白收不住 ⇒ **接受背景过曝**，不回引擎。

## 六条铁律

1. **不许打数值靶**。数值只用于：定位问题 / 卡物理边界 / 判过不过的门槛。
   阈值只能来自：**量化下限 · 物理不可逆 · 生理常识 · 大师实测区间**。
2. **不许为单张/单批打补丁**。参数只挂三层：**卷纸 · 场景类 · 意图**；
   代码里不许按 stem / 文件名 / "这批都欠曝" 分支。
3. **先查资料再定系数**。查四类：GitHub 实现 · 论坛/厂商文档 · 专利 · 论文。
   查不到就明说"没有公开闭式"，**不许编斜率**；只给方向 + 一档步进。
4. **不许乱跑**。LR 只在**出 ③ 成片**时驱动；引擎先试点 2 张；测量默认 10~30 张 + 看图。
   跑之前写**代价 + 预期**，跑完只做"预测 vs 实测"，不许当场改参数再跑。
5. **先出成片，再量，再目检**。①≠成片；五段走满：引擎出片 → LR ②③ → 导出 ③ → 量 ③ → 目检。
   目检一页 HTML、竖排占满宽、不拼网格；链接独占一行。
6. **分工不许越界**：
   | 层 | 只许管 | 不许碰 |
   |---|---|---|
   | 引擎 | 卷/纸/颗粒/光晕/柔光/自己的测光/报余量/白点 | 逐图曝光落点、明暗分布、颜色 |
   | LR | 看哪里、曝光落点、收白、曲线、饱和、肤色 | 卷纸质感、颗粒 |
   | 人 | 意图（亮/暖/浓/软）、审片 | 具体参数 |

两条硬边界：**引擎不管脸、不管落点**；**算值不依赖 LR**（公式可查、可离线复算）。

## 不达标怎么归因

只有一种结论：**流程或实现哪一段没做到**。
"场景没余量 / 素材不行 / 换纸 / 这张本来就过曝"只能是现象描述，不能是结论。
每条"不达标"后面必须写"漏在哪一段"。

## 每轮标准动作

```
1 设计对齐（不动代码/不跑/不谈参数）→ 2 写代码+单测（先钉判据）→
3 五段出片 → 4 量 ③（只定位，不宣布对错）→ 5 目检（先看图）→
6 不达标→找漏（回 1/2）→ 7 记账（只写真源）
```


## 复核四条（重复踩过的坑）

1. **同名必须同义**：一个词进判据前写清"代表什么 / 有哪些同名版本 / 用哪个"。
2. **系数必须带样本**：写清 `n 张图 · 哪几张 · 几档`；**n<5 只进台账，不进常数**。
3. **一处真源**：一条规则只许一处定义；废掉的证据是旧句 grep 不到。
4. **无调用者＝未实现**：死参数/死分支/读不回来的回读，当场删或标"未接线"。

## LR 数值（先查资料，查不到才自标定）

```
① 单位换算（EV/4、UI/100、+1档=×2）      ⇒ 写死，注明定义
② 标准量换算（L*↔Y↔EV↔sRGB 码、分位数）  ⇒ 用定义式，禁止斜率乘档数
③ 有公开传递函数？                        ⇒ 用公式（目前没有一根 Basic 滑杆有）
④ 有成熟开源实现？                        ⇒ 先过本方小矩阵；不过只作参考
⑤ 只有 n<5 实测？                         ⇒ 进 LEDGER，只预测不剂量
⑥ 都没有？                                ⇒ 方向 + 一档（10 UI）+ ③ 验，记账
```

**判据**：代码里出现 `X L*/点` / `X L*/档` 的绝对系数，先问它是①~⑥哪一类；
答不上来就是⑥，不许写。分析模型只许放 `analysis/`，**生产不 import**。

# 第二部分 · 设计

## 0 目的

一组人像 → 匹配卡（人拍板）→ 引擎出质感 → LR 出风格 → 人好看。

1. **匹配**：排序出候选大师目录（一张卡 = 一个目录），**人拍板一张**。
2. **引擎**：把这张卡的**胶片质感**做出来。
3. **LR**：对齐这张卡的**曝光规律 / 颜色特点 / 明暗层次 / 冷暖层次**，并保证**人好看**。
4. **全程**：人优先，但背景同样要成立。

---

## 1 原则

| # | 原则 | 执行含义 |
|---|---|---|
| **P1** | **不打数值靶** | 卡给带 / 关系 / 形状 / 配比；判"在不在带内"；多解取**动得最少**的 |
| **P2** | **先查资料再定系数** | 优先公开公式 / 文档 / 开源实现；查不到才标定，且写清"对哪个量、哪张图、几档" |
| **P3** | **每步都对齐卡上的量** | 说不出"对齐卡的哪一项"，这一步不许存在（物理不变量除外） |
| **P4** | **人优先 ≠ 背景可牺牲** | 脸先修；背景爆白/死黑同样算错，排在后面 |

三条检验：平移检验（卡带平移 2 L\*，输出跟着变 ⇒ 打靶）· 常数检验（五类之一）· 指认检验（写出卡字段名）。
**纪律只有一处：本文件第一部分。**

---

## 2 三级对齐（架构）

| 级 | 谁 | 管什么 | 判据 | 频率 |
|---|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/锐度/化学曲线 = **材质签名**（介质**由系统按批算**，人只选卡） | 介质匹配结果 + 不剪死 | **每批一次** |
| **批级** | LR-A | 颜色（中性/肤色）、明暗层次（曲线）、冷暖的**参数** | **卡的不变量带** | 每批一次，**全批中位、全批同参** |
| **图级** | LR-B | 曝光、脸÷背景、白端/黑端、冷暖的**落地** | **条件表** + 物理 | 每图 |
| — | 人 | 选卡 / 批边界 / 意图 / 目检 | 好看 | — |

**三条边界**：

```
① 空间：A 只用全局旋钮；B 用唯一那一组蒙版（MASKPARAM 只能写第 1 组）
② 时间：A 每批一次；B 每图一次
③ 物理量：A 不动亮度（曲线保持 p50）；B 不做颜色修正（WB / HSL / 肤色）
   ★ 例外：冷暖分级必须用背景蒙版，参数由 A 算、落地在 B（`LR设计.md` §4）
```

**为什么这么切**（`eta²`，鹿井 672 张）：

| 量 | 卡解释 | 光位解释 | 归谁 |
|---|---|---|---|
| `warm_cool_b` | 0.418 | 0.018 | A |
| `contrast` | 0.412 | 0.075 | A |
| `face_C` / `face_h` | 0.328 / 0.287 | 0.035 / 0.003 | A |
| `face_over_bg` | 0.235 | **0.298** | B |
| `face_L` | 0.347 | **0.414**，其余 59% 不可解释 | B 的**弱约束**，只做护栏 |

## 3 流程与闭环

### 3.1 端到端

```
0 原片 + 批定义（人确认：同一场 / 同一套光；跨场景必须拆批）
1 引擎试点 2 张（**基线介质** = 引擎默认配对 portra_400 + portra_endura，只为把原片送进成片域）→ 报代价 → 人点头
2 全批渲基线 ①′（**只为匹配**）→ 转成交付域（sRGB/1080/JPEG）→ 测
3 匹配：**候选生成器**（不追求精确排序，只要人想选的卡在前 5 里）——不变量层的中位/分布 → 候选 5 张（每张 3–6 张样片 + 理由 + 代价）→ 人**同时拍板两件事**：选哪张卡 + 指定哪张样片当 **hero**
   · 候选都不像 ⇒ 换候选集，记账；不许硬选
4 按 §4.4 算出的介质渲 ①（与基线同介质就复用 ①′，否则重渲）
5 测 ① 的**交付域副本**（预测用；与 ③ 同一把尺子，sha 登记）
6 LR-A：全批 ① 中位 → batch_grade.json → 人过一眼（只改意图，不改数值；意图只记账，幅度未标定前不加偏置）
7 LR-B：逐图 → plan_<stem>.json
8 执行（桥/XMP）→ ③；回读失败立刻中止并记账，不许静默
9 测 ③ → 验收表 + 预测 vs 实测 + 目检页 → 人拍板"过 / 不过"
10 记账：一图一行；"不过"按 §3.3 归因，**本批不再导出**，下一批改
```

### 3.2 批的定义（中位的前提）

**一批 = 同一次拍摄 / 同一套光**。批内异质（两种场景混在一起）时，中位没有意义——
LR-A 必须先报"IQR 超卡带宽"，由**人**决定拆不拆批。

### 3.3 闭环

```
图级出带 ──→ 账本 ──→ 验收按光位分组看方向
                        │
                        ├─ 方向混合 ⇒ 单图差异，本批到此为止
                        └─ 整批同向 ⇒ 系统偏差 ⇒ 归上游（引擎 / 选卡），下一批处理
```

**批内一次算、不迭代；跨批才回灌**。这是唯一的闭环，也是"少折腾"的结构保证。

### 3.4 候选页：人只在这两处拍板

```
1 选卡：5 张候选 —— 每张把**该目录下的全部大师作品**摆出来（网格缩略图，一张不少）
          + 理由（像 / 不像 / 数值偏）+ 代价
2 选 hero：在选中的那张卡里点一张（从全部作品里选）—— 这一批的 look 参考
记录：batch 元数据写 card + hero 两个字段；后面所有步骤只认这两个
```

★ 缩略图长边 480 就够（手机上看）；点开才出 1080 大图。
★ 全部作品 = 8–20 张/卡 × 5 张卡 = 最多 100 张缩略图；**不许只给前 3 张**（前 3 张不是这张卡的代表）。

## 4 卡

**卡 = 大师成片数据库里的一个目录**（60+ 个，已经测量好）。

```
给一批自己的图 → 按匹配权重排序 → 前 5 个目录（带样片/理由/代价）→ **人拍板**
→ 选中的那个目录，就是这张卡
→ 引擎与 LR 的求解目标**都只有这一张卡**
```

卡不是"我们建出来的"，是**从库里选出来的**；它的数据就是那个目录的测量。

### 4.1 不变量层（与光位无关，卡间可分）

`contrast` · `toe/shoulder/contrast_win/skew` · `face_C/face_h` · `warm_cool_b` · `hue_bands` · `neutral_axis`（高频 grain 只记档；**空间族不按卡量**，用固定值）
卡文件：`_corpus/kurai/full/cards_v4.json`（现在是 `cards_v3.json`，待重建）。

- 用途 1：**hero 样片只做目检参考**——**由人选卡时一起指定**（从**该目录全部作品**里点一张）；**数值目标仍是卡的不变量带**，A 不拿 hero 做拟合。
- 用途 2：**匹配的画像**——用中位/分布距离排序。**匹配用中位合法，求解用中点非法**（§8）。

★ 卡**不带介质字段**：介质由系统按批算（§4.4）；卡只带测量出来的东西。

### 4.2 条件形状（模型级，不是卡的字段）

```
光位 → face_over_bg 的**相对形状**（back / mid / front 的中位与半宽），由**全部卡**统计得到；
卡只存自己的带；B 段把"条件形状"套在**这张卡的带**上。
```

一张卡 8–20 张图撑不起分位数 ⇒ 条件形状只能是**模型**，不能写进卡。
这是唯一一处"跨卡共享"的东西——它是**统计模型**，不是任何卡的默认值。

### 4.3 卡里没有的

| 缺 | 后果 |
|---|---|
| 人/背景分开的 clip | 只能整幅对齐（§15-2） |
| 轮廓亮边的带 | 只能记账（§15-3） |

### 4.4 介质从哪来（系统按批算，人只选卡）

```
候选：profile 的 target_print 配对（Kodak 卷 → Portra Endura；Fuji 卷 → CAII），约 6–16 组
做法：本批 1–2 张代表图 × 每个候选 → 渲 → 量
      contrast / toe / shoulder / face_C / face_h / warm_cool
      → 与**这张卡的带**比距离 → 最近者
基线：预演之前先用默认配对 portra_400 + portra_endura 渲 ①′（只为把原片送进成片域）
诚实：10-19 的"留一图不稳"是针对"给大师挑身份"；这里是"给这批图挑最接近这张卡的介质"，
      目标不同；差距 <10% 时报并列，不硬选
```

### 4.5 加一张卡

```
≥8 张有脸 → 新尺子测 → 卡（不变量带 + hero 样片 + 自己的 clip）
条件形状用模型，不写进卡
```

| | 引擎 | LR-A（批级） | LR-B（图级） | 人 |
|---|---|---|---|---|
| 管 | 介质·质感·化学曲线·自己的测光 | 颜色/明暗层次/冷暖的**参数** | 曝光/关系/白黑端/冷暖的**落地** | 选卡·批边界·意图·目检 |

## 6 引擎（介质级）

**怎么做见 `引擎设计.md`。** 宪法只定三件事：

```
两种渲染：①′ 基线（只为匹配）· ① 正式（卡的介质）
测光只保证"余量一致 + 不剪死"；介质**由系统按批算**，质感按 profile / 标定
判据：不剪死 + 质感量（尚未定义）+ 目检
```

★ 这是"像不像"的主体（风格层卡解释 0.33–0.42），也是当前最大缺口。

---

## 7 LR（A / B / C）

**怎么做见 `LR设计.md`。** 宪法只定顺序与边界：

```
A（批级）：**hero 只做目检参考**；数值目标 = 卡的不变量带。只动颜色 / 曲线形状 / 冷暖参数，**不动亮度**（曲线保持 p50）
          三个保护：肤色（只动 S/H、L 不动）· 饱和（不越卡带）· 对比（曲线不反折、不动 p50）
B（图级）：只动曝光 / 关系 / 白黑端 + 冷暖落地，**不动颜色修正**
C（验收）：测 ③ → 在带 / 出多少 → 预测 vs 实测 → 目检
顺序 A → B → C；一次算，不导出回看（预测误差必须报）
```

六格决策、公式、机理成熟度表：见 `LR设计.md` §3 / §6。

## 8 判据与约束

```
判决   物理（死白 / p1 / 量程 / 单调）—— 破了就是错，没有"接近"
约束   卡带 / 条件带 —— 出带且**偏出 > 半个带宽**才动，动到带边；交付逐项报，不排名
死区   量化下限（u8 一个编码：L* ≈ 0.4、a/b ≈ 0.5、C ≈ 0.2）—— 小于一格不动
```

- **判决只有两条：物理 + 目检。** 卡带是求解约束，不是合格证。
- **匹配可以用中位/分布**（"像不像"的度量）；**求解不许用中点**（只能出带才动）。

## 9 通道能力表（接口事实，别再推）

| 能力 | 事实 | 后果 |
|---|---|---|
| 蒙版组 | `MASKPARAM` 只写第 1 组 | 一图一组；见 §2 边界① |
| 局部曝光刻度 | `LocalExposure2012 = EV/4` | 直接换算 |
| 回读 | 回读 nil ≠ 没写（成片里 `LocalShadows2012="1"` 落下了） | 以成片 XMP/测量为准 |
| 局部选择性 | `LocalShadows` 满档：人 p99 +0.1；`LocalExposure` 1 档：p99 +11.2（未饱和）/ +1.3（已撞 100） | "局部必爆"不是物理；这两个数是 n=2 观察，不是常数 |
| 桥写值 | `MASK ... LocalExposure2012=` 不落地，必须 `MASKPARAM` | — |
| A/B 合写 | 两段的键不重叠（A：曲线/颜色；B：曝光/蒙版） | 合并成一份 XMP 再写；写后整份回读校验 |

## 10 常数（没有"被测量"列的不算常数）

> 生产只保留两类数——**单位换算** + **标准定义式**。
> 没有公开传递函数的旋钮（Highlights/Shadows/Whites/Blacks/Contrast、局部饱和、
> 局部 Shadows、冷暖）：**方向 + 一档（10 UI）+ ③ 验**，不建模、不外推。
> 分析模型只放 `analysis/corpus/kurai/_lr_models/`，**不进生产**。
> 证据见 `LR数值来源.md`。

**单位换算（定义，不是标定）**

| 换算 | 值 | 依据 |
|---|---|---|
| `LocalExposure2012` 文件值 | EV/4（4 档 = 满刻度 1.0） | autoshade 实测 |
| 局部其余滑杆文件值 | UI/100 | 同上 |
| 全局 Exposure | +1 = 线性光 ×2 | Adobe：f-stop 增量 |

**一档政策（没有公开传递函数时）**

| 旋钮 | 触发 | 剂量 |
|---|---|---|
| 全局 Whites | 曝光/曲线后 p95 仍 > 卡肩 | **−10 UI**，③ 验 |
| 局部 Saturation | 脸 C 出卡带 | **±10 UI**，③ 验 |
| 冷暖（SplitToning） | `warm_cool_b` 出卡带 | 两轮各 **10 点**，色相成对 |
| 局部 Shadows / LocalHighlights | — | **只记账**，不动（除非 ③ 明确要） |

分析证据与已删常数见 `LR数值来源.md`；**不进生产**。

## 11 测量、账本与验收

### 11.1 测什么

口径、字段、尺子质量见 `测量设计.md`。宪法只定"必算什么"和"同尺子"。

| 级别 | 量 |
|---|---|
| 必算 | 脸 L/C/h · 背景 p90 · clip（整幅 + 人/背景）· 脸内死白 · p1 · `gap`+`dark`（光位） |
| 按需 | `near_bg` · 中性面 · `rim` 分位 |

**只有一套光位标签**（`back/mid/front`，双区判据）。检测不是判据。
**①（含基线 ①′）与 ③ 必须同一个 measure sha**，否则拒收。

### 11.2 账本与验收

字段与产物见 `LR设计.md` §7。宪法只要求三条：**一图一行 · 出带必记账 · 预测 vs 实测同屏**。

## 12 失效清单（做了也会失效）

| 情况 | 为什么 | 处置 |
|---|---|---|
| 批内异质 | 批级中位会平均掉 | 报 IQR，交人拆批 |
| 条件格 n<30 | 分位数不稳 | 不给带，只报 |
| 无脸 / 脸太小 | 判据全基于脸 | 跳过图级，记账 |
| 无中性面 | 色锚不可信 | 只做保守修正 |
| 主体已削顶 | 物理不可逆 | 图级截断 |
| 冷暖与提脸同时要蒙版 | 一组蒙版 | 二选一，记账 |
| 前向模型 ±50% | 大动作会偏 | 动到带边即止 |
| 介质预演差距并列（<10%） | 选不出唯一 | 报并列，交人目检定 |
