# 设计真源

> **设计唯一真源**。**纪律在 `纪律.md`（先读，不读不做）**；代码与本文冲突 ⇒ **改代码**。历史版本在 git 里查。
> 三句话：**引擎给介质基线 · LR 批级定骨架 · LR 图级补参差 · 人目检**。
> 证据：`cond_bands_v2.json` / `cond_table_鹿井.json`（672 张鹿井，新尺子）。

---

## 0 目的

一组人像 → 匹配卡（人拍板）→ 引擎出质感 → LR 出风格 → 人好看。

1. **匹配**：排序出候选大师目录（一张卡 = 一个目录），**人拍板一张**。
2. **引擎**：把这张卡的**胶片质感**做出来。
3. **LR**：对齐这张卡的**曝光规律 / 颜色特点 / 明暗层次 / 冷暖层次**，并保证**人好看**。
4. **全程**：人优先，但背景同样要成立。

---

## 1 原则

| # | 原则 | 执行含义 |
|---|---|---|
| **P1** | **不打数值靶** | 卡给关系 / 形状 / 配比 / 规律；用公式算落点，再对到卡的关系/形状；多解取**动得最少**的 |
| **P2** | **先查资料再定系数** | 优先公开公式 / 文档 / 开源实现；查不到才标定，且写清"对哪个量、哪张图、几档" |
| **P3** | **每步都对齐卡上的量** | 说不出"对齐卡的哪一项"，这一步不许存在（物理不变量除外） |
| **P4** | **人优先 ≠ 背景可牺牲** | 脸先修；背景爆白/死黑同样算错，排在后面 |

三条检验：平移检验（把卡的关系/形状整体平移，输出跟着变 ⇒ 打靶）· 常数检验（有出处/样本）· 指认检验（写出卡字段名）。
**纪律只有一处：`纪律.md`；本文只写"怎么做"。**

## 2 三级对齐（架构）

| 级 | 谁 | 管什么 | 判据 | 频率 |
|---|---|---|---|---|
| **介质级** | 引擎 | 卷/纸/颗粒/光晕/锐度/化学曲线 = **材质签名**（介质**按目录（卡）算**，人只选卡） | 介质推导依据 + 不剪死 | **每目录一次** |
| **批级** | LR-A | 明暗层次（曲线）、冷暖的**方向**；颜色只给方向不落地 | **卡的不变量（关系/形状）** | 每批一次，**全批同一条曲线** |
| **图级** | LR-B | 曝光、脸÷背景、白端/黑端、**颜色（肤色 H/S/L、冷暖落地）** | **条件形状** + 物理 + 每张自己的颜色残差 | 每图 |
| — | 人 | 选卡 / 批边界 / 意图 / 目检 | 好看 | — |

**三条边界**：

```
① 空间：A 只用全局旋钮；B 用唯一那一组蒙版（MASKPARAM 只能写第 1 组）
② 时间：A 每批一次；B 每图一次
③ 物理量：A 不动亮度（曲线保持 p50）；**B 做颜色修正**（肤色饱和 · 冷暖落地）
```

**为什么这么切**（`eta²`，鹿井 672 张）：

| 量 | 卡解释 | 光位解释 | 归谁 |
|---|---|---|---|
| `warm_cool_b` | 0.418 | 0.018 | A 给方向 / B 落地 |
| `contrast` | 0.412 | 0.075 | A |
| `face_C` / `face_h` | 0.328 / 0.287 | 0.035 / 0.003 | B（逐图） |
| `face_over_bg` | 0.235 | **0.298** | B |
| `face_L` | 0.347 | **0.414**，其余 59% 不可解释 | B 的**弱约束**，只做护栏 |

## 3 流程与闭环

### 3.1 端到端

```
0 原片 + 批定义（人确认：同一场 / 同一套光；跨场景必须拆批）
1 引擎试点 2 张（**基线介质** + 基线 PE，只为把原片送进成片域）→ 报代价 → 人点头
2 全批渲基线 ①′（**只为匹配**）→ 转成交付域（sRGB/1080/JPEG）→ 测
3 匹配：**候选生成器**（不追求精确排序，只要人想选的卡在前 5 里）——不变量层的中位/分布 → 候选 5 张（每张摆该目录全部作品 + 理由 + 代价）→ 人**同时拍板两件事**：选哪张卡 + 指定哪张样片当 **hero**
   · 候选都不像 ⇒ 换候选集，记账；不许硬选
4 按 §4.4 算出的介质渲 ①（与基线同介质就复用 ①′，否则重渲）
5 测 ① 的**交付域副本**（预测用；与 ③ 同一把尺子，sha 登记）
6 LR-A：全批 ① 中位 → 一条曲线 + 冷暖**方向**（batch_grade.json）→ 人过一眼；颜色**不在这里落地**
7 LR-B：逐图 → 曝光/关系/白黑端 + **颜色补差（肤色 H/S/L、冷暖落地）** → plan_<stem>.json
8 执行（桥/XMP）→ ③；回读失败立刻中止并记账，不许静默
9 测 ③ → 验收表 + 预测 vs 实测 + 目检页 → 人拍板"过 / 不过"
10 记账：一图一行；"不过"按 §3.3 归因，**本批不再导出**，下一批改
```

### 3.2 批的定义（中位的前提）

**一批 = 同一次拍摄 / 同一套光**。批内异质（两种场景混在一起）时，中位没有意义——
LR-A 必须先报"批内离散度过大"，由**人**决定拆不拆批。

### 3.3 闭环

```
图级对齐 ──→ 账本 ──→ 验收按光位分组看方向
                        │
                        ├─ 方向混合 ⇒ 单图差异，本批到此为止
                        └─ 整批同向 ⇒ 系统偏差 ⇒ 归上游（引擎 / 选卡），下一批处理
```

**批内一次算、不迭代；跨批才回灌**。这是唯一的闭环，也是"少折腾"的结构保证。

★ **唯一例外：`--push`（推一档）**。它量上一轮的 ③、把这一轮的剂量累加上去，
用于"滑块没有公开刻度、只能一轮一档"的标定期。**它故意违反"批内不迭代"**，
所以：只在人明确要求时跑；不是常规流程；每轮都要重新量 ③ 并记账。

### 3.4 候选页：人只在这两处拍板

```
1 选卡：5 张候选 —— 每张把**该目录下的全部大师作品**摆出来（网格缩略图，一张不少）
          + 理由（像 / 不像 / 数值偏）+ 代价
2 选 hero：在选中的那张卡里点一张（从全部作品里选）—— 这一批的 look 参考
记录：batch 元数据写 card + hero 两个字段；后面所有步骤只认这两个
```

★ 缩略图长边 480 就够（手机上看）；点开才出 1080 大图。
★ 全部作品 = 8–20 张/卡 × 5 张卡 = 最多 100 张缩略图；**不许只给前 3 张**（前 3 张不是这张卡的代表）。

## 4 卡

**卡 = 大师成片数据库里的一个目录**（60+ 个，已经测量好）。

```
给一批自己的图 → 按匹配权重排序 → 前 5 个目录（带样片/理由/代价）→ **人拍板**
→ 选中的那个目录，就是这张卡
→ 引擎与 LR 的求解目标**都只有这一张卡**
```

卡不是"我们建出来的"，是**从库里选出来的**；它的数据就是那个目录的测量。

### 4.1 不变量层（与光位无关，卡间可分）

`contrast` · `toe/shoulder/contrast_win/skew` · `face_C/face_h` · `warm_cool_b` · `hue_bands` · `neutral_axis`（高频 grain 只记档；**空间族不按卡量**，用固定值）
卡文件：`analysis/corpus/kurai/cards_v5.json`（v7 口径）。

- 用途 1：**hero 样片只做目检参考**——**由人选卡时一起指定**（从**该目录全部作品**里点一张）；**数值目标仍是卡的不变量（关系/形状/配比）**，A 不拿 hero 做拟合。
- 用途 2：**匹配的画像**——用中位/分布距离排序。**匹配用中位合法，求解用中点非法**（§8）。

★ 卡**不带介质字段**：介质按目录（卡）算（§4.4）；卡只带测量出来的东西。

### 4.2 条件形状（模型级，不是卡的字段）

```
光位 → face_over_bg 的**相对形状**（back / mid / front 的中位与半宽），由**全部卡**统计得到；
卡只存自己的关系值；B 段把"条件形状"按**这张卡的关系值**缩放。
```

一张卡 8–20 张图撑不起分位数 ⇒ 条件形状只能是**模型**，不能写进卡。
这是唯一一处"跨卡共享"的东西——它是**统计模型**，不是任何卡的默认值。

### 4.3 卡里没有的

| 缺 | 后果 |
|---|---|
| 人/背景分开的 clip | 只能整幅对齐 |
| 轮廓亮边 | 只能记账 |

### 4.4 介质从哪来（按目录算，人只选卡）

```
每个目录（卡）一份介质，从引擎 profile / 参数面 + 这张卡的目标值推，不靠渲染试：
  卷     ← 卡暗部色偏轴 → 引擎中性滤片数据库里最近的卷（推导，不是唯一解）
  纸     ← 卷的 target_print + 纸的 Dmax / 形状（分位匹配）
  amount ← 这张卡的脸 C（点值，不用带中点）/ 同语料中位 × 语料标定值（夹边界）
  PE     ← 18.4% 参考灰 + 这张卡的 p50（点值，不用带中点）反解（auto_exposure 同状态）
  空间族 ← 固定值（柔光/光晕/眩光；验收可调）
  滤片   ← 中性轴 → CC → simulation.print_y / m_filter_shift
依据表：analysis/corpus/kurai/card_medium.md（每行写清凭哪个量推的）
```

- 不再"本批 1–2 张代表图 × 每个候选 → 渲 → 量"；那是把介质当匹配结果，不是从卡推。
- 基线 ①′ 用基线介质 + 基线 PE，只为把原片送进成片域；选卡后按本目录介质重渲。
- 介质不写进卡：卡只带测量出来的东西，介质由系统按目录算。

### 4.5 加一张卡

```
≥8 张有脸 → 新尺子测 → 卡（不变量 + hero 样片 + 自己的 clip）
条件形状用模型，不写进卡
```

## 5 分工

| | 引擎 | LR-A（批级） | LR-B（图级） | 人 |
|---|---|---|---|---|
| 管 | 介质·质感·化学曲线·自己的测光 | 颜色/明暗层次/冷暖的**参数** | 曝光/关系/白黑端/冷暖的**落地** | 选卡·批边界·意图·目检 |
| 输入 | 卡 + 原片（介质按目录算） | 全批 ① 的**中位** | 单张 ① + 条件形状 + 光位 | — |
| 输出 | ① + `engine_params.json` | `batch_grade.json`（全批同参） | `plan_<stem>.json` | 拍板 |
| 不动 | 逐图落点·白端·分级 | **亮度**（曲线保持 p50） | 介质与颗粒（卷纸质感归引擎） | 数值 |
| 失败算谁的 | 整批同向偏离 / 质感不像 | 批内颜色一致偏离 | 单图比值偏离 | — |

## 6 引擎（介质级）

**怎么做见 `引擎设计.md`。** 宪法只定三件事：

```
两种渲染：①′ 基线（只为匹配）· ① 正式（卡的介质）
测光只保证"余量一致 + 不剪死"；介质**按目录（卡）算**，质感按 profile / 标定
判据：不剪死 + 质感量（尚未定义）+ 目检
```

★ 这是"像不像"的主体（风格层卡解释 0.33–0.42），也是当前最大缺口。

## 7 LR（A / B / C）

**怎么做见 `LR设计.md`。** 宪法只定顺序与边界：

```
A（批级）：**hero 只做目检参考**；数值目标 = 卡的不变量（关系/形状/配比）。只定"一套"的骨架：曲线形状 + 冷暖的方向，
           **不动亮度**（曲线保持 p50）。保护：曲线不反折、不动 p50；冷暖色相成对
B（图级）：曝光 / 关系 / 白黑端 / **颜色补差**（肤色饱和 ±10 UI · 冷暖落地 · 色相只记账）
C（验收）：测 ③ → 对齐多少 / 偏离多少 → 预测 vs 实测 → 目检
顺序 A → B → C；一次算，不导出回看（预测误差必须报）
```

六格决策、公式、机理成熟度表：见 `LR设计.md` §3 / §6。

## 8 判据与约束

```
判决   物理（死白 / p1 / 量程 / 单调）—— 破了就是错，没有"接近"
对齐   卡的关系 / 形状 / 配比 —— 用公式算目标值，对到卡给的量；不设区间靶
死区   量化下限（u8 一个编码：L* ≈ 0.4、a/b ≈ 0.5、C ≈ 0.2）—— 小于一格不动
```

- **判决只有两条：物理 + 目检。** 卡是求解目标，不是合格证。
- **匹配可以用中位/分布**（"像不像"的度量）；**求解用公式/规律算落点**，不用中点、不用区间靶。

## 9 通道能力表（接口事实，别再推）

| 能力 | 事实 | 后果 |
|---|---|---|
| 蒙版组 | `MASKPARAM` 只写第 1 组 | 一图一组；见 §2 边界① |
| 局部曝光刻度 | `LocalExposure2012 = EV/4` | 直接换算 |
| 回读 | 回读 nil ≠ 没写（成片里 `LocalShadows2012="1"` 落下了） | 以成片 XMP/测量为准 |
| 局部选择性 | `LocalShadows` 满档：人 p99 +0.1；`LocalExposure` 1 档：p99 +11.2（未饱和）/ +1.3（已撞 100） | "局部必爆"不是物理；这两个数是 n=2 观察，不是常数 |
| 桥写值 | `MASK ... LocalExposure2012=` 不落地，必须 `MASKPARAM` | — |
| A/B 合写 | 两段的键不重叠（A：曲线/颜色；B：曝光/蒙版） | 合并成一份 XMP 再写；写后整份回读校验 |

## 10 常数（没有"被测量"列的不算常数）

> 生产只保留两类数——**单位换算** + **标准定义式**。
> 没有公开传递函数的旋钮（Highlights/Shadows/Whites/Blacks/Contrast、局部饱和、
> 局部 Shadows、冷暖）：**方向 + 一档（10 UI）+ ③ 验**，不建模、不外推。
> 分析模型只放 `analysis/corpus/kurai/_lr_models/`，**不进生产**。
> 来源见 §10.1；已删常数见 §10.2。

**单位换算（定义，不是标定）**

| 换算 | 值 | 依据 |
|---|---|---|
| `LocalExposure2012` 文件值 | EV/4（4 档 = 满刻度 1.0） | autoshade 实测 |
| 局部其余滑杆文件值 | UI/100 | 同上 |
| 全局 Exposure | +1 = 线性光 ×2 | Adobe：f-stop 增量 |

**一档政策（没有公开传递函数时）**

| 旋钮 | 触发 | 剂量 |
|---|---|---|
| 全局 Whites | 曝光/曲线后 p95 仍 > 卡的肩部物理上限 | **−10 UI**，③ 验 |
| 局部 Saturation | 脸 C 偏离卡的目标 C | **±10 UI**，③ 验 |
| 冷暖（SplitToning） | `warm_cool_b` 偏离卡的目标值 | 两轮各 **10 点**，色相成对 |
| 局部 Shadows / LocalHighlights | — | **只记账**，不动（除非 ③ 明确要） |

### 10.1 来源（查过的公开资料）

- [autoshade](https://github.com/skymanbp/autoshade)（MIT）：`LocalExposure2012` 文件值 = EV/4；8 结点 tone model 是拟合，不是 Adobe。
- [rawmakase](https://github.com/pch/rawmakase/blob/main/docs/tone-controls.md)（MIT）：Camera Raw Basic 面板系统实测；Highlights/Shadows 是局部算子，滑杆组合不能简单相加。
- [Adobe tone controls](https://helpx.adobe.com/lightroom-classic/desktop/help/tone-control-adjustment.html)：只有定性，无公开传递函数。
- [darktable splittoning.c](https://github.com/rawfiner/darktable/blob/61dc624f222be77aba21c166f69ac718c895ee2c/src/iop/splittoning.c)：另一种 HSL 替换模型，不能跨实现抄。

口径、字段、尺子质量见 `测量设计.md`。宪法只定"必算什么"和"同尺子"。

| 级别 | 量 |
|---|---|

## 12 失效清单（做了也会失效）

| 情况 | 为什么 | 处置 |
|---|---|---|
| 批内异质 | 批级中位会平均掉 | 报 IQR，交人拆批 |
| 条件格 n<30 | 分位数不稳 | 不给目标值，只报 |
| 无脸 / 脸太小 | 判据全基于脸 | 跳过图级，记账 |
| 无中性面 | 色锚不可信 | 只做保守修正 |
| 主体已削顶 | 物理不可逆 | 图级截断 |
| 冷暖与提脸同时要蒙版 | 一组蒙版 | 二选一，记账 |
| 前向模型 ±50% | 大动作会偏 | 分步 + ③ 验 |
| 介质推导依据冲突 | 推不出唯一 | 报冲突，交人定 |
