# 提亮保层次 · 冷暖对比（设计，2026-10-30）

> 触发：SV 指出两件事 ——
> ① 「背景亮部可能和人物不相交，可能是在天上，导致人物边缘和周边亮度有些割裂」
> ② 「提背景的时候能不能保留明暗层次和冷暖对比」
> 本文只写**机制与判据**，不含代码与参数值。所有数值都是"怎么算出来"，不是"该给多少"。

---

## 0 前提：先承认三个背景尺度

同一张片子，"背景有多亮"至少有三个不同的答案，混用就会出错：

| 尺度 | 怎么量 | 它决定什么 | 1608 实测 |
|---|---|---|---|
| **贴脸一圈**（rim） | 脸掩膜外扩 ~2% 画面宽 | **边缘会不会割裂**（脸与紧邻环境的亮度差） | 15.7 |
| **人周围一圈**（near_bg） | 人物掩膜外扩 2%~10%，去天空 | **整幅该多亮**（人所处的环境） | 53.9 |
| **全局背景亮部** | 背景掩膜 p90 | 只在"没有人周围参照"时用 | 73.2（含天空） |

★ 失误记录：之前一直拿"全局背景亮部 73.2"当脸的落位参考，而贴脸的只有 15.7 ——
差 57 格，脸落在中间，两头都不靠 ⇒ 亮脸贴在暗树荫上，边缘必跳。

## 1 提亮会丢层次：三个机制，全部可量

| 机制 | 为什么会丢 | 判据（可量） |
|---|---|---|
| **黑点被抬起** | 最暗处不再读成黑，整片发灰 | 提亮前后 **p1** 的差 |
| **暗部 L\* 跨度被压缩** | 暗部各层挤在一起，看着平 | **r = (p50−p5) 后 / (p50−p5) 前**，r<1 即被压 |
| **暗部色偏被放大** | 阴影本来偏冷，抬亮后偏色可见 | 背景 **b\*** 的 p10/p90 前后变化 |

出处：行业实务口径一致 —— "shadows lifted so aggressively that the image has no black point at all"；
"lifting blacks can make photos look flat. Contrast compensates by restoring midtone separation"。

---

## 2 保层次：三招，其中两招可算

### 2.1 把黑点锚回去（可算）

```
Δ黑 = 提亮后 p1 − 提亮前 p1        （提亮把黑点抬了多少）
Blacks 参数 = −Δ黑 / 实测黑端增益   （增益需标定：Blacks 每点动 p1 多少）
```
判据：处理完 **p1 回到提亮前 ±1**。回不去 ⇒ 黑点没锚住，失败。

### 2.2 段内补斜率（可算，这是本设计的核心）

不整幅加对比，只在"被提亮的那个亮度段"把斜率补回去：

```
r = (p50 − p5)_后 / (p50 − p5)_前            跨度压缩比
曲线在 [p5, p50] 段的斜率要 × (1/r)          只改这一段，不动中高段
```
为什么只改这一段：整幅加对比会把脸一起推亮（脸在中高段），脸就不受控了。
这也是"一根旋钮管一件事"的应用：**曲线的暗部段只负责背景层次**。

### 2.3 别用 Dehaze / 大 Clarity（禁用项）

- Dehaze：去饱和冷色 + 边缘起光晕 ⇒ 直接破坏冷暖对比
- 大 Clarity：人像出 halo，皮肤最明显
⇒ 保层次的工具只用「黑端 + 曲线暗部段」，其余禁用。

## 3 冷暖对比：顺序比参数重要

### 3.1 必须"先提亮，后定冷暖"

提亮会改变色偏的**可见度**：同样 b\* 偏移，L=15 时看不见，L=35 时明显。
所以冷暖分离量必须在提亮**之后**测、之后再定。先定冷暖再提亮，等于用一个过期的读数。

### 3.2 三论分工（颜色分级）

| 轮 | 给谁 | 为什么 |
|---|---|---|
| 阴影 | 背景（暗部）加冷 | 把环境"推远"；且不像压暗那样把背景压死 |
| 高光 | 保留暖 / 轻加暖 | 逆光的光感在这里 |
| **中间调** | **脸 —— 少动或不动** | 这一轮动多了脸就黄了 |

### 3.3 强度来源

- **方向**：高光暖 / 阴影冷 —— 行业共识（胶片特性 + 人像惯例），不是我们编的
- **强度**：由卡的 `warm_cool_b` 与背景 **b\* 的 p90−p10 跨度**共同给
  （跨度大 ⇒ 场景本身冷暖分明 ⇒ 分离量可以小；跨度小 ⇒ 需要更主动地分开）
- **量**：可标定（分级轮的 S 每单位改变 b\* 多少），但**要不要这么分**是风格，必须显式写

## 4 流程（重排后）

```
① 测  脸 L / 贴脸圈 L / 近场 L 与 b* / 背景五分位与 b* / p1
② 判  贴脸圈 < 脸 ⇒ 全局提（一起亮，关系不变）
      贴脸圈 > 脸 ⇒ 局部提（只提人，别推背景）
③ 提  全局曝光 或 局部曝光；量由 Y 比反解（× 工具实测系数）
④ 保层次  Blacks 锚黑点 + 曲线暗部段按 1/r 补斜率
⑤ 定冷暖  重测 b* → 颜色分级（阴影冷 / 高光暖 / 中间调留给脸）
⑥ 校验  见下
```

## 5 失败判据（比"达标"更重要）

| 检查 | 阈值 | 破了说明 |
|---|---|---|
| 脸的 L 变化 | >1 格（由 ④⑤ 引起） | 暗部工具侵入了脸 |
| p1 | 比提亮前高 >1 | 黑点没锚住 |
| 背景跨度 (p50−p5) | 低于提亮前的 0.9 | 层次没补回来 |
| 脸的 b\* 变化 | >2 | 冷暖分级污染了中间调 |
| 贴脸圈与脸的差 | 比原片大 >10 格 | 边缘会跳，该换全局提 |
| clip | 涨 >1 个百分点 | 提亮过头，该收 |
