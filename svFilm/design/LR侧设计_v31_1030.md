## 1 前置：分类树（G7 · 先分类再处理）

任何片子进七步之前，先过这棵树。同一个坑反复踩的共同前置缺失，就是少这一步。

```
有脸（且 face_w ≥ 40）？ ── 否 ──→ 整幅策略（不做人像流程，记账"无脸"）
  │ 是
主体已削顶（死白在主体）？ ── 是 ──→ 提亮受限分支（按 EV_max 截断，收白无解）
  │ 否
贴脸圈 < 脸？ ── 是 ──→ 【暗背景】全局提（关系保持）
  │ 否
  └────────────→ 【亮背景】局部提（别推背景）
                    │
                    └─ 有中性面？ ── 否 ──→ 颜色只做保守修正，记账"无中性面"
```

**每个分支必须记录**：进了哪一支、依据是哪两个数、为什么。否则事后无法追溯。

## 2 对齐匹配卡：三组约束 + 量释义（G1）

### 2.1 量释义表（每个量：代表什么感知 · 同名版本 · 判据用哪个）

| 领域词 | 测量字段 | 代表什么感知 | 同名版本（易混） | 判据里用哪个 |
|---|---|---|---|---|
| 脸的亮度 | `skin.L` | 观众"看脸"的那个亮度 | 脸掩膜中位 / 脸内 p90 | `skin.L`（取样点中位） |
| **紧邻环境** | `rim.L_p90` | **贴着脸的那圈**（决定边缘割裂） | 近场环带 / 全局背景 | `rim.L_p90` |
| 人所处环境 | `near_bg.L_p50` | 整个人周围一圈（决定整幅多亮） | 贴脸圈 / 全局 | `near_bg`，仅作参考 |
| 背景亮部 | `bg.L_p90` | 卡的关系量里的"背景" | 中位 / p95 | `bg.L_p90`（与卡同口径） |
| 爆白（可逆性） | 死白 / 濒白 | 信息丢没丢 | `clip_pct`（整幅） | **死白/濒白分开** |
| 爆白（归属） | 主体 / 背景各自统计 | 该压谁 | 整幅 clip | **按掩膜分开** |
| 暗部层次 | `bg.L_p50 − bg.L_p5` | 暗部"挤不挤" | 对比度 / 标准差 | 跨度 |
| 冷暖 | `bg.b_p10/p50/p90`、`skin.b` | 环境与人各自的色温位置 | C / h | **b\* 本身** |
| 轮廓光 | `rim.bright_share` | 发丝亮边还在不在 | —— | 前后比 |

★ 规矩：**没在这张表里的量，不许进判据。**

### 2.2 三组约束（卡只给边界，不给中点）

```
关系约束  face_over_bg [0.78,0.92] · person_over_bg · light_ratio（旁证）
形状约束  toe / shoulder / contrast_win / skew · p95 带（肩部落点，唯一绝对量）
色彩约束  neutral_axis · hue_bands · face_C/face_h 带 · warm_cool_b
```

**用法**：出带才修，带内不动、不排名。`p50 / clip` 的分布**不进约束**（随拍什么变）。

## 3 七步：设计（判据）+ 机制（怎么做）

每步三块：**设计**（什么时候动、动到什么程度、怎么算越界）· **机制**（哪个量 / 哪根旋钮 / 哪条通道）· **失败判据**。

### ① 两种锚

| | 亮度锚 | 颜色锚 |
|---|---|---|
| **设计** | 死白=0 且 p1 回到原值±1；`Blacks = −Δp1/0.15`（上限 −20） | 有中性面 ⇒ 把 b\* 归到卡的中性轴；**无中性面 ⇒ 不做强修正** |
| **机制** | 量：`img.p1`、死白比例；旋钮：`Whites`/`Blacks`；通道：XMP 标量 | 量：中性面 a\*/b\*（**待新增**）；旋钮：`WhiteBalance`；通道：XMP |
| **失败** | 死白>0 或 p1 回不去 | 无中性面却硬归零 |

作用域：**全幅 · 全段/端点**。

### ② 关系（脸该多亮）

| 设计 | 机制 | 失败判据 |
|---|---|---|
| 贴脸圈<脸 ⇒ 全局提；反之 ⇒ 只提人。目标 = `R × bg.L_p90`，`EV = log2(Y比) × 工具系数`。上界 `EV_max=(100−主体p99)/slope` | 量：`skin.L`、`rim.L_p90`、`bg.L_p90`、主体 p99。旋钮：`Exposure` 或 主体蒙版 `LocalExposure`。通道：XMP / 桥 `MASK subject + MASKPARAM`（值=EV/4，回读校验） | 脸与贴脸圈差比原片大 >10 格 |

作用域：**全幅·全段** 或 **主体·全段**（二选一，不许同用）。

### ③a 形状（学卡）+ ③b 层次（补跨度）

| | ③a 形状 | ③b 层次 |
|---|---|---|
| 设计 | 由卡的 toe/shoulder/contrast_win 生成 4 个锚点，PCHIP 插值 | `r=(p50−p5)后/前`，暗部斜率 ×1/r，只动暗部段 |
| 机制 | 量：卡形状带 + `img` 分位；通道：`ToneCurvePV2012`（16 点） | 量：`bg.L_p5/L_p50` 前后；通道：同上（参数曲线暗部段） |
| 失败 | 曲线反折 / 肩部越过卡 p95 上沿 | 跨度没回到 0.9 或脸 L 被改 >1 |

作用域：③a **全幅·全段**（形状是整幅的）；③b **全幅·阴影段**。

### ④ 肤色

| 设计 | 机制 | 失败 |
|---|---|---|
| h 拉回卡带、C 补回提亮稀释的量；**L 不动** | 量：`skin.h/C/L`、`face_C/face_h` 带；旋钮：`HSL 橙色`；通道：XMP（Hue/Sat/Lum 三根，只动前两根） | 脸 L 变化 >1 格 |

作用域：**肤色（按色相选择）· 全段**。

### ⑤ 分离（把环境推远）

| 设计 | 机制 | 失败 |
|---|---|---|
| 背景压暗（不压死）+ 阴影推冷 + 降饱和；强度来自 `warm_cool_b`，**是风格** | 量：`bg.L_p90`、`bg.b_p50`、`skin.b`；旋钮：背景蒙版 `LocalExposure−` / `LocalToning` / `LocalSaturation`；通道：桥 `MASK background + MASKPARAM` | 脸 b\* 变 >2 |

作用域：**背景 · 全段/阴影段**。★ 必须用背景蒙版——全局阴影轮会漏脸 0.13 b\*/点（实测）。

### ⑥ 收白（一次算）

| 设计 | 机制 | 失败 |
|---|---|---|
| 死白>0 ⇒ 物理救不回 ⇒ 回退提亮；死白=0 有濒白 ⇒ `LocalHighlights = −(濒白超出)/0.18` | 量：主体/背景各自的死白与濒白；通道：桥 `MASK background + LocalHighlights2012`（回读校验） | 压完死白还在 |

作用域：**背景 · 高光段**。**不迭代。**

### ⑦ 轮廓光校验（只判不动）

| 设计 | 机制 | 失败 |
|---|---|---|
| `rim.after / rim.before < 0.7` ⇒ 提亮吃掉了亮边 | 量：`rim.bright_share` ①②前后；无旋钮 | 触发 ⇒ 回退 ② 的提亮 0.2 档 |

## 4 求解机制：CSP + 作用域解耦

```
变量：EV · local_ev · 曲线4参数 · HSL橙2根 · 分级3根 · 收白1根
约束：三组带 + 物理边界（死白=0 / p1≥下限 / 滑杆量程）
目标：无（域内不排名）
```

**可顺序解的依据（解耦表）**

| 耦合对 | 耦合？ | 解法 |
|---|---|---|
| 曝光 ↔ 白端 | 有 | 先算 `EV_max` 当上界，不迭代 |
| 曲线暗部 ↔ 脸 | 无 | 只动暗部段 |
| 分离 ↔ 肤色 | 有（全局轮） | 换背景蒙版（实测脸 ±0） |
| 收白 ↔ 脸 | 有（全局） | 换背景蒙版（实测脸 ±0） |
| 提亮 ↔ 轮廓光 | 有 | ⑦ 校验 + 回退 |

**执行顺序（机制层）**：分类 → ① → ② → ③a → ③b → ④ → ⑤ → ⑥ → ⑦ 校验 → 验收。
（③a 必须在 ③b 之前：先有形状，才谈"跨度还原"在哪个斜率上做。）

## 5 分工：主笔 vs 修补（可操作判据）

| | 主笔（引擎） | 修补（LR） |
|---|---|---|
| 做什么 | 介质、性格、质感、自己的测光 | **残差**、小优化 |
| 输入 | 卡（卷/纸） | **残差**（差多少），不是目标 |
| 颜色 | 定倾向 | 可以动颜色（LR 色彩能力强），但只补残差 |
| 越界判据 | —— | **LR 只该拿到"带的边界"，不该拿到"中点"** |

## 6 机制总表：测量 → 求解 → 执行 → 验证

### 6.1 测量机制（每个量的算法与图域）

| 量 | 算法 | 图域 | 备注 |
|---|---|---|---|
| `skin.L/C/h/b` | 皮肤取样点（脸掩膜 ∩ 去鼻 ∩ 去高光/阴影） | 1080 | 复现性待测（门槛 ≤1 格） |
| `rim.L_p90 / bright_share` | 脸掩膜外扩 ~2% 环带 | 1080 | 已有 |
| `near_bg.*` | 人物外扩 2~10%、去天空 | 1080 | 已有 |
| `bg.L_p5..p95`、`bg.b_p10..p90` | 背景掩膜分位 | 1080 | 已有 |
| 死白/濒白（主体/背景分计） | `max(RGB) ≥ 0.996 / 0.96~0.996`，按掩膜统计 | 1080 | **待实现** |
| 中性面 a\*/b\* | 低饱和（C<8）且中亮（L 30~80）区域占比 + b\* 中位 | 1080 | **待实现** |
| 卡记录 | `card` 名 + 选法 + 理由 | —— | **待实现** |

**测量纪律**：同一张图连测 5 次，脸 L 离散必须 ≤1 格；否则先修尺子再谈判据。

### 6.2 执行通道表（写进 LR 的哪条路）

| 参数 | 通道 | 回读 | 已知限制 |
|---|---|---|---|
| Exposure / Whites / Blacks / Highlights | XMP 标量（GLOBAL） | 需核 | —— |
| 曲线 16 点 | XMP `ToneCurvePV2012` | 需核 | —— |
| HSL 橙 | XMP | 需核 | 三根独立 |
| 主体提亮 | 桥 `MASK subject` + `MASKPARAM LocalExposure2012` | **必须回读** | 值 = EV/4 |
| 背景收白/冷暖/压暗 | 桥 `MASK background` + `MASKPARAM` | **必须回读** | —— |
| **每图最多一个蒙版组** | —— | —— | `MASKPARAM` 只写第 1 组；要两组必须改 Lua 并重启 LR |

★ 通道限制直接决定设计：**同一张图不能同时"主体提亮 + 背景收白"**。所以分类树里"暗背景分支走全局提"不只是判据上更优，也是**当前通道下唯一可行**——这条要写清，别让后人以为是偏好。

### 6.3 验证机制

| 层次 | 验什么 | 容差来源 |
|---|---|---|
| 物理 | 死白=0、p1 不低于原值 | 物理不可逆 / 量化下限 |
| 关系 | 脸 L 到目标、贴脸圈差、跨度还原 | 大师实测区间 |
| 颜色 | h/C 在带内、脸 b\* 变化 ≤2 | 大师区间 / 生理 |
| 结构 | 轮廓光比 ≥0.7 | 实操口径 |
| 目检 | 好不好看 | **人** |

### 6.4 失败处置（每种失败的回退路径）

| 失败 | 回退 |
|---|---|
| 死白>0 | 提亮减 0.2 档（用预测值重算，不跑 LR） |
| 轮廓光掉 >30% | 提亮减 0.2 档 |
| 脸 b\* 变 >2 | 撤掉分离（回到未分离态） |
| 跨度没还原 | 加大 ③b 斜率，一次到位（不迭代） |
| 脸 L 到不了目标 | 记账"物理截断"，不硬提 |

## 7 失效清单（G6 · 做了也会失效的情况）

| 情况 | 为什么会失效 | 当前处置 |
|---|---|---|
| 无脸 / 脸太小 | 全部判据都基于脸 | 跳过人像流程，记账 |
| 无中性面 | 颜色锚不可信 | 只做保守修正 |
| 贴脸圈极暗 + 脸上有光斑 | 提亮必割裂（1608 本质如此） | 少提或只做全局 |
| 主体已削顶 | 物理不可逆 | 提亮截断 |
| 多张卡混合的批次 | 关系带互相矛盾 | 必须单卡 |
| 强人造光 / 混合色温 | 中性轴假设不成立 | 未知，需新判据 |
| 脸被遮挡（口罩/头发） | 皮肤点失效 | 现有 strict→anchor→loose 降级 |

### 8.1 已经有结论、已落地（不要再做）

| 项 | 既有结论 | 出处 |

### 8.2 已记录、但执行层没落地（接着做就能用）

| 项 | 结论 | 缺的那一步 |
|---|---|---|
| ~~局部蒙版必须 ∩ 亮度范围~~ **→ 已解决（2026-10-30 晚）** | 用 **`LocalShadows`** 代替亮度范围：它天生按亮度选择性，实测**几乎不推 p99**（满档 +0.1）、clip 只 +0.5。对比 `LocalExposure` 1 档 → p99 +11.2、clip 爆 | 分配律已写进 `formula.allocate_fill`：**先 Shadows 吃满（不受白端限制）→ 剩余用 Exposure（受 `(100−p99)/11.2` 限制）→ 不够就记账** |
| **每图只能一个蒙版组** | `MASKPARAM` 只写第 1 组 ⇒ 主体提亮与背景收白不能同时 | **降级为不阻塞**：LocalShadows 解决了"提人不爆"，背景收白只在暗背景分支（走全局提、无主体蒙版）才需要，两者不再冲突。真要同用仍要改 Lua |

★ 这两条其实是**同一件事的两面**：一旦"主体 ∩ 亮度范围"能落地，整人提爆的问题自然消失，
也就不再需要"主体提亮 + 背景收白"两组蒙版。

## 8.5 检测分两级（2026-10-30 晚，SV 追问后修正）

> SV：「有必要这么多检测吗？不是因为完全由我的目检为准吗？」
> **判据只有目检。检测不是判据，只有两个合法用途：防物理事故、定位问题。**

### 必算（出片前 5 项，每项都必须能说出"防什么"）

| 量 | 防什么 |
|---|---|
| 死白 / 濒白（主体·背景分计） | 防不可逆的削顶 |
| 主体 p99 | 防提亮越过白端物理上限 |
| 脸 L | 关系要动多少（执行） |
| 贴脸圈 L | 防止选错方向（全局/局部） |
| `bg.L_p90` | 关系的另一半（执行） |

### 按需（4 项，只在出问题或 SV 提出时跑）

| 量 | 什么时候才需要 |
|---|---|
| `near_bg` | "脸和背景关系看着不对" |
| 中性面 | "颜色不正" |
| 轮廓光 rim | "逆光的光没了" |
| 光照边缘 | 目前没遇到过 |

**规矩**：新增任何检测，必须能回答"它防什么事故 / 定位什么问题"；答不出来 ⇒ 删。

### 风格参数（明确单列，不许混进判据）

以下是**审美**，不是检测能定的，必须由人给或由卡带定：
`R`（脸/背景亮部）· 冷暖分离强度 · 贴脸圈允许差 · 背景压暗幅度。

## 9 纪律对照

| 铁律 | 怎么守 |
|---|---|
| 1 不打数值靶 | 阈值只有四个合法来源 + 工具刻度；带内不排名；`+25`、`clip 2.5%` 已删 |
