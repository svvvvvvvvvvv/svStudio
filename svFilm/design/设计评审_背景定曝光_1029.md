# 设计评审：背景定曝光 + 人物按光向量局部补（"去以人为本"这个想法）

> 2026-10-29 晚 · 只读已有测量与代码，没渲东西。评审对象 = SV 的提议：
> 「背景曝光固定下来，基础曝光去定背景；人物曝光按和背景的规律、按光的向量动态调。
>  以人为本不要了，这样是不是更好？」

---

## 0 结论（先说清楚"能不能不要"）

**这个想法方向是对的，但"不要以人为本"这句要改一个字：不是不要，是换个执行位置。**

```
现在的「以人为本」= 脸进不了区 ⇒ 动**全局曝光**（整幅跟着亮，背景陪葬）
提议的「以人为本」= 脸进不了区 ⇒ 动**局部补光**（只碰人，背景不动）
```

判据还是那条（脸 > 背景），变的只是**谁来执行**。真把以人为本删掉会变成"背景对了就算完"，
那和你要的"亮、白、有血气"直接冲突 —— 所以删不得。

**而且这个想法已经有一半实现了**（下面 §2 有数）：引擎那条 `render_safe` 就是"背景定曝光"，
v6 里 LR 的全局曝光 **8/10 张是 0**（另两张 +0.134 / +0.288）。真正要改的只有一件事：
**⑨ 禁止 LR 再为了脸去动全局曝光**，把它整体搬到 ⑥ 的局部补光。

---

## 1 现在是三段曝光在抢同一件事

```
① 引擎 print_exposure（逐图，render_safe）   → 二分求解，让 黑≤3% / p95≤96   ← 这是在"定背景"
② LR 全局 Exposure                          → 脸出区才动，动了背景陪葬         ← 这是在"定脸"，用错工具
③ LR 局部（点颜色亮度 / 主体蒙版）           → 只碰人
```

②和①/③的关系是重叠的：② 想干①已经干过的事（背景落位），又想干③该干的事（脸）。
**v6 的实测证据**：LR 曝光中位 **0.00**、范围 0~0.29，**8/10 张是 0** —— 它基本没动过。
也就是说"背景定曝光"这条**已经在跑**，只是没人把它写成设计。

---

## 2 为什么提议更好（四条，都有今天的数）

### 2.1 背景不再为了脸挨刀

v6 里 ② 只给过两张小剂量（1608 +0.134、1627 +0.288），所以这批没出事。
但判据一改就要出事：1231 若按面光判（脸 48.7 该进 55~85、目标 58.5）⇒ ② 会 +0.5 档，
而它的 ① 背景 p95 已经是 **99.1**、clip 5.27%。这 0.5 档**全是拿背景换的**，
接下来 ③ 收白只能靠 −50 硬压（v6 里 1608 的 −50 就是同一个机制）。
**这不是假设，是判据修好后马上会发生的事。**

### 2.2 ③收白 与 ⑥补光 的"仲裁"可以删掉

现在 `batch.run_final` 里有一条仲裁：

```
脸不够亮、且 ⑥ 还没推满 ⇒ 这一轮不动收白（先让 ⑥ 补）
```

它存在的原因是：**收白会把脸压暗**，而脸又还没补够 —— 两条在抢同一张脸。
一旦"为脸动全局"这条被禁掉，③ 的职责就纯粹是"修背景高光"，**永远碰不到脸**
（除了蒙版边界），这条仲裁自然消失。流程少一个互相牵制的环节。

### 2.3 光位向量终于有活干

现在光位只用来选一套脸亮区（45~70 / 55~85）—— 一个二值开关。
按提议，它给的是**自然关系**，剂量由"目标关系 − 自然关系"算出来：

```
自然关系（今天量到的，733 张语料）：
   逆光 ΔEV = −2.09（脸比背景亮部低 2.1 档）· 侧逆/3-4 −0.85 · 顺光 −0.13
补光口味（人给的，两档）：
   自然档 K = 沿用上面的自然关系
   补光档 K = 逆光 1.2 · 侧逆 0.8 · 顺光 0.2        ← "补到比环境低一档左右"
目标脸 L = 背景亮部 × 2^(−K)
剂量(EV) = (目标脸 L − 现在脸 L) / 20              ← 今天实测的传递 ≈ +20 L*/档
```

**这才是"根据光的向量动态调"的落点**：向量决定 K，不决定亮度本身。

### 2.4 两层正交，可以分别验收

```
全局那层只对"背景"负责：p95 ≤ 93（T0）/ clip < 0.5% / p5 不堵（T2）
局部那层只对"人"负责：  脸 L 落区 / C 不掉 / 白裙不爆 / 仍是人样
```

现在"脸出区"会同时触发两层，验收时分不清是谁的账 —— 这是审计 G1~G4 那种病的根。

## 3 但有五条护栏，缺一条就会翻车

```
① **背景亮部不能用 p95 当参照**：p95 会被天空/太阳骗（1231、1526 今天刚栽过）。
   参照要么用"背景 p75"，要么用"排除天空后的背景"；K 的标定必须在同一个参照上做。

② **局部补光有上限**：主体蒙版 ±4 档，但实测 +1.25 档时白裙 p95 已经 96~98、
   全幅爆白 0.43~0.57% ⇒ **实际可用约 +1.0 档**。超过这个，再往上就只能动全局
   （也就是退回现在这条路，接受背景爆）。

③ **补光会连带衣服**：主体蒙版不分皮肤/布料（1608 白裙 p95 71→95.4 @+1.0）。
   所以"白裙 p95"必须是硬门，不是提示。

④ **不许闭环**：背景锚点、K、剂量全部从 ①（引擎底片）算；③ 只用来验，不许回写。
   （手册那条"必然振荡"是同一个道理。）

⑤ **脸仍然优先**：如果局部补到上限脸还没进区（极暗），才允许动全局；
   这时要记账"这一张是拿背景换的脸"，不能静默。
```

## 4 和"补光"那两跑的关系（今天已经量出来的）

| 事实 | 数 | 用途 |
|---|---|---|
| 局部补光传递 | **+20 L\*/档** | 剂量公式的分母 |
| 主体蒙版选择性 | 背景 30.0→29.1（+1.0 档时） | 证明"只碰人"成立 |
| 白裙上限 | +1.0 档 p95 95.4 / +1.25 档 96.3 | 护栏②的实际数字 |
| 彩度代价 | 底子越好越不掉（1608 −1.0 @+1.25；1665 −2.4 @+1.0） | 回彩剂量要逐图量，不能常数 |
| 点颜色色相 | 0.5°／格；我们本来就比大师红 8~12° | 色相别往红推 |

⚠ 一个必须先说清的边界：上面 K 的标定用的是**目录卡**（自然光、无补光）。
"补光档"的 K（1.2 / 0.8 / 0.2）目前**没有语料支撑**，是摄影通行的"补到低一档左右"口径 ——
按纪律只能当方向，要出片 + 目检定。

## 5 怎么验证（不铺全量）

**一批 10 张，走两条路，比同一套验收：**

```
A 路（现状）：② 可以为脸动全局  →  ③ 收白  →  ⑥ 补光（点颜色）
B 路（提议）：② 永不为脸动全局  →  ③ 只修背景  →  ⑥ 主体蒙版补光 + 回彩
```

比四件事（都在 ③ 上量，取样点固定）：

```
① 脸 L 分布（两路谁更靠近目标）
② 背景 clip / p95（B 路应该明显更好）
③ 白裙 p95（B 路的代价）
④ 目检：B 路的"提起来"有没有塑料感（这是唯一的真风险）
```

代价：10 张 × 1 轮导出 ≈ 2~3 分钟（引擎不重渲，用 v6 的 ①）。

## 6 会变 / 不变

```
变：② 的职责从"定脸"收窄成"只做整幅的小修（如果背景锚点没到位）"
    ⑥ 从"补最后一段"升成"补脸的唯一执行者"，剂量由光向量 + 口味算
    ③ 不再和 ⑥ 仲裁（因为它永远碰不到脸）
不变：脸 > 背景这条铁律；引擎仍只负责介质与"背景落位"；曲线仍不追形状
```

一句话：**这不是推翻"以人为本"，是把它的执行从"整幅抬"换成"局部补"，
并且第一次让"光位"从一个开关变成一个可算的参照。**

## 7 反方意见（写下来防止我只会点头）

> SV 要求"不要顺着我讲"。以下是我站反方时能找到的最硬的四条。

### 7.1 这是"结构卫生"，不是"画面变好"

这个工具的目的：**把整批人像稳定做成"亮白有血气、有胶片质感"的成片，且不用逐张手调。**
而决定画面好坏的三件事是 —— 补光剂量、回彩、质感。**曝光架构一件都不碰。**
v6 里 8/10 张 LR 曝光本来就是 0 ⇒ 这条改动在**这批**上的画面收益 ≈ 0。

⇒ 若目标是"画面变好"，这个改动的优先级排在**第四**（前面是：谁定义脸、光位判据、补光/回彩）。

### 7.2 它拿掉了一个"用背景换脸"的自由度 —— 而那正是铁律的保险

实测：局部补光可用上限 **+1.0 档**（+1.25 就顶裙子）。
如果场景让脸离目标超过 1 档，禁掉全局曝光意味着 **B 路根本给不出脸要的亮度**：
要么裙子爆，要么脸不够亮。而"脸 > 背景"这条铁律恰恰要靠"拿背景换脸"兜底。

⇒ 正确做法不是**禁掉**，是**降级成最后一张牌**：默认不动（你的规则），
补到上限仍不够才动，并记账"这张拿背景换了脸"。**保留自由度，改默认值。**

### 7.3 它会放大光位判据的错

现在判错只影响一件事：选哪套脸亮区（±10 L* 的区间）。
一旦脸的目标变成 `背景 × 2^(−K)`，K 由光位定 ⇒ 判错的代价从"区间选错"变成"目标差约 1 档"。
而今天已经证明判据会错两次（1231 假逆光、1665 真逆光漏判），rim 量具还是坏的。
⇒ **顺序必须是"先修判据，再让它管目标"**，否则是把噪声接到最关键的变量上。

### 7.4 我上一条自己写错了一句，这里纠正

我说 `r²(脸 L ~ 背景 L) = 0.01` ⇒ "没有关系"。**这个推论不成立**：
逆光桶里背景亮部只在 87.3~97.4 之间（被白平台压住了）⇒ 这是**量程受限**（range restriction），
不是"没有关系"。物理上关系是真的（太阳 / 天空 ≈ 2 档，语料的 −2.09 正是它）。

**但结论反而更清楚**：因为背景亮部在日光下几乎恒为 90~97，
相对式和绝对式在我们这批里**数值上等价**（0.55×91 ≈ 50，和"区间下界+3.5"只差 2 格）。
相对式的价值只在**非日光**（阴天 18 张 / 窗光 87 张 / 钨丝 62 张）才显出来 ——
那部分语料还没量过。

⇒ **这个设计对接下来的批不重要，对"工具能泛化到什么场景"很重要。**

### 7.5 真正的瓶颈（按价值排序）

```
1 谁定义"脸"：侧光下两颊差 10~26 L*，现在取"像素最多的那块" = 硬币
   ⇒ 判据的分子不稳，任何曝光策略（全局/局部/绝对/相对）都建在沙子上
2 光位判据 + rim 量具（今天已证会错，且 rim 量的是贴脸背景）
3 补光/回彩的剂量（白裙上限、彩度代价看底子）
4 曝光架构（即本设计）—— 结构更干净，但画面收益 ≈ 0
```

⇒ 我的建议：**先做 1 和 2，架构这一步等它们稳了再动**。
不然就是"把一间还没定梁的房子重新刷一遍墙"。
