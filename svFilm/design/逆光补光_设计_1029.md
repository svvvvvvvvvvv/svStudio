# 逆光补光（fill）：把"人像审美"做成一档，而不是修一个物理错误

> 2026-10-29 晚 · 依据 = `_mask4/主体提亮.html` 的四档实测 + 语料标签统计 + 查到的补光口径。
> 没有新渲染。本文只定**机制与剂量来源**，不定最终审美值（那个要目检）。

---

## 0 结论

**补光不是篡改，是模拟一支没带上的灯。** 真实拍摄里逆光人像会加闪光灯/反光板；
我们的链路里对应的位置是 **LR ⑥（主体蒙版 / 点颜色亮度）**，不是引擎 —— 分工没破。

要改的只有一件事：**判据得分成两档**。
现有的 `T4_BACKLIT = 45~70` 是**"无补光档"**的边界（来自大师语料，而语料里 0 张闪光灯），
它不代表人像审美。补光档需要自己的边界。

---

## 1 我们已经有"补光曲线"了（实测，不是估）

`_mask4` 探针：同一张 ①，用 LR **主体蒙版**（`LocalExposure2012 = EV/4`）单独提人，四档实测：

| 图 | 档 | 脸 L | ΔL* | 脸 C | ΔC | 背景 L |
|---|---|---|---|---|---|---|
| **1608**（逆光） | 0 | 48.7 | — | 21.6 | — | 30.0 |
| | +0.5 | 58.1 | +9.4 | 19.5 | −2.1 | 29.9 |
| | +1.0 | **68.1** | +19.4 | **18.3** | −3.3 | 29.3 |
| | +1.5 | 77.3 | +28.6 | 16.5 | −5.1 | 29.2 |
| **1665**（侧逆光） | 0 | 58.3 | — | 14.3 | — | 35.1 |
| | +0.5 | 68.2 | +9.9 | 13.3 | −1.0 | 35.7 |
| | +1.0 | **77.4** | +19.1 | **11.9** | −2.4 | 36.1 |
| | +1.5 | 85.4 | +27.1 | 10.1 | −4.2 | 36.4 |

三条可以直接写进代码的事实：

```
① 传递：脸 +19 L*/EV（线性）
② 代价：脸 C −2.4 ~ −3.3 /EV（≈ −2.5 平均）
③ 选择性：背景只动 +0.1~+1.3 L* ⇒ 主体蒙版确实是"只碰人"
```

⇒ **"提亮会把彩度稀释"这句话现在有数了：每提 1 档赔 2.5 个 C。**
"白"和"有血气"是**一对反向的力**，必须同时给。

## 2 语料帮不了这一档（重要，别拿它当依据）

- 64 卡 / 847 张的 `light.source` 标签里 **`flash` = 0**（鹿井 / 滨田 / xhs 全是自然光）。
- 所以语料测出来的"逆光脸 −2.1 EV（比值 0.55）"是**无补光档**的样子。
- 把它当成人像该有的样子，就会得出"逆光脸就该暗"——那是**街拍纪实**的审美，不是人像补光的审美。

**两档并列，不是谁对谁错：**

```
自然档（无补光）：脸 = 背景亮部 × 0.55  ≈ −2.1 EV     ← 鹿井那种街拍
补光档（fill）  ：脸 = 背景亮部 × 0.35  ≈ −1.5 EV     ← 经典"补光压到环境下一档半"
                 （强补）        × 0.30  ≈ −1.7 EV
```

出处：补光是逆光人像的标准手段，常规口径是**补到比环境光低 1~1.5 档**
（[Basics Photography: Lighting](https://www.archive.org/download/Basics_Photography_Lighting/Basics_Photography_Lighting.pdf)、
[DPR 论坛实操帖](https://www.dpreview.com/forums/threads/advice-needed-re-fill-in-flash-for-outdoors.2678787/)）。
"白/有血气"这一半属于**记忆色**问题（人偏好的肤色比实测更亮更饱和）——
方向有文献支持（[记忆色肤色再现](https://warp.ndl.go.jp/collections/info:ndljp/pid/1436884/sciencelinks.jp/j-east/article/200218/000020021802A0612161.php)、
[US7202975](https://patentimages.storage.googleapis.com/5e/44/76/b4853179496cee/US7202975.pdf)、
[Color Res. 记忆色](https://onlinelibrary.wiley.com/doi/pdfdirect/10.1002/col.70114)），
**但没有公开闭式** ⇒ 只当方向，剂量靠出片 + 目检（纪律 §3）。

## 3 剂量怎么定（我的建议，不是让人挑）

对 1608 这种（背景亮部 97）：

| 目标 | 需要 | 落点 | 结果 |
|---|---|---|---|
| −2.1 EV（自然档） | +0 | 48.7 | 暗脸 + 轮廓光（鹿井味） |
| −1.5 EV | ≈ +0.7 | 62 | 明显补光，仍有氛围 |
| **−1.2 EV** | **+1.0** | **68.1** | **亮、白、C 18.3 还有血气** ← 起点 |
| −0.9 EV | +1.5 | 77.3 | 再亮就发白，C 16.5，"血气"开始丢 |

**起点取 +1.0 EV**，理由两条都不是拍脑袋：
1. 落在经典补光口径的上半段（−1.2 EV，比环境低一档多一点）；
2. 它是**彩度的拐点**：+0.5→+1.0 每档赔 2.1~2.4 C，+1.0→+1.5 开始赔 1.8 但 C 已经掉到 16.5。

**约束是 C，不是 L** —— 1665 就是反例：+1.5 档脸 85.4（T4 上界刚破）但 C 只剩 10.1（T5 地板），
再提就变灰白板。⇒ 剂量必须由"**C 不低于多少**"封顶，不是由"L 不超过多少"封顶。

## 4 判据要怎么改（两档，不是改一个数）

```
自然档：逆光 zone = T4_BACKLIT 45~70      （现状，保留）
补光档：逆光 zone = T4 55~85              （补完的脸按顺光的要求判 —— 因为脸上确实多了一支灯）
        + 新的硬门：C_after ≥ C_after_pred - 1     （提亮不许把血色提没）
```

实现顺序（都落在 LR，引擎不动）：

```
② 曝光：仍按"受光面进区"判（自然档的值），**不负责补光**
⑥ 补光：主体蒙版 LocalExposure = EV/4（量程 −1~+1 ⇒ ±4 档），起点 +1.0
⑦ 回彩：点颜色 SatScale（现在 PC_BACKLIT_SAT=0.15），把 ⑥ 赔掉的 C 补回来
        剂量 = 0.7 × (2.5 C/EV × 补光档)  ⇒ +1.0 EV 时约 +1.75 C 的补偿起点
```

三条护栏：
1. **补光后要量衣服**（主体蒙版连衣服一起提；白裙会先爆）⇒ 量 `CLOTH` 掩膜的 p95/clip；
2. **补光后脸贴顶（L≥99 或 p99.9 截断）⇒ 停**，不许硬顶；
3. **补光只补一次**（一次算、一次验，不闭环）—— 闭环就是手册那条"必然振荡"。

---

## 5 这一改会不会破坏工具的设计初衷

不会，三条都对得上：

```
· 引擎那条线**一个字没动**（不碰落点、不补光、不改曝光）⇒ 分工没破
· 补光在 LR 的局部工具里（主体蒙版 / 点颜色），正是它擅长的"按位置局部"
· 物理没被篡改：我们不是在改"脸本来有多亮"这个测量值，
  而是在它**之上**加一支虚拟的灯 —— 跟实拍加反光板是同一件事
```

唯一要承认的是：**"补多少"不是物理，是审美**。所以它必须
①挂在"意图/场景档"上（不逐图闭环）②有明确的默认值 ③每次都由目检确认。

### 6.1 三条结论

```
① 传递 ≈ +20 L*/档（和 mask4 的 19 一致），背景几乎不动（30.0→29.1）
② **真正的上限是白裙**：+1.25 档裙子 p95 到 96~98、全幅爆白 0.43~0.57%；
   +1.0 档只有 0.32% ⇒ 剂量由裙子封顶，不是由脸封顶
③ 彩度代价**看底子**：1608（C 21.6）几乎不掉（+1.25 才 −1.0）；
   1665（C 14.3）掉得明显（+1.0 就 −2.4）⇒ 底子越灰，提亮越灰
```

### 6.2 量法修正（重要，改 §1 那个表）

`mask4` 那张表（21.6→18.3、14.3→11.9）是**自由取样**量的：每渲一版就重新挑"最平整的点"，
脸一亮就挑到另一块 ⇒ "提亮掉彩度"里混进了**取样点漂移**。
这次固定像素量：1608 的 C 在 +1.0 时是 **21.8**（不是 18.3），1665 仍是 11.9（这条对上了）。

⇒ **§1 的"每档赔 2.5 C"不能当通用常数**；它是"底子 + 取样点"的函数。
⇒ 补光的彩度补偿不能按固定斜率算，要按"这一张掉多少"来（量 ③ 才知道）。

### 6.3 回彩先别急着定

1665 饱和 +50 ⇒ C 11.9→17.9（+6.0）、L −1.5。数值上"血色回来了"，
但**画面偏橙**（手臂、裙边一圈暖）——因为加饱和是沿着**原色相**推，而肤色本来是橙黄（h≈43）。
要"白里透红"应该**同时把色相往红挪一点**（h 43 → 37 量级），这要单独标一次色相-彩度的响应。
