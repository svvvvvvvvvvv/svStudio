# 日系胶片人像的 LR 工作流：别人怎么做，我们怎么用

> 目的：不是抄参数，是看**顺序、方向、哪些是风格、哪些是内容**。  
> 我们的工具是“匹配卡 → 从卡生成参数”，所以别人的固定数值只能当**方向**，不能当 target。

---

## 1. 别人的典型工作流（中文教程/问答）

来源：太平洋摄影部落的日系胶片问答、小红书的富士人像教程。

### 1.1 基础光影

- **曝光 +0.3～0.7**：整体提亮，求“通透/空气感”。
- **对比度 −20 左右**：低反差，柔化。
- **高光 −50～−80**：压树叶间隙/天空，防过曝。
- **阴影 +30～+50**：提暗部，去生硬阴影。
- **黑色色阶上提**：blacks 不纯黑，模拟胶片褪色。
- **饱和度 −5～−10**：整体降一点，避免浓烈。

### 1.2 HSL

- **绿色**：色相向青，饱和 −10～−20，明度 +10～+20 → 薄荷/青绿背景。
- **蓝色**：饱和降、明度提 → 淡雅天空。
- **橙色/黄色**：明度提、饱和降 → 皮肤白皙透亮。
- **背景色服务主体**：绿/蓝不抢人。

### 1.3 曲线 + 分离色调

- **RGB 小 S 曲线**：幅度小，只补形状。
- **红曲线暗部下拉**：加青。
- **蓝曲线暗部上提**：中和过度偏色。
- **分离色调**：阴影加青绿，高光加淡橙黄；饱和度低，避免脏。
- **颗粒**：15–25 / 3–5%，模拟胶片质感。

### 1.4 相机校准

- **蓝原色饱和度 +10～+20**：整体更纯净、有层次，模拟胶片。

### 1.5 前期

- **逆光/侧逆光**、漫射光；**浅色穿搭**；**RAW**；**轻微过曝**。

## 2. 这些做法的共同“方向”

| 维度 | 日系胶片方向 |
|---|---|
| 曝光 | 偏高，脸亮，背景可过 |
| 对比 | 低，但保留层次 |
| 黑端 | 上提（不纯黑） |
| 白端 | 柔，不硬切 |
| 阴影 | 青/蓝绿 |
| 高光 | 暖橙/黄 |
| 绿/蓝 | 降饱和、提明度、偏青 |
| 肤色 | 橙/黄：提明度、降饱和、偏暖 |
| 质感 | 细颗粒、轻微柔 |

**注意：这些是“方向”，不是“数值”。** 同一方向在不同光线下数值差很大；抄数值会翻车。

## 3. 对我们设计的启发

### 3.1 顺序：和 LR 的实际面板顺序一致

```
Basic（曝光/对比/高光/阴影/黑白色阶）
→ HSL（肤色/绿/蓝）
→ 曲线（形状）
→ 分离色调（阴影青/高光暖）
→ 相机校准（蓝原色）
→ 颗粒（介质）
```

我们 v2 的顺序是 Basic → 曲线 → SplitToning → HSL；**HSL 应该更早**（它管肤色和背景色，Basic 之后就该做），SplitToning 在其后；相机校准我们还没用。

### 3.2 风格 vs 内容

- **风格**：低对比、提黑、阴影青、高光暖、绿蓝降饱和、肤色亮而淡、颗粒。
- **内容**：白裙、天空、树叶、逆光——这些是**场景**，不是风格；不能拿它们的全图 white/black 当靶。
- 我们的 `card_target_v2` 已经把 **fg/bg** 分开；接下来 HSL/曲线都要用 **fg**，背景只做参考。

### 3.3 曲线：形状，不是端点

- 别人用小 S + 提黑点；提黑点是**风格**（褪色），不是“黑端没对齐”。
- 我们的曲线应该：
  - 端点由 Whites/Blacks 锁；
  - 形状（toe/shoulder/中间调）由卡的前景 p5–p95 决定；
  - 提黑点 = 卡的黑端 + 一点风格，不是硬把 p5 拉到 0。

### 3.4 颜色分级：两段够用，三段更好

- 多数教程用 **Split Toning 两段**（阴影青/高光暖）；LR Classic 也有 **Color Grading 三段**（shadow/mid/high）。
- 我们已用 `SplitToning*` 真键；mid 段可以后续用 `ColorGrade*` 补。
- 关键：**阴影/高光的 a/b 从卡来**，不是固定青/橙。

### 3.5 HSL 是主角之一

- 肤色（橙/黄）和背景（绿/蓝）是日系胶片的核心；不能只当“最后微调”。
- 我们的 HSL 目前只给了橙/黄的小步；应该：
  - 橙/黄：按卡的 `skin h/C/L` 反解；
  - 绿/蓝：按卡的 `bg` 色相/饱和；
  - 幅度可以大，但要保脸不脏。

### 3.6 相机校准：我们漏了

- **蓝原色饱和度/色相** 是整体色彩倾向的“总闸”，教程里常用来模拟胶片。
- 可以加入 look 层：`BluePrimarySaturation`/`BluePrimaryHue`（真键需验证），从卡的蓝色/整体色偏来。
- 这是全局的，不能和 HSL 的蓝抢；一个 owner。

### 3.7 颗粒：介质，不是 LR 补

- 教程用 LR 颗粒；我们的引擎已经有 grain（介质）。
- 不要 LR Grain + 引擎 grain 双补；LR 只做轻微，或交给引擎。

## 4. 我们的新顺序（建议）

1. **Exposure**：脸 L 落卡的脸带；背景可过。
2. **Whites/Blacks**：前景 p99/p1；黑点上提是风格，由卡的黑端决定。
3. **Highlights/Shadows**：前景 p95/p5；不压脸。
4. **Contrast**：前景 p25–p75。
5. **HSL**：橙/黄（肤色）、绿/蓝（背景）——按卡的 skin/bg 反解。
6. **Curve**：形状残差（≤16 点；端点锁）。
7. **Split Toning / Color Grading**：阴影/高光 a/b 从卡来。
8. **Camera Calibration**：蓝原色（整体色偏；验证键名后）。
9. **Grain**：引擎介质；LR 不重复。

每步量；2–3 轮；一个 owner 一次。
