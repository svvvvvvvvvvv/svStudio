# 滨田（整套）拆卡提案

## 现状

`滨田（整套）` 的 `content.mixed = true`，15 张样本，当前仍是一张并列卡：

- 当前 stock/paper：`kodak_portra_160 + kodak_portra_endura`
- 当前配方：Portra 160 + Endura
- 问题：样本不是同一套人/光/场景，一张 medium 不能代表整卡。

## 视觉分组（按文件前缀/场景）

| 组 | 样本 | 说明 |
|---|---|---|
| A | `02.jpg` | 海边白裙，单人，硬太阳 |
| B | `04.jpg` | 海边蓝衬衫，单人，硬太阳 |
| C | `x102_01/06/07.jpg` | 城市/室内，同一人像系列 |
| D | `x103_05/08/11/12/13.jpg` | 海边绿裙/卡其裙/白衬衫/咖啡馆，至少 2–3 个子组 |
| E | `x104_01/02/05/06/07.jpg` | 蓝裙，同一场景系列 |

## 建议

- 至少拆成 **4 张卡**：A、B、C、D、E 中把 D 再按“海边 / 白衬衫 / 咖啡馆”细分；
- 每张子卡重新构建 `points/tone/content/medium`，**不能复制整卡的聚合统计**；
- 拆分前，当前整卡不要用于批量匹配；
- 现有 `stock/paper` 只保留在整卡占位，拆完后按子卡重选。

## 状态

- 这是**视觉提案**，不自动写卡；
- 拆卡需要重新跑卡构建（`matchcard` / `card_tone` 流程），不是手改 JSON 能完成的。
